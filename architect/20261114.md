# 2026-11-14 KST · ArcFace 대조 모델의 학습과 평가

**상태** 구현됨. SCFace와 TinyFace 정렬 모델은 이미 40 epoch 학습을 마쳤다. 11월 6일의 체크포인트와 불변 데이터 검증 정책을 계속 사용한다. 기준 보고서는 `facex-ca0238b1a4614dfb21012afd`다.

**FaceX-Zoo**에서 03의 SurvFace 대조 캠페인은 기준 parent와 학습 설정 파일의 SHA-256, 역할 목록을 확인한다. 같은 ArcFace head에서 `margin_am`을 0에서 `1 − cos(0.6)`으로 바꾼다. FR 학습 4,255명과 비등록 보정 1,064명은 고정한다. 학습·복구·export 파일은 별도 경로를 사용한다. 실제 64장으로 순전파와 역전파를 확인했다. 성능 판정에는 40 epoch 완료 후의 평가가 필요하다.

**정렬 모델 전달**은 04의 `aligned_controls`를 사용한다. FaceX-Zoo는 기존 SCFace 두 눈 및 TinyFace PFLD 5점 대조 체크포인트를 읽는다. 이미지 ID, 원본 SHA-256, 112×112 변환 행렬을 담은 CSV의 해시를 가중치에 포함한다. 학습 PNG와 변환 결과가 픽셀 단위로 일치해야 게시한다. 이 방식은 평가에 쓸 원본 이미지가 확정된 두 데이터셋을 대상으로 한다.

**ronbun**의 02는 같은 ID와 원본 바이트를 검증하고 변환 후 임베딩을 생성한다. 정렬 모델에는 자체 데이터셋만 선언한다. 03은 같은 분할의 PQ 개발 표본에서 해당 모델의 codec을 학습한다. 04는 압축 전 순위, 압축에 따른 변화 및 SurvFace의 품질별 임계값 효과를 보여준다. SurvFace 시험 ROC는 기술 통계이며 시험 점수로 구한 경계를 보정 모델에 전달하지 않는다. DB 스키마 변경은 없다.

**검증 기준**은 SCFace의 1,020/1,200, TinyFace의 2,297/3,728 및 오답 후보 포함 2,071/3,728이다. SurvFace에서는 기준 모델 대비 대조 모델에서 미등록 cosine ≥ 0.95 건수와 같은 목표 FPIR에서의 Origin TPIR@20을 확인한다. PQ는 각 점수 공간에서 다시 학습한 Global-safe와 Continuous-FIQA의 실제 FPIR와 TPIR@20을 비교한다. 대조 결과는 seed 8972에 한정되며 수치 개선이나 FPIR 보장을 전제하지 않는다.

## 17:25 KST · 필요한 fine-tune 조합만 확장

**상태: 구현됨, 경로 검증됨.** 이전의 parent·FR/calibration/test 분리와 정렬 대조 결정을 유지한다. FaceX 03·04는 `selected` 캠페인을 선택하며 실행 기본값은 False다. 신규 `selected_campaign.py`가 recipe·dataset·head·seed별 계획, 명시적 완료 참조, 중단 checkpoint, 불변 선택 파일, export inventory를 담당한다. Trainer·수식·fingerprint 대상 파일은 변경하지 않았다. `process_runner.py`/`run_campaign.py`로 안전 중단과 오류 전파를 유지한다.

기본 행렬은 SCFace 두 눈 정렬 4개, TinyFace PFLD 정렬 4개, SurvFace resize 3개와 ArcFace continuous-margin 1개, seed 8972다. 실제 checkpoint 검증에서 5개 재사용과 7개 신규 학습으로 판정했다. completed 여부만으로 재사용하지 않고 parent·훈련 설정·seed·프로토콜·전처리·파일 hash를 비교한다. 기존 5개의 export는 원본 파일과 UID를 유지한다. 새 head/seed 추가 시 같은 출력 루트와 새 selection 파일을 사용한다. 조건 변경은 새 출력 루트로 분리한다.

ronbun `facex_inventory.py`와 02는 전체 inventory를 검증하고 명시적 ModelSpec/YAML을 생성한다. 새 YAML은 baseline 단계부터 시작하며 현재 선택은 native 데이터셋 평가다. 정렬 모델을 LFW/RFW까지 평가하는 패키지는 이번에 추가하지 않았다. DB schema·평가 지표·calibration split은 변경하지 않았다. 원본 보존 옵션은 각 기존 workflow에 전달하며 결과/모델은 외부 저장소에 남긴다.

검증 근거는 기존 5개 모델의 실제 별도 프로세스 재사용·export 및 ronbun 등록, 7개 신규 조합의 GTX 1080 Ti 실제 64-image 순전파·역전파, 합성 2 epoch 중단/재개 후 가중치 완전 일치다. 검증 artifact는 `F:/models/facex/selected/validation_20261114`에 있으며, 5개 재사용 inventory의 ID는 `4d5b25dae1bb1528958c9d93e4eb615989fe6ae3b72aa0ad70a99640beaa6bcf`다. 전체 12개 완료 inventory가 아니다. 40 epoch 신규 학습·새 임베딩 추출·PCA/PQ 및 보정 본실험은 아직 실행하지 않았다. 이 작업은 실행 구조의 검증이며 성능 개선의 검증이 아니다.
