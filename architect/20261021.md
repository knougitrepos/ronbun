## 로컬 입력 파일과 Git

시작 시 유일한 변경은 미추적 `results/lfw_pair_inputs_v1/`이었다.
총 16개 파일 167,925,756 bytes이며 FIQA CSV는 13,233행, 1,986,961 bytes다.
이 폴더에는 완료 manifest가 없고 현재 pair YAML은 `lfw_deepfunneled_resize_v1`을 참조한다.
두 위치의 FIQA CSV hash도 다르므로 동일 완료 입력의 복제본이라고 단정할 수 없다.
추가 Git 이력 조사에서 `ucface-lfw` 계열에 포함된 commit `9470478d`에 FIQA manifest가
등록되어 있고 `61730965`에도 유지되는 것을 확인했다. 그 manifest의 FIQA CSV SHA-256
`d0310f4a6cf209bdd7a16774fa71736e1947f3ddc3598aa25f26559e29fdb162`와 현재 로컬 CSV가 일치한다.
따라서 질문의 CSV는 해당 과거 입력 artifact와 연결된다. branch 이동 후 로컬 payload만
남고 step14에는 대응 manifest/ignore가 없는 상태와 부합한다. 실제 생성 명령과 branch 이동
시점은 확인하지 않았다. 현재 YAML로의 재사용 적합성을 검증한 것은 아니다.
같은 commit의 source manifest 5개와 로컬 NPY/population 15개도 SHA-256이 모두 일치했다.
이는 과거 artifact 파일과의 동일성 검증이며 step14 입력 설정 변경이나 실험 재실행을 뜻하지 않는다.
파일을 보존한 채 상세 NPY/population/FIQA payload에 한정한 ignore 규칙을 추가한다.
manifest·요약은 제외하지 않으며 검증되지 않은 manifest를 새로 만들지 않는다.
