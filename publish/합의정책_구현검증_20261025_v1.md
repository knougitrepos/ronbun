## 수치 정책의 정확한 범위

`fine-tune/modules/target_margin.py`의 정책 이름은 `target_only_fp32_zero_radicand_eps_v1`이다.

```text
c = clamp(FP32 normalized dot product, -1, 1)[target]
r = 1 - c*c
sin_target = sqrt(where(r == 0, finfo(float32).eps, r))
```

이는 원래 목적과 내부 구간의 수식을 유지하면서 정확 경계의 값·미분을 수정하는 로컬 수치 정책이다.
경계 근처의 큰 유한 gradient까지 없애는 정책이 아니며, 모든 NaN 또는 동일한 학습 성능을 보장하지 않는다.
MagFace adaptive margin 전체를 no_grad로 만들지 않으며 CosFace/AdaFace 수식은 변경하지 않았다.
FaceX-Zoo의 기존 head/·backbone/·face_sdk/ 파일도 이번 작업에서는 변경하지 않았다.

공개 FaceX-Zoo [ArcFace 코드](https://github.com/JDAI-CV/FaceX-Zoo/blob/main/head/ArcFace.py)와
[MagFace 코드](https://github.com/JDAI-CV/FaceX-Zoo/blob/main/head/MagFace.py)는 전체 cosine 행렬에 sqrt를 계산하고
정답 위치를 선택한다. 따라서 이번 정책을 저자가 공식적으로 제안한 수정이나 UCFace의 완전 동일 재현으로
기술하지 않는다. 공개 코드 확인일은 2026-10-25이다.

새 ArcFace parent와 후속 ArcFace/MagFace에는 처음부터 동일한 정책을 사용한다. 모델 config와 training_numerics,
export sidecar에 정책을 기록한다. 구 numerical policy 또는 코드 fingerprint의 parent/resume는 엄격 비교로 거부한다.
기존 checkpoint와 완료 run을 새 정책으로 덮어쓰지 않는다.

## 데이터와 실험 단계

SurvFace·TinyFace·SCFace를 FR 파인튜닝 대상으로, LFW·RFW를 모델 활용 평가 대상으로 유지한다.
현재 고정 FR/calibration/test 역할을 변경하지 않았다. TinyFace·SCFace의 기본 rank 프로토콜에는 threshold
fit/safety를 추가하지 않는다. 1024D와 두 backbone의 독립 export/등록 계약을 유지한다.

Stage 2는 SurvFace/LFW/RFW에서만 실행한다. SurvFace는 calibration_fit의 비등록자 query와 고정 calibration
gallery를 사용한다. LFW/RFW는 outer-test 인물을 제거한 기존 fit impostor pairs를 사용하며, 양쪽 identity가
같은 inner 역할인 pair만 남긴다. 최종 test와 최종 safety를 scoring/변환 입력에서 제외한다.

| 설정 | 현재 기본값 | 의미 |
| --- | --- | --- |
| study.stage | baseline | 현재 고정 분할의 기준 평가 |
| 다음 단계 | calibration_size + 명시적 BASELINE_REPORT | 완료 기준 run의 모델·입력·codec을 재사용 |
| inner folds | 5 | 원래 fit 인물 내부의 validation 분리 |
| inner safety fraction | 0.3 | 각 fold에서 validation을 뺀 인물 중 safety pool 배분 |
| fit fractions | 0.25, 0.5, 0.75, 1.0 | inner fit pool에서 선택할 인물 비율 |
| safety fractions | 0.25, 0.5, 0.75, 1.0 | inner safety pool에서 선택할 인물 비율 |
| FR/calibration 배분 비교 | 자동 실행하지 않음 | 진단 후 필요성이 확인되면 별도 protocol·학습 계획 |

비율마다 실제 query/pair 수와 인물 수를 기록한다. 같은 fold의 validation은 고정하고 subset은 중첩한다.
20개 미만 inner fit/safety 또는 빈 validation은 `insufficient_rows`로 남겨 부족한 조건도 보이게 한다.
Global-safe와 Continuous-FIQA의 관측 FPIR/FMR, 분자·분모, pinball loss, 설명용 Wilson 구간과 N×target을 기록한다.
이는 FPIR/FMR 안정성 진단이며, 최적 FR 분할 또는 TPIR/TAR 개선을 확정하는 분석은 아니다. 반복 인물과
중첩 fold/subset을 독립 표본으로 합산하지 않으며, 수학적 FPIR 보장을 주장하지 않는다.

결과는 별도 immutable report에 게시한다. summary_parts는 모델·데이터셋·group·outer fold·압축·목표별로 나누고,
각 part에 모든 inner 조건을 남긴다. 파일 수·바이트·추정 토큰량과 읽기 순서를 제공하며 CSV 왕복 일치를 확인한다.
stage 2는 원래부터 집계표만 생성하므로 KEEP_RAW_RESULTS 값과 관계없이 상세 개별 점수를 새로 저장하지 않는다.
기준 run의 원본·입력·codec은 보존한다. 부분 실행은 완료로 표시하지 않으며 같은 조건으로 재계산할 수 있다.
