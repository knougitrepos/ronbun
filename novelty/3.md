## 핵심 결론

두 연구는 **ArcFace 계열 얼굴 임베딩, cosine similarity, LFW, 얼굴 쌍의 점수 변화, saliency/가림 분석**을 공유한다. 그러나 중심 연구문제는 다르다.

- S-RISE 논문: 이미 학습된 얼굴인식 모델이 특정 얼굴 쌍을 왜 match/non-match로 판단했는지 픽셀 영역으로 설명한다.
- 현재 thesis3 구현: 압축 ArcFace 임베딩을 PostgreSQL/pgvector에서 1:N 검색할 때 압축과 ANN이 점수·순위·open-set 결정을 어떻게 바꾸는지 측정하고, candidate-conditioned accept/reject/defer와 origin exact fallback을 평가한다.
- thesis3 목표 구조: saliency를 모든 질의의 설명 그림으로 만들기보다, 저비용 특징만으로 불확실한 질의에서 압축 점수 잔차 또는 판정 위험을 추가로 예측해 fallback 비용을 줄이는 조건부 특징으로 검토한다.

따라서 이 논문이 thesis3 전체 novelty를 선점하지는 않는다. 반대로 **face-pair similarity를 대상으로 saliency map을 만든다는 아이디어 자체는 이미 선행연구**이므로, pair-conditioned Grad-CAM/S-RISE 또는 `saliency-conditioned risk`라는 이름만으로 novelty를 주장할 수 없다. Saliency가 cheap baseline보다 동일 FPIR에서 DIR·coverage·fallback·end-to-end latency를 개선할 때만 보조 방법 기여가 된다.

정식 SPIE판과 첨부본은 핵심 알고리즘과 Figure 6/Table 1 수치는 같지만 설명 설정 문구가 일부 다르다.

- 정식 SPIE판: 기본값을 500으로 쓰고, 약 500회에서 수렴한다고 설명한다.

이 차이는 모델 학습 epoch의 차이가 아니라 설명 알고리즘의 계산 예산 설정 차이다.

## Figure 6의 `10 iter`, `100 iter`가 의미하는 것

`iter`는 ArcFace/ResNet-50의 학습 epoch가 아니다. 얼굴인식 모델은 이미 MS1M으로 학습된 상태로 고정되며, S-RISE 설명 방법 자체도 별도 학습을 요구하지 않는다.

얼굴 쌍 \(\{I_p,I_m\}\)에 대해 S-RISE는 무작위 Gaussian mask를 \(N\)개 만든다.

\[
\mathcal M=\{M_i\}_{i=1}^{N}
\]

각 iteration \(i\)에서 다음을 반복한다.

1. probe만 \(M_i\)로 가리고 mate는 원본으로 둔다.
2. 고정된 얼굴인식 모델로 두 임베딩을 forward 계산한다.
3. 두 임베딩의 cosine similarity \(s^p_i\)를 계산한다.
4. 반대로 mate만 가리고 probe는 원본으로 둔 similarity \(s^m_i\)도 계산한다.
5. 이 similarity를 해당 mask의 가중치로 누적한다.

최종 probe saliency map은 개념적으로 다음과 같다.

\[
H_p=\sum_{i=1}^{N}s^p_iM_i
\]

mate map도 \(H_m=\sum_i s^m_iM_i\)로 계산한다. nonmate 쌍에도 같은 과정을 다시 수행한다.

따라서 Figure 6은 각각 \(N=10,100,500,1000\)개의 무작위 가림 실험을 누적해 만든 heatmap을 비교한다. 10회는 Monte Carlo 표본이 너무 적어 위치가 불안정하고, 표본 수가 증가할수록 무작위성이 평균화되어 map이 안정된다.

한 얼굴 쌍에서 iteration마다 양방향 가림 점수를 계산하므로 최소 두 개의 masked-image embedding 계산이 필요하다. probe-mate와 probe-nonmate를 모두 처리하는 triplet은 대략 \(4N\)개의 masked-image forward가 필요할 수 있다. unmasked embedding의 cache 여부와 batch 구현에 따라 실제 호출 수와 시간은 달라진다. 이는 GTX 1080 Ti 환경에서 S-RISE를 전체 1:N 후보에 적용하지 않고 층화 표본의 faithfulness baseline으로만 두어야 하는 중요한 비용 근거다.

Figure 6의 `iteration`과 Deletion/Insertion 평가에서 픽셀을 순서대로 제거·추가하는 반복은 서로 다른 절차다. 표의 `Iterations` 열은 saliency map을 만들 때 사용한 mask 수 \(N\)이고, Deletion/Insertion은 완성된 map의 픽셀 순위를 이용해 얼굴인식 결정이 threshold를 넘나드는 데 필요한 수정 픽셀 비율을 측정한다.

## 논문 방법의 정확한 범위

### 입력과 판단 단위

- 입력은 probe, mate, nonmate triplet이다.
- triplet을 probe-mate와 probe-nonmate의 독립적인 두 verification pair로 분리한다.
- 각 얼굴 쌍의 cosine similarity를 설명한다.
- 1:N gallery retrieval의 Top-K 후보 누락이나 rank certificate가 목적이 아니다.

### 설명 방법

- post-hoc, perturbation-based, model-agnostic 방법이다.
- 모델 내부 gradient나 구조에 접근하지 않는다.
- 무작위 Gaussian mask로 한 이미지씩 가린다.
- 고정 얼굴인식 모델의 cosine similarity를 mask 가중치로 쓴다.
- 얼굴인식 모델과 S-RISE 모두 설명 단계에서 재학습하지 않는다.

### 평가

- 모델 parameter randomization sanity check를 수행한다.
- LFW의 50 triplet 소규모 subset에서 Deletion/Insertion을 평가한다.
- CPLFW와 Webface-Occ를 포함한 표준·pose·occlusion 사례를 시각적으로 분석한다.
- FPIR, DIR, Candidate Recall@K, DB latency, storage, exact fallback은 평가하지 않는다.

## 중복되는 기여와 단순 재명명 판정

다음은 S-RISE 및 후속 XFR 연구가 이미 다루므로 thesis3의 독립 novelty가 아니다.

- ArcFace face-pair decision의 saliency 시각화
- cosine similarity를 목표로 하는 pair-conditioned explanation
- random occlusion/perturbation으로 중요한 얼굴 영역 탐색
- match와 nonmatch pair를 분리한 설명
- Deletion/Insertion 또는 occlusion score drop 기반 faithfulness 평가

다음 표현만 바꾸어도 새 방법이 되지 않는다.

- `compression-aware saliency`
- `saliency-conditioned confidence`
- `pair-conditioned Grad-CAM`
- `uncertainty heatmap`

이들이 새 기여가 되려면 saliency map 자체가 아니라 **압축으로 인한 동일 query-candidate pair의 score/rank/threshold 불안정성을 설명하는 추가 통계량**으로 정의되고, strong no-saliency baseline보다 위험과 비용을 개선해야 한다.

## 남은 차별점

이번 논문과 직접 겹치지 않는 thesis3의 방어 가능한 중심은 다음 조합이다.

1. 실제 PostgreSQL/pgvector 1:N open-set 검색
2. ANN candidate miss와 candidate 내 compression decision error의 분리
3. ground-truth FPIR/DIR와 origin exact agreement의 분리
4. registered/known unknown/unknown unknown별 위험 보고
5. 압축 profile·threshold·`K/ef_search`·fallback cutoff의 제약 기반 선택
6. hot index, cold origin, 실제 conditional I/O와 p95 latency 보고
7. saliency는 위 기준선 이후 독립 이득이 있을 때만 조건부 확장

이 차별점은 현재 전부 구현·검증된 것이 아니라 일부는 목표 구조다. 따라서 `최초`라는 표현을 쓰지 않고, 조사 범위와 완료된 실험 범위를 명시해야 한다.

## 수학적 정의

### S-RISE가 설명하는 값

고정된 얼굴인식 함수 \(f\)와 cosine similarity에 대해 mask \(M_i\)의 probe 가중치는 다음과 같다.

\[
s_i^p=cos\bigl(f(I_p\odot M_i),f(I_m)\bigr)
\]

\[
H_p=\sum_{i=1}^{N}s_i^pM_i
\]

이는 원본 모델의 pair similarity에 대한 공간적 설명이다.

### thesis3가 우선 설명해야 하는 값

동일 query \(i\)와 retrieved candidate \(j\)에 대해 원본과 압축 점수의 잔차를 정의한다.

\[
r_{ij}=s_{ij}^{512}-s_{ij}^{c}
\]

saliency 특징 \(z_{ij}^{sal}\)의 유효성은 cheap 특징 \(x_{ij}^{cheap}\)만 사용한 모델보다 잔차 또는 판정 위험을 더 잘 예측하는지로 검증한다.

\[
\Delta_{sal}
=L\bigl(\widehat r(x^{cheap})\bigr)
-L\bigl(\widehat r(x^{cheap},z^{sal})\bigr)
\]

단순 loss 감소만으로는 부족하다. 정책 수준에서는 정해진 FPIR 제약 아래 DIR 손실, fallback, saliency 호출 비용을 함께 평가해야 한다.

\[
\max_g \operatorname{UCB}_{1-\delta_g}(\mathrm{FPIR}_g)\le\alpha_g
\]

\[
\operatorname{LCB}_{1-\delta_D}(\mathrm{DIR})
\ge \mathrm{DIR}_{512}-\epsilon
\]

saliency 경로를 포함한 질의 비용은 다음처럼 분리한다.

\[
C_i=T_{hot}
+\mathbf 1\{a_i=saliency\}T_{saliency}
+\mathbf 1\{a_i=fallback\}(T_{cold\ I/O}+T_{origin})
\]

saliency가 fallback을 줄여도 \(T_{saliency}\)가 더 크면 시스템 기여가 아니다.

## 실험으로 검증할 항목

1. PyTorch ArcFace와 기존 ONNX ArcFace의 image-level embedding cosine, Top-1, score, threshold crossing 동일성을 검증한다.
2. 동일 identity-disjoint split에서 no-saliency cheap baseline을 먼저 고정한다.
3. Top-1 similarity target, Top-1/Top-2 contrastive margin target을 사전 정의해 비교한다.
4. Grad-CAM, occlusion sensitivity, 층화 S-RISE 또는 CorrRISE/xSSAB를 같은 pair 표본에서 비교한다.
5. saliency와 실제 region occlusion score drop의 Spearman 상관 및 Deletion/Insertion을 보고한다.
6. \(r_{ij}\) 예측과 ground-truth decision risk에 대한 out-of-sample 추가 설명력을 평가한다.
7. 동일 FPIR에서 DIR, automatic coverage, fallback rate를 no-saliency baseline과 비교한다.
8. GPU saliency 시간, template lookup, cold I/O, origin exact를 포함한 P50/P95 end-to-end latency를 측정한다.
9. LFW에서 선택한 saliency 정책을 SurvFace에서 재조정 없이 외부 검증한다.
10. 여러 saliency 설정을 탐색할 때 policy-selection과 최종 certification/test split을 분리한다.

## 최종 판단

- **공통점:** ArcFace/cosine/LFW/threshold/occlusion과 face-pair saliency라는 기술적 접점이 크다.
- **근본 차이:** S-RISE는 1:1 설명 품질 연구이고, thesis3는 압축 1:N open-set DB 검색의 위험·비용 제어 연구다.
- **중복 위험:** saliency 또는 pair-conditioned explanation 자체를 novelty로 주장하면 직접 중복된다.
- **현재 구현 판정:** saliency 방향은 아직 미구현·검증 불가다.
- **권장 위치:** S-RISE는 전체 시스템의 핵심 방법이 아니라 층화 표본 faithfulness baseline으로 사용한다.
- **권장 연구 순서:** cheap selective risk와 candidate miss/compression error 분리를 먼저 완성한 뒤, saliency가 독립적 위험·비용 이득을 보일 때만 확장 기여로 승격한다.

안전한 novelty 표현은 다음과 같다.

> 본 연구는 face-pair saliency 자체를 새로 제안하는 것이 아니라, 압축 ArcFace 임베딩의 1:N open-set PostgreSQL/pgvector 검색에서 ANN 후보 누락과 검색 후보 내 압축 판정 불일치를 분리하고, FPIR·DIR 및 원본 접근비용 제약 아래 선택적 판정·fallback 정책을 평가한다. Saliency는 압축 잔차와 판정 위험에 대한 독립적 추가 정보 및 end-to-end 비용 개선이 검증된 경우에만 조건부 확장으로 포함한다.
