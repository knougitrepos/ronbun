## 핵심 결론

UCFace Table IV의 FPIR 10%에서 ArcFace 1.12% → 21.80%는 fine-tuning 전후다. 같은 fine-tuning 조건에서 PFE 22.61%, DUL 25.47%, UCFace 26.80%이므로 추가 차이는 각각 +0.81/+3.67/+5.00%p다. Table IV를 학습 없는 보정이 20%p 이상 개선한 증거로 쓰면 안 된다.

PFE는 임베딩 평균을 고정하되 불확실성 head를 학습한다. DUL-cls는 평균/분산 공동 학습, DUL-rgs는 convolution 고정이 가능하지만 최종 평균/분산 head를 학습한다. UCFace는 기존 backbone에도 적용하는 추가 학습 loss다. “새 아키텍처를 설계하지 않음”, “모든 인식기 가중치 고정”, “threshold-only”는 서로 다르다.

현재 목적에는 PFE가 조건부 확장 비교 후보이며 DUL 신규 학습의 우선순위는 낮다. 외부에서 학습된 DUL/UCFace 인식기를 고정한 뒤 보정하는 비교는 자신의 post-hoc 기여와 양립한다. 다만 전체 상승을 자신의 기여로 귀속시키지 않는다.

## 이전 약점의 개선 판정

- **원본×동일 보정 대조: 개선됨.** 24~26의 확인 부족 상태를 위 완료 report 근거로 갱신한다. 구조 구현뿐 아니라 완료 비교가 존재한다. 이는 압축 특이 우위가 입증되었다는 뜻은 아니다.
- **순위 실패와 threshold 실패 구분: 개선됨.** 완료 metric에 counts, rates, rank_k_ceiling이 있고 합계와 TPIR 상한을 검증했다. Origin rank-20 ceiling은 16.8479%다.
- **압축 특이 이득: 미개선.** 이번 ArcFace/SurvFace 진단에서 m128의 보정 이득은 원본과 비슷하고 m32는 감소한다. 연구 전체 부재 증명은 아니지만 이 조건에서 큰 고유 이득을 주장할 수 없다.
- **PFE/DUL/UCFace와의 외부 실험: 미개선·해당 연결 경로 미구현.** 이번 검토에서 원문/공개 구현을 확인했으나 호환 head/checkpoint, 학습, 동일 프로토콜 결과를 만들지 않았다.
- **문헌 비교의 baseline 혼동: 부분 개선.** Table IV의 fine-tuning 열과 추가 방법 차이를 교정했다. 보충자료의 구체적 학습 분할과 PFE scoring 재현은 검증 불가다.
- **압축 전이·재보정 데이터 효율: 검증 불가.** 이번 감사 범위는 명시적 origin/PQ report이며 별도 신규 전이 실험의 완료 여부를 확인하지 않았다. 24의 계획을 완료로 승격하지 않는다.
- **Formal/그룹 FPIR 보장: 미개선.** 현재 manifest/code는 `formal_fpir_guarantee=False`. 경험적 목표 충족과 구간 상한 충족도 다르다.

## 직접·인접 경쟁 논문

1. Ahn et al., UCFace, **IEEE TIFS 2024 정식**, [DOI](https://doi.org/10.1109/TIFS.2024.3426973). uncertainty-aware contrastive representation learning. 첨부 정식 PDF Table IV·IV-A를 확인했다. 비압축 인식기 학습 비교이며 threshold-only 경쟁 baseline은 아니다.
2. Shi and Jain, PFE, **ICCV 2019 정식**, [원문](https://openaccess.thecvf.com/content_ICCV_2019/papers/Shi_Probabilistic_Face_Embeddings_ICCV_2019_paper.pdf). 고정 μ+학습 σ와 MLS가 저품질 인식/uncertainty 활용에서 겹친다. 후보별 점수 변경과 추가 저장 비용이 현재 query 공통 threshold와 다르다.
3. Chang et al., DUL, **CVPR 2020 정식**, [원문](https://openaccess.thecvf.com/content_CVPR_2020/papers/Chang_Data_Uncertainty_Learning_in_Face_Recognition_CVPR_2020_paper.pdf). uncertainty 학습으로 μ를 개선한다. DUL-rgs의 convolution 고정과 최종 μ 고정을 혼동하지 않는다.
4. 기존 FSN/FALCON/QMagFace/CQR 등은 24~26의 post-hoc 관련 비교 경계를 유지한다. 이번에는 이 논문들의 새 실험/출판 상태 전수 재검증을 하지 않았다.

## 수학적 정의와 중복 경계

현재는 `S_c(x)=max_g s_c(x,g)`에 대해 미등록 calibration에서 `tau_c(q)`를 학습한다.

`FPIR=P(S_c(x)>=tau_c(q(x)) | non-mated)`.

`TPIR20=P(rank_c(x,g*)<=20 and s_c(x,g*)>=tau_c(q(x)) | mated)`.

따라서 `TPIR20<=P(rank_c(x,g*)<=20 | mated)`. 현재 query 공통 threshold만으로 Origin의 16.8479% 순위 상한을 넘지 못하며 20%대 TPIR를 만들 수 없다. FPIR 제약을 무시한 상한과 FPIR10%에서 가능한 TPIR를 구분한다. 낮은 실제 TPIR 전체의 원인을 순위만으로 단정하지 않는다.

PFE의 MLS는 `-0.5 sum_d[(mu_xd-mu_gd)^2/(sigma_xd^2+sigma_gd^2)+log(sigma_xd^2+sigma_gd^2)]`에 상수항을 더한 점수다. gallery별 분산 때문에 후보 순위가 달라질 수 있고 기존 PQ-ADC와 별도 score space다. μ·cosine/ADC를 그대로 쓰고 σ를 무시하면 PFE를 붙이는 것만으로 이득이 생기지 않는다.

PFE+Continuous FIQA의 단순 연결은 새로운 기여가 아니다. MRQ류 압축 오차 reranking, KWS류 quantization score calibration, NP/conformal threshold, uncertainty rejection/fallback을 재명명하는지 계속 점검한다. 원 얼굴 불확실성과 PQ 근사 오차도 구분한다. `s>=tau(q)`와 `s-tau(q)>=0`은 동치다.

남는 차별화 후보는 압축 후 1:N 최대 점수 분포의 변화, 제한된 calibration 데이터에서의 운용점 유지, 저장·계산 비용과 실패 조건의 실증이다. 최초성·우월성·수학적 보장은 입증되지 않았다.

## 검증할 후속 항목

1. 동일 고정 인식기·점수 경로 안에서 Global-safe와 Continuous FIQA를 비교한다. 더 강한 외부 인식기로 바꾸어도 자신의 효과는 그 인식기 안의 추가 차이다.
2. PFE head 학습이 허용되면 test/calibration과 identity가 분리된 학습 데이터, 정확한 bottleneck 입력, MLS 또는 별도 adaptation을 먼저 고정한다. TensorFlow 1.9/64-CNN 공개 head를 현재 PyTorch iResNet100에 무검증 이식하지 않는다.
3. DUL 신규 학습 시 동일 예산의 plain ArcFace fine-tuning 대조를 포함한다. DUL-rgs 원 재현에는 classifier class-center target도 필요하다.
4. PQ+m128/m64/m32 평균에 512D float32 분산을 추가하면 gallery payload는 각각 최소 2,176/2,112/2,080 bytes다. codebook/인덱스/원 평균 추가 저장은 별도이며 분산 압축은 새 근사 설계다.
5. PFE 재정렬은 후보 L의 recall ceiling과 총비용을 평가한다. PFE uncertainty를 `tau(q,u)`에만 쓰면 순위는 유지되며 원 PFE 매칭과 구분한다.
6. 기존 전체 실험 행렬을 보존한다. 추가 pilot 조건은 사전 명시하고, 모델/head/압축기/calibration/test의 분리와 미사용 outer cohort 검증을 유지한다.

이번 분석은 architecture 변경 승인이 아니다. 기존 완료 run·score·threshold를 덮어쓰지 않았으며 기존 실험 재실행을 요구하지 않는다.
