# 7.20일 조사 1 — 연구 방향 메모

## 1. 핵심 연구 방향

본 연구는 새 거리함수를 제안하기보다, **압축 ArcFace 임베딩의 1:N open-set PostgreSQL/pgvector 검색에서 점수·순위·판정이 어떻게 변하는지 분석하고 불확실한 질의만 원본 exact 검색으로 넘기는 방법**을 검토한다.

핵심 위험은 다음 두 가지로 분리한다.

1. **ANN candidate miss**: 정답 identity가 HNSW 후보 집합에 포함되지 않는 문제
2. **후보 내 압축 판정 불일치**: 동일 후보 집합에서 압축 때문에 점수·순위·threshold 판정이 바뀌는 문제


## 2. 기술 검토

### 2.1 Cosine 이외의 거리함수

#### Sin

원 메모의 직관은 “sin은 cosine의 위상 이동과 유사하므로 굳이 사용할 이유가 있는가?”였다. 실제로 sin θ는 0≤θ≤π 전체에서 일대일 대응이 아니며 θ와 π−θ가 같은 값을 가진다. 전체 각도 범위의 고유한 유사도 순위에 부적합하다.

#### Tan

원 메모의 “90°에서 0”은 잘못된 해석이다. tan 90°는 **정의되지 않으며**, 90° 부근에서 값이 발산한다. 0°에서는 정의되고 미분 가능하다. 직교 부근의 작은 각도 차이를 과도하게 확대하므로 안정적인 얼굴 유사도 함수로 쓰기 어렵다.

#### Cosine, Euclidean, Angular distance

L2 정규화된 두 벡터 `x`, `y`에는 다음 관계가 성립한다.

```text
‖x − y‖₂² = 2 − 2(x · y) = 2 − 2 cos θ
θ = arccos(clip(x · y, −1, 1))
```

따라서 동일한 정규화 벡터를 exact 비교하면 cosine similarity, Euclidean distance, angular distance는 같은 최근접 이웃 순위를 만든다. 다만 HNSW 후보 누락이나 PQ 근사거리까지 같은 결과를 보장하는 것은 아니다.

Manhattan·Mahalanobis distance도 가능하지만, 현재 연구에서는 거리함수 교체보다 다음 항목이 더 중요하다.

- cosine 점수 분포와 threshold 이동
- 동일 query–candidate의 압축 전후 score residual
- Top-1/Top-2 margin과 순위 변화
- 임계값 경계 교차
- 질의별 불확실성과 원본 fallback

### 2.2 압축 오차와 판정 변화

Markdown 수식 렌더러에 따라 세로 막대가 깨지는 문제를 피하기 위해 수식은 Unicode 기반 표기로 적는다.

#### 재구성 오차

```text
e_rec = ‖e − ê‖₂
```

원본 임베딩 `e`와 복원 임베딩 `ê` 사이의 L2 기하학적 왜곡을 뜻한다.

#### 각도 오차

```text
e_ang = arccos(clip((e · ê) / (‖e‖₂ ‖ê‖₂), −1, 1))
```

ArcFace 초구면에서의 방향 왜곡이다. 두 벡터가 이미 L2 정규화됐다면 분모는 1이 된다.

#### 동일 쌍 점수 잔차

```text
r_ij = s_origin(i,j) − s_compressed(i,j)
```

동일 probe `i`와 동일 candidate `j`의 압축 전후 점수 이동이다. 압축 전후 Top-1 identity가 다를 때 서로 다른 후보 점수를 빼지 않도록 pair 기준을 유지한다.

#### 판정 위험 지표

- **순위 변화 `I_rank`**: 압축 후 Top-1 identity가 바뀌었는지 여부
- **경계 교차 `I_cross`**: 압축 때문에 accept/reject 판정이 뒤집혔는지 여부
- **후보 누락 `I_miss`**: 정답 identity가 ANN Top-K 후보 밖으로 빠졌는지 여부

평균 재구성 오차만으로는 충분하지 않다. Open-set에서는 non-mated probe별 최대 gallery score, margin, candidate recall, threshold crossing이 직접적인 위험 지표다.

### 2.3 데이터셋 역할

| 데이터셋 | 적절한 활용과 주의점 |
|---|---|
| **LFW** | 구현 검증·소규모 ablation. 대규모 1:N 또는 매우 낮은 FPIR 보장에는 부족 |
| **QMUL-SurvFace** | 감시환경의 저해상도 open-set identification 주 평가 후보. 463,507 images, 15,573 identities |
| **MegaFace** | 약 1.03M photos와 690,572 subjects의 대규모 distractor 평가. 배포가 종료되어 이미 확보한 경우에만 검토 |
| **VGGFace2** | 3.31M images, 9,131 identities. 주로 학습·표현 일반화용이며 공식 다운로드는 종료됨 |
| **CASIA-WebFace** | 모델 학습용. 표준 open-set 평가셋은 아님 |
| **RFW** | 인종 집단별 verification·공정성 평가. 표준 1:N open-set benchmark는 아님 |
| **AgeDB / CFP-FP** | 연령·정면-측면 포즈 변화에 대한 verification 평가 |
| **IJB-C** | template verification·open-set identification에 적합하지만 NIST 배포가 2023-03-14 종료됨 |

현실적인 순서는 **LFW로 구현·ablation 확인 → SurvFace 내부 dev/cal/test 주 평가 → 확보 가능할 때만 더 큰 gallery로 확장**이다.

Saliency를 이미 완성된 방법처럼 표현하지 않고 조건부 검토 대상으로 둔다.

## 4. 권장 실험 흐름

```text
InsightFace SCRFD 검출
→ 5-point 얼굴 정렬
→ 현재 ONNX ArcFace로 origin embedding·template 생성
→ PCA 압축 벡터를 pgvector HNSW에서 검색
→ candidate miss와 후보 내 compression error 분리
→ score·margin·재구성오차·각도오차·profile 기반 1차 logistic/BCE
→ 불확실하면 origin exact fallback
→ FPIR·DIR·coverage·fallback·hot/cold 비용 평가
→ SurvFace 외부 검증
→ 위 baseline이 안정된 뒤에만 ONNX–PyTorch 동일성 확인
→ 필요한 경우 불확실 질의의 pairwise saliency를 보조 분석
```

PQ code는 pgvector HNSW 벡터가 아니다. PQ는 Faiss ADC 등 별도 검색 baseline 또는 별도 후보 생성·reranking 실험으로 분리한다.

## 5. 단어 사전

| 용어 | 간단한 의미 |
|---|---|
| **Gallery** | 시스템에 등록된 identity 또는 template 집합 |
| **Probe** | 검색·판정을 위해 입력되는 질의 얼굴 |
| **Mated probe** | 실제 identity가 gallery에 존재하는 probe |
| **Non-mated probe** | 실제 identity가 gallery에 없는 probe |
| **Known unknown** | 학습에서는 보았지만 gallery에는 등록되지 않은 identity |
| **Unknown unknown** | 학습과 gallery에서 모두 보지 못한 identity |
| **Verification** | 두 얼굴 또는 주장된 identity가 동일인인지 판단하는 1:1 문제 |
| **Identification** | gallery에서 identity를 찾고 필요하면 unknown으로 거부하는 1:N 문제 |
| **FPIR** | non-mated probe를 gallery identity로 잘못 식별·수락한 비율 |
| **FNIR** | mated probe를 지정 rank·threshold 조건에서 올바르게 식별하지 못한 비율 |
| **DIR** | mated probe를 지정 rank 안에서 올바르게 식별하고 threshold 이상으로 수락한 비율 |
| **TAR/TPR** | 실제 동일인 또는 positive trial을 올바르게 수락한 비율 |
| **FAR/FMR** | 다른 사람 또는 non-match trial을 동일인으로 잘못 수락한 비율 |
| **Rank-K** | 정답 identity가 상위 K개 검색 결과에 포함되는 조건 또는 비율 |
| **ANN/AKNN** | 근사 최근접 이웃 / 근사 K-최근접 이웃 검색 |
| **PQ / OPQ** | subspace codebook 양자화 / 회전을 학습해 PQ distortion을 줄인 방법 |
| **ADC** | query는 원본으로 두고 양자화된 database code와 근사거리를 계산하는 방식 |
| **Calibration** | raw score를 판정·확률 해석에 적합하도록 변환하는 과정 |
| **Coverage** | 본 연구에서 원본 fallback 없이 압축 단계에서 판정을 확정한 비율 |
| **Defer rate** | 본 연구에서 압축 정보만으로 확정하지 못해 다음 단계로 넘긴 비율 |
| **Score drift** | 압축·도메인 변화 등으로 유사도 점수가 이동하는 현상 |
| **Candidate recall** | 정답 또는 exact Top-K 후보가 ANN 후보 집합에 포함되는 비율 |
