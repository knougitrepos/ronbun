5개 데이터셋 각각 1개 표본을 실제 로더로 읽어 기존·신규 입력의 원본 hash와 112×112×3 픽셀이 같음을 확인했다.
이번 검증은 새 전수 이미지 디코딩 감사가 아니다. SurvFace calibration gallery와 등록 probe는 FR-seen이며,
fit/safety만 FR에서 제외한 기존 계약을 유지한다. 분할 최적성이나 인식 성능 개선을 주장하지 않는다.

FaceX 전체 테스트에는 기존 FaceRecImageCropper의 skimage API deprecation 경고가 있었다. 원본 cropper는 수정하지 않았다.

## 보존·재실행·한계

외부 공유 데이터/전처리/model은 KEEP_RAW_RESULTS 삭제 대상이 아니다. ronbun 03의 상세 평가 결과와
FaceX 현재 run의 checkpoint 보존 정책을 각각 유지한다. 새로운 코드/경로로 입력 UID가 달라지면 새 결과를 만든다.
기존 완료 cache·manifest를 강제로 덮어쓰거나 새로운 실험으로 재명명하지 않는다.

Linux에서는 두 root 환경변수와 저장된 설정을 00부터 재확인한다. portable protocol은 다른 루트로 복사한 fixture에서 검증했다.
실제 Linux/A100 학습은 수행하지 않았다. 이미 만든 처리 결과에는 호스트별 출처 경로와 코드/정책 hash가 있으므로
다른 호스트에서 검증을 우회해 재사용하지 않는다. 필요한 경우 00의 RUN_NAMESPACE에 새 이름을 주어 재생성한다.

정식 VGGFace2 전수 추출·정렬, 새 1024D parent/후속 학습·export, 전체 입력 생성·보정·성능 평가,
DB 적재는 이번 작업에서 실행하지 않았다. `models: {}`는 유효한 새 export 등록 전 상태로 유지한다.
이전 실패 checkpoint는 사용자의 기록 보존 지시에 따라 그대로 두었다.
