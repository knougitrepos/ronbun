## 1. 핵심 결론

첨부 답변의 큰 순서인 `S/L 통제 -> Continuous FIQA -> Gallery ambiguity -> Gallery PQ distortion`는 과학적 ablation 순서로 타당하다. 다만 다음 세 가지를 수정해야 한다.

1. CR-FIQA(L)은 2-bin에서 부분적으로 유용한 신호를 보였지만 전 operating point에서 S를 지배하지 않는다. 특히 target FPIR 1%에서 L의 FPIR이 S보다 유의하게 나쁘다.
2. 2-bin threshold 차이는 `q`에 따른 conditional distribution 차이의 근거이지, `tau(q)`가 매끄럽고 단조라는 근거가 아니다. 4/5-bin 안정성 진단을 Continuous 모델 전에 두어야 한다.
3. 현재 compact test core에는 top-2 ADC score가 없다. Margin은 수식상 추가 비용이 작지만 현 artifact에서는 test ADC search 재생이 필요하다. Margin과 PQ distortion을 위한 feature ledger를 한 번에 생성해 재실행을 줄여야 한다.

최종 판정은 **Share with caveats**이다. 방향은 좋지만, Continuous나 Margin의 추가가 자동으로 novelty 또는 성능 향상을 만든다고 보면 안 된다.

위 CI는 현 구현의 query-level paired bootstrap이다. Calibration fit/safety partition은 identity-disjoint이지만 test CI는 identity cluster correlation을 반영하지 않으므로, 논문 최종 표에서는 identity-cluster paired bootstrap sensitivity를 추가해야 한다.

따라서 L을 주 개발 FIQA로 선택하는 것은 타당하지만, **1% low-tail에서 S보다 열세였음을 숨기지 말고 S를 필수 sensitivity control로 남겨야 한다.** 또한 1%와 5%는 둘 다 test target을 만족하지 못했다.

## 3. Continuous FIQA의 수정된 수학적 정의

단순히 bin threshold를 spline으로 이으면 test 성능을 보고 곡선을 고르는 과적합 위험이 크다. 먼저 calibration fit non-mated에서 target `alpha`별 conditional upper quantile을 추정한다.

\[
\hat\tau^{fit}_{\alpha}(q)
=
\operatorname{QuantileReg}_{1-\alpha}\left(S^-\mid q\right).
\]

초기 모델은 자유도가 작은 linear/hinge spline 또는 부드러운 5-bin interpolation으로 제한한다. 단조 제약은 4/5-bin 진단에서 target FPIR별 threshold trend가 안정적으로 단조일 때만 사전 정의해 적용한다.

이후 held-out safety non-mated의 residual

\[
r_i=S^-_i-\hat\tau^{fit}_{\alpha}(q_i)
\]

에서 safety offset을 구한다.

\[
\delta_{\alpha}
=
\max\left(0,Q_{1-\alpha}(r\mid \mathcal D_{safety})\right),
\qquad
\hat\tau^{safe}_{\alpha}(q)
=
\hat\tau^{fit}_{\alpha}(q)+\delta_{\alpha}.
\]

이는 safety data가 fit 곡선을 더 느슨하게 만들지 않는 one-sided empirical guard이다. formal FPIR guarantee라고 표현하지 않는다. Knot 수, penalty, 단조 여부는 test를 보지 않고 사전 고정하거나 fit 내부 nested validation으로 선택한다.

## 4. Gallery ambiguity의 위치와 Margin의 함정

ADC score는 큰 값이 우수하므로

\[
M_{ADC}=s_1-s_2\ge 0
\]

를 쉬운 gallery ambiguity baseline으로 사용할 수 있다. 다만 `M`에 `s_1`이 포함되므로 `s_1 >= tau(q,M)`는 왼쪽 판정 score와 오른쪽 조건에 같은 값을 두 번 사용한다. 이것은 label leakage는 아니지만, score에 대한 비단조 판정 경계를 만들 수 있다.

따라서 다음을 사전 지정 ablation으로 비교한다.

- `A_margin`: `M=s1-s2`
- `A_runnerup`: `s2` 또는 top-k spread를 조건으로 사용
- `A_density`: 다중 enrollment gallery feature가 유지될 때만 local density baseline

가장 단순한 방법은 `q` 구간과 ambiguity 구간의 2D bin + partial pooling이며, 직접 GAM/MLP로 넘어가지 않는다. 정말 continuous 모델을 사용하면 `s1`에 대해 단조인 결정 score를 학습한 뒤 safety non-mated에서 최종 scalar threshold를 다시 맞추는 편이 더 방어적이다.

현재 `retrieval_ledger` compact core와 `condition_scores` parquet은 top-1 score는 보존하지만 top-2/top-k score tuple을 보존하지 않는다. 따라서 Margin 검증은 calibration뿐 아니라 test PQ-ADC search 재생이 필요하다. 이는 SDC나 FIQA inference 재실행은 아니다.

## 5. Gallery-side PQ distortion

각 gallery template `g`의 PQ reconstruction `g_hat`에 대해

\[
E_{PQ}(g)=\lVert g-\hat g\rVert_2
\]

를 사전 계산하고 compressed top-1 candidate의 `E_PQ(g_(1))`를 query feature로 결합한다. 정의는 frozen codec이 실제로 입력받은 동일 embedding space에서 계산해야 한다.

이 feature의 장점은 다음과 같다.

- FIQA와 다른 compression-specific 원인을 나타낸다.
- gallery template당 scalar 하나를 미리 저장하면 되므로 online 비용이 작다.
- 현 test core에 compressed top-1 gallery ID가 있어 top-1 distortion은 Margin보다 artifact 재사용이 쉽다.

한계는 distortion norm이 query 방향에 따른 실제 ADC score error를 완전히 설명하지 못한다는 점이다. 또한 original gallery vector를 online에서 다시 읽어야 하는 query-dependent exact error를 주 방법으로 삼지 않는다.

## 6. 권장 실험 구성

구현은 순차적으로 ADC를 여러 번 재생하지 말고, 한 번의 feature-ledger 확장으로 다음 컬럼을 같이 보존한다.

```text
sample_id, identity_id, fiqa_s, fiqa_l,
adc_s1, adc_s2, adc_margin,
compressed_top1_gallery_id, top1_gallery_pq_distortion,
is_mated, top_k_correct, split/provenance columns
```

논문 ablation 순서는 다음으로 고정한다.

- M0: `global_safe`
- M1: CR-FIQA(L) 2-bin
- M1d: CR-FIQA(L) 4/5-bin 진단
- M1c: `tau_alpha(q_L)` continuous conditional quantile + safety offset
- M2: M1c + gallery ambiguity (`margin` 또는 `s2`, 사전 지정 비교)
- M3: M2 + top-1 gallery PQ distortion
- Sensitivity: 같은 seed/split의 CR-FIQA(S)

초기 주 모델은 spline/GAM/MLP 전체를 동시에 시험하지 않는다. 사전 정의한 5-bin과 저자유도 continuous 모델 하나만 비교한다.

## 7. 성공·유지 gate

다음을 모두 보고 방법을 유지한다.

1. 1%, 5%, 10% target FPIR을 primary operating points로 사전 고정한다. 20%, 30%는 secondary characterization으로 둔다.
2. `realized_fpir`, Wilson upper bound, `target_met_on_test`, TPIR@20, query-level paired CI와 identity-cluster paired CI sensitivity를 같이 본다.
3. FPIR이 다른 두 방법의 TPIR 차이를 순수 효과로 과장하지 않고, test ROC/TPIR at matched realized FPIR은 사후 진단으로만 보고한다.
4. 최소한 동일 ArcFace SurvFace의 복수 split/cross-fit에서 방향이 안정적이어야 하고, 최종 주장 전에 AdaFace 또는 추가 domain no-harm control이 필요하다.
5. point estimate의 작은 향상 하나만으로 모델을 유지하지 않는다. 추가 feature가 가져오는 latency, storage, coverage를 같이 보고한다.

## 8. Saliency의 위치

Saliency를 순위 6으로 밀어 연구에서 제거하지 않는다. 두 track을 병렬로 유지한다.

- Track A, 보정: Global -> FIQA -> ambiguity -> PQ distortion
- Track B, 설명: saliency -> compression-induced embedding/score/rank/crossing association

Saliency의 threshold feature 승격은 calibration split의 label-free saliency coverage와 faithfulness gate가 통과한 뒤 M3 대비 incremental gain으로만 판단한다. High/low masking은 intervention, random masking은 negative control로 유지한다. 현 test-only saliency로 threshold를 fit하지 않는다.

## 9. 직접 경쟁·인접 연구와 중복 경계

- QMagFace, WACV 2023: quality-aware score adjustment로 FNMR/FMR operating point를 개선한다. Continuous FIQA score correction 자체는 이미 점유된 축이다. `https://openaccess.thecvf.com/content/WACV2023/papers/Terhorst_QMagFace_Simple_and_Accurate_Quality-Aware_Face_Recognition_WACV_2023_paper.pdf`
- FALCON, WACV 2025: embedding 위치에 따른 continuous local threshold를 kernel ridge regression으로 예측한다. Continuous threshold 자체를 novelty로 주장할 수 없다. `https://openaccess.thecvf.com/content/WACV2025/papers/Al-Refai_FALCON_Fair_Face_Recognition_via_Local_Optimal_Feature_Normalization_WACV_2025_paper.pdf`
- HolUE: sample uncertainty와 gallery ambiguity를 결합한 open-set 연구이다. 첨부 답변의 gallery-aware 방향은 타당하지만 최초 주장은 불가하다. arXiv 2408.14229의 2025 revision이 있고 2026 IEEE Access 게재 메타데이터가 후속 문헌에서 확인되지만 최종 원고에서 IEEE Xplore/DOI를 다시 검증한다. `https://arxiv.org/abs/2408.14229`
- Adaptive Calibration for Fair and Performant Facial Recognition: continuous local calibration의 인접 선행이며 2026-09-03 현재 확인된 출처는 arXiv preprint이다. `https://arxiv.org/abs/2606.04469`
- LocalScore: gallery local density를 biometric score에 결합하는 인접 선행으로 2026-09-03 현재 arXiv preprint/under-review 상태로 확인된다. `https://arxiv.org/abs/2602.01012`

따라서 남는 차별점은 FIQA, Margin, distortion 각 요소가 아니라 다음의 결합된 실험 계약이다.

> Gallery-only PQ compressed 1:N face search에서 ADC score space를 분리하고, probe quality·gallery ambiguity·candidate PQ distortion의 incremental value를 identity-disjoint held-out FPIR safety 계약으로 검증하며 Rank-20 ceiling·TPIR@20·storage·latency를 함께 보고한다.
