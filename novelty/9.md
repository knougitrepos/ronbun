## 1. 핵심 결론

현재 실험은 **IEEE Access에 맞는 응용·측정·재현성 연구의 재료로는 충분하다.** 그러나 다음 문장만을 논문의 핵심 novelty로 제시하면 약하다.

> PQ ADC가 reconstruction-cosine보다 좋은 성능을 보였고, 압축 score에 threshold를 재보정하면 FPIR·TPIR·DIR을 유지할 수 있다.

그 이유는 다음과 같다.

1. ADC가 symmetric/code-to-code 거리보다 정밀하다는 사실은 Jégou et al.의 원 PQ 논문에서 이미 명시됐다.
2. 현재 ADC는 원본 float32 probe와 PQ-coded gallery를 비교하지만 reconstruction-cosine은 probe와 gallery를 모두 PQ로 양자화한다. 따라서 두 방법은 동일한 정보 조건이 아니다.
3. ADC는 squared-L2이고 reconstruction은 cosine이므로, query 압축 여부와 distance metric 효과가 동시에 바뀐다.
4. 압축 score space마다 threshold를 다시 선택하는 것은 필요한 강한 baseline이지만, 그 자체는 새로운 threshold 방법이 아니다.

따라서 현재 결과의 올바른 위치는 다음과 같다.

> **새 ADC 알고리즘이 아니라**, 얼굴 1:N open-set 검색에서 원본-query/압축-gallery와 양쪽 압축 배치조건을 구분하고, score-space별 threshold 재보정이 회복하는 score shift와 회복하지 못하는 ranking loss를 FPIR·TPIR20·DIR·Rank20·저장량으로 정량화하는 시스템 평가 연구.

이 범위로 원고를 구성하면 IEEE Access 투고 적합성은 있다. 반대로 `ADC가 더 좋다`와 `threshold를 다시 맞췄다`만 남기면 명확한 SOTA advance가 부족하다는 desk-review 또는 reviewer 지적 위험이 높다.

## 2. 현재 구현에서 실제로 비교되는 조건

원본 probe embedding을 \(q\), 원본 gallery embedding을 \(g\), PQ encoder/decoder를 \(E,D\)라고 둔다.

### 2.1 원본 baseline

\[
s_{OO}(q,g)=\cos(q,g)
\]

probe와 gallery가 모두 원본 float32이다.

### 2.2 현재 PQ reconstruction-cosine

\[
s_{QQ}^{\cos}(q,g)
=\cos(D(E(q)),D(E(g)))
\]

`step2_compression.py`는 query와 gallery를 모두 `transform_profile(...).vectors`로 복원한 뒤, `compare_cosine_retrieval`에서 두 행렬을 각각 L2 정규화한다. 따라서 양쪽에 quantization error가 들어간다.

### 2.3 현재 PQ ADC

\[
s_{OQ}^{ADC}(q,g)
=-\|q-D(E(g))\|_2^2
\]

`profiles.py::search_adc_with_metrics`는 query를 원본 float32로 유지하고 gallery code만 Faiss `IndexPQ`에 적재한다. 결과 score space는 `negative_squared_l2_adc`이며 origin cosine과 직접 비교할 수 없다.

### 2.4 현재 비교의 confounding

현재 ADC와 reconstruction의 차이는 두 가지 요인을 동시에 포함한다.

1. query representation: 원본 \(q\) 대 PQ 복원 \(D(E(q))\)
2. metric: squared-L2 대 normalized cosine

따라서 현재 결과만으로 다음과 같이 단정할 수 없다.

> ADC의 향상은 전부 query를 원본으로 유지한 효과다.

이를 입증하려면 one-sided reconstruction cosine과 PQ/PQ squared-L2 또는 SDC가 추가로 필요하다.

## 3. 현재 결과가 지지하는 범위

Target FPIR 10%, `recalibrated_compressed`에서 4개 모델 × 2개 데이터셋 × 5개 PQ profile의 40개 paired cell을 비교했다.

| 판정 | 결과 |
|---|---:|
| ADC TPIR20 우세 | 26/40 |
| 동률 | 9/40 |
| reconstruction TPIR20 우세 | 5/40 |
| ADC target FPIR 충족 | 34/40 |
| reconstruction target FPIR 충족 | 26/40 |
| 양쪽 모두 target 충족 | 24/40 |

양쪽 모두 target FPIR을 충족한 24개 cell로 제한하면 ADC 우세 12, 동률 7, reconstruction 우세 5이며 평균 TPIR20 차이는 ADC 기준 약 `+0.33 percentage point`였다.

강한 압축인 `pq_512_m8_b8`에서는 8개 model×dataset cell 모두 ADC의 raw TPIR20이 높았다. 그러나 LFW의 여러 `M=8` 운영점은 ADC와 reconstruction 모두 target FPIR을 넘었다. 예를 들어 MagFace-LFW의 약 `+20.6 percentage point` raw TPIR20 차이는 ADC FPIR 약 15.8%, reconstruction 약 16.9%로 둘 다 10% target을 실패했으므로, 유효 동일-FPIR 성능 향상으로 인용할 수 없다.

반대로 `pq_512_m128_b8`에서는 TPIR20 차이가 대체로 매우 작았다. 이는 압축이 정밀해질수록 query-side quantization과 metric 차이에 의한 격차가 줄어든다는 해석과 일치하지만, 인과 분해 실험은 아직 아니다.

현재 결과가 지지하는 안전한 문장은 다음과 같다.

> Full-precision probe와 PQ-coded gallery를 사용하는 ADC는 특히 coarse PQ에서 양쪽을 PQ 복원한 cosine 검색보다 높은 TPIR20과 더 안정적인 target-FPIR 달성을 보이는 경향이 있었다. 다만 효과 크기는 profile·model·dataset 및 operating-point validity에 의존하며 ADC가 보편적으로 우수하지는 않았다.

## 4. 선행연구 대비 novelty 경계

### 4.1 직접·인접 선행연구

| 연구 | 정식 상태 | 이미 다루는 내용 | 현재 연구에 남는 경계 |
|---|---|---|---|
| Jégou, Douze, Schmid, *Product Quantization for Nearest Neighbor Search*, IEEE TPAMI 2011, DOI `10.1109/TPAMI.2010.57` | 동료심사 journal | PQ, code 기반 거리, asymmetric comparison의 precision 이점 | 얼굴 1:N open-set FPIR/TPIR20, threshold transfer, 배치별 biometric 운영위험은 목적이 아님 |
| OPQN, *Pattern Recognition* 2023 | 동료심사 journal | scalable face retrieval용 end-to-end product quantization과 asymmetric comparison | frozen pretrained FR systems의 score-space별 open-set threshold와 gallery-amortized storage는 다르나, face PQ 자체는 선점됨 |
| OpenGCN, CVPR 2024 | 동료심사 conference | open-world threshold calibration | embedding compression 및 PQ 배치조건·storage/rank ceiling은 없음 |
| 기존 `novelty/1.md`–`8.md`의 MRQ/RaBitQ/ConANN/KWS calibration | 동료심사 중심 | quantization refinement, ANN risk, quantization-aware score calibration | 얼굴 1:N TPIR20/FPIR와 deployment asymmetry의 결합은 직접 동일하지 않음 |

### 4.2 이미 알려진 기여

다음 항목을 독립 novelty로 주장하면 안 된다.

- Product Quantization
- ADC가 SDC 또는 양쪽 양자화보다 정확한 경향
- 압축 score에 별도 threshold를 적용
- cosine과 L2 score scale이 다름
- PQ codebook과 vector payload의 저장 절감
- open-set에서 FPIR/DIR/TPIR을 측정

### 4.3 남는 방어 가능한 차별점

개별 기술이 아니라 다음 결합을 엄격하게 검증하는 데 차별점이 남는다.

1. 원본/압축 query와 원본/압축 gallery를 배치조건으로 명시한다.
2. query-side compression loss와 gallery-side compression loss를 분리한다.
3. metric effect와 representation effect를 factorial baseline으로 분리한다.
4. 각 score space에서 held-out threshold를 독립 보정한다.
5. nominal target이 아니라 realized FPIR, `target_met`, count와 CI를 보존한다.
6. TPIR20과 closed-set Rank20을 함께 사용해 보정 가능한 score shift와 보정 불가능한 rank loss를 분리한다.
7. query 재사용, unknown-X enrollment, codebook migration 등 실제 biometric template lifecycle을 실험 시나리오와 연결한다.
8. vector payload뿐 아니라 codebook overhead, gallery size, query 전송량, latency를 공동 보고한다.

## 5. novelty를 강화하는 최소 실험 설계

### 5.1 2×2 representation 비교

| Probe | Gallery | 권장 이름 | 목적 |
|---|---|---|---|
| Origin | Origin | `origin-origin` | 완전 원본 기준선 |
| Origin | PQ | `origin-query / pq-gallery` | gallery compression loss |
| PQ | Origin | `pq-query / origin-gallery` | query compression loss의 대칭 control |
| PQ | PQ | `pq-query / pq-gallery` | 양쪽 압축 실제 저장 baseline |

실제 산업에서 `PQ query / origin gallery`의 직접 배치는 덜 일반적이지만, query-side와 gallery-side 손실을 인과적으로 분리하는 control로 유용하다.

### 5.2 metric 통제

최소 다음 다섯 score mode를 비교한다.

1. \(\cos(q,g)\): origin cosine
2. \(\cos(q,D(E(g)))\): one-sided reconstruction cosine
3. \(-\|q-D(E(g))\|^2\): ADC
4. \(\cos(D(E(q)),D(E(g)))\): both-reconstruction cosine
5. \(-\|D(E(q))-D(E(g))\|^2\): SDC 또는 decoded-query L2

2 대 3은 metric/normalization 효과를, 3 대 5는 query precision 보존 효과를 주로 분리한다.

### 5.3 operating-point 평가

각 mode와 PQ profile마다 calibration split에서 threshold를 고정하고 test에 한 번 적용한다.

\[
\tau_{m,c,s}(\alpha)
=\min\{\tau:\widehat{FPIR}_{cal,m,c,s}(\tau)\le\alpha\}
\]

보고 항목은 다음과 같다.

- target 및 realized FPIR, false-accept count/denominator, Wilson CI
- TPIR20, DIR@1, closed-set Rank20, 성공 count/denominator
- origin 대비 retention과 paired bootstrap CI
- `target_met_on_test`
- code bytes, codebook bytes, amortized gallery storage
- probe 전송/저장 bytes와 query 재사용 조건
- encode/decode/index-build/search p50/p95 또는 현재 계약에 맞는 latency

### 5.4 분해 지표

같은 metric과 유효 operating point에서 다음을 정의한다.

Gallery compression penalty:

\[
\Delta_g=M(O,O)-M(O,Q)
\]

Query compression penalty:

\[
\Delta_q=M(O,Q)-M(Q,Q)
\]

Total compression penalty:

\[
\Delta_{total}=M(O,O)-M(Q,Q)
\]

비선형 ranking과 threshold interaction 때문에 \(\Delta_{total}=\Delta_g+\Delta_q\)를 가정하지 않고 실제 paired event로 측정한다.

### 5.5 lifecycle 실험

산업 시나리오를 다음처럼 분리한다.

1. 일회성 online query: 원본 query는 검색 후 폐기, ADC 사용
2. unknown-X 재식별: 첫 query의 PQ code를 가명 gallery에 등록, 미래 원본 query와 ADC
3. 과거 동일 query replay: 원본 float embedding 또는 이미지가 있어야 정확한 ADC 재현
4. 동일 codebook index rebuild: PQ code만으로 가능
5. 새 PQ codebook migration: 원본 float embedding 필요
6. 새 FR model/preprocessing migration: 원본 이미지 또는 재처리 가능한 face crop 필요

이 lifecycle 표는 단순 정확도 비교를 실제 biometric system design knowledge로 바꾸는 데 중요하다.

## 6. 이전 novelty 약점의 개선 여부

| 이전 항목 | 최신 판정 | 근거 |
|---|---|---|
| PQ ADC score space를 cosine과 분리 | **개선됨** | 코드가 `negative_squared_l2_adc`, `score_spaces_comparable=false`, ADC 전용 재보정을 강제 |
| TPIR20·Rank20·realized FPIR 결합 | **개선됨** | v5/common report에서 운영점별 보고 가능 |
| ADC 대 reconstruction의 공정한 배치 비교 | **부분 개선** | matched 결과는 존재하지만 query precision과 metric이 동시에 달라짐 |
| query-side와 gallery-side 압축 손실 분리 | **미개선** | one-sided cosine, PQ-query/origin-gallery, SDC factorial 결과 없음 |
| ADC가 좋은 이유의 인과 검증 | **검증 불가** | 현재 결과는 원본-query와 squared-L2 효과가 결합됨 |
| RFW-Custom matched ADC/reconstruction | **미개선** | 현재 공통 TPIR20 비교표에 paired PQ row 없음 |

| clean final provenance | **완료 전제** | 사용자 요청에 따라 본 venue 판단에서 완료로 간주 |

## 7. IEEE Access 적합성 판정

IEEE Access의 공식 reviewer guideline은 고도의 novelty가 항상 필요한 것은 아니지만, 기존 출판물과 구별되고 technically sound해야 한다고 밝힌다. 또한 실험·통계가 높은 기술 수준으로 수행되고 결론이 데이터로 뒷받침돼야 한다. 공식 scope는 새 실험·measurement technique·negative result를 포함한 applied engineering article을 허용한다.

따라서 다음처럼 판정한다.

### 7.1 현재 좁은 주장만 제출

> ADC가 reconstruction보다 좋고 threshold를 재보정하면 성능이 유지된다.

- novelty: **약함**
- technical correctness: **중상**
- IEEE Access 적합성: **경계/부족 가능성 큼**
- 예상 reviewer 핵심 반론: `ADC precision advantage is known; the comparison changes both query precision and metric; recalibration is expected.`

### 7.2 현재 전체 평가 계약으로 제출

> 4개 pretrained FR system과 multiple dataset에서 score-space별 calibration, realized FPIR, TPIR20/Rank20, storage를 결합하고 recoverable shift와 irreversible ranking loss를 분해한다.

- novelty: **낮음~중간의 시스템·평가 novelty**
- technical depth: **중상**
- IEEE Access 적합성: **투고 타당, 게재 가능성은 조건부로 현실적**
- 약점: ADC/reconstruction 비교의 representation·metric confounding과 matched RFW 부재

### 7.3 최소 강화안까지 완료

> 2×2 representation × metric factorial, SDC, one-sided cosine, query lifecycle, codebook migration, held-out FPIR/TPIR20 및 storage/latency frontier를 검증한다.

- novelty: **중간 수준의 applied/system characterization**
- technical depth: **높음**
- IEEE Access 적합성: **충분히 방어 가능**
- 성격: 새 PQ 알고리즘이 아니라 실제 biometric deployment 의사결정에 새로운 정량적 지식을 제공하는 논문

## 8. 논문 주장 문안

### 피해야 할 문안

> We propose ADC for compressed face recognition and demonstrate that ADC improves reconstruction search.

ADC는 새 제안이 아니므로 부적절하다.

> Threshold recalibration guarantees FPIR preservation after PQ compression.

현재 `target_met`은 point estimate이고 일부 운영점이 실패하므로 guarantee는 부적절하다.

### 권장 문안

> We conduct a deployment-aware study of post-hoc product quantization for 1:N open-set face search, distinguishing full-precision-probe/compressed-gallery ADC from compressed-probe/compressed-gallery retrieval. Using score-space-specific held-out thresholds, we quantify recoverable score-distribution shifts and irrecoverable identity-ranking losses through realized FPIR, TPIR@20, DIR, Rank@20, and gallery-amortized storage across multiple pretrained face-recognition systems and domains.

한국어 요약:

> 본 연구는 ADC를 새로운 방법으로 제안하지 않는다. 대신 압축 얼굴 임베딩 1:N open-set 검색에서 원본 probe·압축 gallery와 양쪽 압축 배치조건을 분리하고, score-space별 held-out threshold 재보정이 회복할 수 있는 score shift와 회복할 수 없는 identity ranking loss를 realized FPIR, TPIR20, DIR, Rank20 및 총 저장량으로 정량화한다.

## 9. 최종 판단

1. **현재 실험은 IEEE Access 논문의 기반으로 사용할 수 있다.**
2. **`ADC 우세 + threshold 재보정` 자체는 novelty가 충분하지 않다.** 원 PQ 논문이 ADC precision advantage를 이미 다룬다.
3. 현재 40개 paired result는 유의미한 empirical evidence이지만 ADC가 보편적으로 우수하다는 결론은 지지하지 않는다.
4. 원고의 novelty는 새 algorithm보다 deployment 조건, score-space, ranking ceiling, operating-point validity와 storage lifecycle의 엄격한 분해에 둬야 한다.
5. IEEE Access에 가장 비용 대비 효과적인 보강은 새 saliency 또는 복잡한 learned calibrator가 아니라 `one-sided reconstruction cosine + SDC + 2×2 representation/metric ablation`이다.
6. 이 최소 강화 없이도 투고는 가능하지만, reviewer가 알려진 ADC 특성의 재확인으로 판단할 위험이 크다.
7. 최소 강화안을 완료하면 applied engineering/measurement paper로 IEEE Access에 충분히 부합한다고 판단한다.
