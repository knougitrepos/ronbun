### 우선순위 변경 근거

최신 clean full run의 compact summary에서 다음 행을 다시 확인했다.

| 항목 | 값 |
|---|---:|
| run | `20260802-R001-9bccb0c1` |

| dataset/profile/policy | `survface / pca_128 / frozen_origin` |

`pca_128`은 이 행을 운반하는 compression stratum일 뿐 원인이 아니다. `origin_decision_threshold`, `origin_false_accept_count`, `origin_fpir`은 같은 run의 compression profile 전반에 공통인 원본 operating point이다. 따라서 먼저 조사할 대상은 PCA나 PQ가 아니라 **SurvFace origin calibration-to-test transfer**이다.

이 차이는 표본 오차로 설명할 규모가 아니다. 현재 가능한 원인은 다음 셋이며 아직 하나로 확정하지 않는다.

1. threshold 또는 FPIR 구현 오류
2. calibration과 test의 gallery 규모·template 구성·probe 역할 차이
3. low-quality/domain shift에 따른 genuine calibration generalization failure

### 연구 결과 사용 경계 교정

Claude 검토의 핵심 문제 제기는 타당하지만 retrieval association 전체를 threshold 의존 결과로 처리하는 것은 정확하지 않다.

- **calibration과 무관하게 유지 가능한 지표**
  - geometry scope의 `angular_error`, `reconstruction_mse`, `cosine_to_origin`
  - retrieval scope의 `top1_score_drift`
  - retrieval scope의 `agreement_with_origin`: 원본과 압축 검색의 top-1 identity 일치 여부이며 threshold를 사용하지 않는다.
- **root-cause 해결 전 논문 결론 사용 보류**
  - `threshold_crossing`
  - accept/reject와 decision correctness
  - frozen/recalibrated DIR·FPIR
  - fixed-FPIR 운영 개선 또는 calibration 성능 주장

따라서 기존 SurvFace geometry rho 결과는 calibration incident의 직접 영향을 받지 않는다. `saliency_retrieval_associations.csv`도 전부 폐기하지 않고 `threshold_crossing` 계열만 우선 보류한다. `agreement_with_origin`과 `top1_score_drift`는 threshold-independent 분석으로 별도 표시하되, checkpoint·검색공간·다중비교 등 기존 해석 제한은 그대로 적용한다.

### P0 단독 root-cause 조사 범위

압축과 saliency를 제거한 origin-only 최소 경로에서 다음 순서로 조사한다.

1. calibration protocol의 gallery, registered probe, non-mated probe identity와 row count를 고정한다.
2. 각 calibration/test non-mated probe에 대해 전체 gallery template의 최대 impostor cosine score를 저장한다.
3. threshold 선택을 독립 재계산하고 `accepted := score >= threshold`, tie 처리, similarity/distance 방향을 검증한다.
4. `false_accept_count / non_mated_count`를 row artifact에서 다시 계산해 compact summary와 일치시킨다.
5. gallery 100/200/500/1,000 identity sweep으로 gallery-size 효과를 분리한다.
6. identity당 1장 등록과 multi-image mean template을 분리해 template 효과를 측정한다.
7. calibration/test의 raw norm, top-1 impostor score, image quality, template image count 분포를 비교한다.
8. identity leakage, mated mask, template L2 정규화, probe별 maximum 계산, score column 선택을 fail-closed assertion으로 검사한다.
9. MagFace에서 확인한 현상을 AdaFace의 origin FPIR 0.454853 및 ArcFace artifact와 교차 확인한다.

test probe label이나 test impostor score로 threshold를 다시 맞추지 않는다. official test-derived curve는 benchmark 재현용으로만 유지하고 frozen calibration threshold와 분리한다.

### root-cause 종료 기준

다음 조건을 모두 만족하기 전에는 P0가 끝난 것으로 보지 않는다.

- calibration threshold와 FPIR을 독립 재계산할 수 있는 row-level 또는 동등한 검증 artifact가 존재한다.
- 0.506662가 코드 오류, gallery/template mismatch, domain shift 중 무엇에서 발생했는지 요인별 변화량으로 설명된다.
- calibration에서 target FPIR 상한과 tie policy가 assertion으로 검증된다.
- test operating point의 허용 기준 또는 실패 판정 규칙을 test 결과 확인 전에 사전 고정한다.
- test-derived threshold를 frozen calibration 결과로 오인할 수 없도록 artifact schema가 분리된다.
- 원인이 domain shift라면 이를 오류 수정으로 숨기지 않고 calibration 방법의 실패 결과로 보고하며, 별도의 강건한 calibration 설계를 사전등록한다.

| 항목 | Calibration | 공식 test |

## 21:28 KST — Empirical Sidak gallery calibration v1 내부 검증 및 미채택

- 작성일: 2026-08-02 KST

- artifact: `runs/survface_origin_fpir_diagnostics/20260802-R001-9bccb0c1_step6_sidak_holdout_v1`

### 방법

gallery-level 목표 FPIR `α`와 gallery 크기 `G`에서 독립 pair tail 목표를 다음과 같이 정했다.

```text
p_pair = 1 - (1 - α)^(1/G)
```

calibration identity를 결정론적 두 fold로 분리하고, fit fold의 non-mated probe-template pair score에서 `P(score >= threshold) <= p_pair`를 만족하는 tie-preserving empirical threshold를 선택했다. validation fold에서는 동일 gallery/enrollment 조건의 maximum-impostor FPIR을 측정했다. 공식 test는 사용하지 않았다.

### 결과

| Gallery | Enrollment | 평균 threshold | 평균 validation FPIR | 최대 validation FPIR |
|---:|---:|---:|---:|---:|
| 100 | 1 | 0.683458 | 0.070668 | 0.074241 |
| 100 | 5 | 0.747680 | 0.062552 | 0.069655 |
| 100 | 20 | 0.777438 | 0.043048 | 0.044162 |

모든 fold의 Wilson 95% CI 상한이 0.10 미만이므로 FPIR ceiling은 지켰다. 그러나 목표 operating point보다 지나치게 낮아 DIR 손실 위험이 크다. 따라서 v1을 official 3,000-gallery 보정법으로 채택하지 않는다.

### 결정

- `empirical_sidak_pair_tail_v1`은 보수적 baseline으로 유지한다.
- 최종 방법은 pair independence를 그대로 가정하지 않고 calibration identity의 maximum-score 분포와 gallery-size 효과를 함께 모델링해야 한다.
- 다음 후보의 수식·fitting 범위·hyperparameter는 official test를 다시 보기 전에 고정한다.
- P0는 아직 종료하지 않는다.

## 21:42 KST — P1 PQ exhaustive ADC codec 경계 구현 시작

- 작성일: 2026-08-02 KST
- 상태: **codec search 구현됨·단위 검증됨·Step 2 통합 미완료**
- 작업 브랜치: `step6`

### 확인된 현재 구현

기존 `PQCompressor`의 실험 검색은 `encode -> decode -> reconstructed 512D row normalization -> cosine` 경로였다. Faiss `IndexPQ`는 학습 후 `ntotal=0`인 codec 역할만 했으며 실제 gallery code를 index에 추가해 ADC search하지 않았다.

따라서 기존 결과는 PQ reconstruction-cosine 진단이며 실제 PQ ADC 검색 성능, ADC latency 또는 index search 결과로 해석하지 않는다.

### 구현 결정

1. 원본 float32 query와 저장된 uint8 PQ gallery code 사이에서 Faiss `IndexPQ.add_sa_codes`와 exhaustive `search`를 수행한다.
2. fitted codec index는 변경하지 않고 clone/reset한 search index에 gallery code만 추가한다.
3. primary ADC distance는 squared L2로 고정한다.
4. ADC search 전에 gallery code를 decoded 512D vector로 복원하지 않는다.
5. unit-normalized origin vector에서는 원본 L2와 cosine이 동치지만 PQ reconstruction norm은 달라질 수 있으므로 ADC squared-L2와 reconstruction cosine을 같은 score로 취급하지 않는다.
6. ADC squared-L2는 origin cosine threshold와 단위가 다르므로 `frozen_origin` threshold를 그대로 적용하지 않는다.
7. ADC의 open-set operating point는 ADC score space에서 calibration한 `recalibrated_compressed`만 보고한다.
8. reconstruction cosine은 vector distortion 및 frozen-threshold 진단 ablation으로 유지한다.

### 단위 검증

무작위 PQ code에 대해 Faiss ADC가 반환한 top-k index와 distance를 `query` 대 `sa_decode(gallery_codes)` brute-force squared L2와 비교했다. index 순서와 distance가 허용 오차 안에서 일치했고 fitted codec의 `ntotal`은 0으로 유지됐다.

### 남은 P1 작업

- ADC ranking을 origin ranking과 비교하는 공통 evaluation schema
- `search_space=pq_adc_squared_l2`와 `pq_reconstruction_cosine` 명시
- ADC 전용 calibration threshold 및 frozen-origin `not_applicable` 처리
- PCA direct/reconstructed와 PQ ADC/reconstruction 4-way ablation
- storage에 codebook과 code payload 포함
- query latency, throughput, index build/add-code 시간을 분리 측정
- Step 2 workflow와 compact summary/report 통합

- 상태: **코드 구현됨·단위/워크플로 검증됨·정식 run 재실행 전**

- 이전 결정과의 관계: 21:42 KST의 codec 경계를 유지하고 Step 2, compact summary, saliency 층화까지 구현 범위를 확장한다.

### 구현된 검색 공간

| `search_mode` | 실제 검색 표현 | 점수 공간 | 허용 threshold 정책 |
|---|---|---|---|
| `pca_direct_cosine` | centered PCA 저차원 좌표 | cosine similarity | frozen-origin, recalibrated-compressed |
| `pca_reconstruction_cosine` | PCA inverse-transform 512D + 검색 시 row L2 normalization | cosine similarity | frozen-origin, recalibrated-compressed |
| `pq_reconstruction_cosine` | PQ decode 512D + 검색 시 row L2 normalization | cosine similarity | frozen-origin, recalibrated-compressed |
| `pq_adc_exhaustive` | float32 query 대 uint8 PQ gallery code | negative squared-L2 ADC | recalibrated-compressed만 허용 |

ADC distance는 threshold selector가 “큰 점수일수록 accept”라는 공통 계약을 유지하도록 `negative_squared_l2_adc`로만 부호를 바꾼다. 이를 cosine으로 재해석하지 않으며 `top1_score_drift`와 `origin_winner_score_drift`는 score-space가 다른 ADC 행에서 결측값으로 둔다.

### 저장량·지연시간 계약

1. PCA payload는 `dimension × float32 bytes`, PQ payload는 실제 code bytes를 사용한다.
2. PQ 총 gallery 저장량은 `gallery_template_count × code_bytes + codebook_bytes`로 계산한다.
3. 데이터베이스 규모별 공정 비교를 위해 `payload + codebook_bytes / gallery_template_count`를 임베딩당 상각 저장량으로 함께 기록한다.
4. cosine 검색은 origin과 compressed 검색의 실제 wall time을 분리 기록한다.
5. PQ ADC는 gallery code encode, codec clone/reset, `add_sa_codes`, query search 시간을 분리하고 query당 latency와 throughput을 기록한다.
6. 현재 latency는 `time.perf_counter`를 이용한 해당 실행의 1회 관측값이다. 논문의 안정적인 latency 표에는 별도 warm-up/repeat benchmark가 필요하다.

### 산출물과 downstream 분리

- retrieval row 및 compact summary에 `search_mode`, origin/compressed score space, score 비교 가능 여부, frozen-origin 적용 가능 여부를 기록한다.
- compact summary grain을 `compression family × profile × search mode × threshold policy`로 변경한다.
- 이전 완료 run에 `search_mode`가 없으면 PCA는 direct cosine, PQ는 reconstruction cosine으로 명시적으로 추론해 하위 호환한다.
- saliency retrieval association과 대표 사례 선택은 `search_mode`를 별도 층으로 사용한다. PCA direct/reconstruction 또는 PQ reconstruction/ADC 행을 한 profile로 합치지 않는다.
- ADC의 cross-space score drift는 결측이므로 score-drift 기반 대표 사례에서는 제외되지만, rank agreement 및 ADC-space 재보정 decision 지표는 유지된다.

### 검증 근거
