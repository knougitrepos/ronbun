## 핵심 결론

후속 실험은 원본 × 같은 FIQA 보정 대조군, 대표 외부 보정법의 동일 프로토콜 비교, 압축률 변경 후 재보정 데이터 효율로 좁히는 것을 권한다. 더 추가할 특징이 없다는 상황과 논문 주장을 판별할 실험이 끝났다는 상황을 구분한다.

동일 조합의 논문을 찾지 못해도 비교는 가능하다. 압축 손실은 비압축 대조군, 보정 이득은 동일 압축·동일 분할의 Global-safe 등과 비교한다. 외부 방법은 이 프로토콜에서 재평가하며, verification accuracy/FMR와 본 연구의 TPIR@20/FPIR 숫자를 직접 비교하지 않는다.

연속 품질 보정, gallery-aware confidence, quantization error calibration 자체의 최초성을 주장할 근거는 없다. 이번 검색도 선행 연구 부재의 전수조사 증명이 아니다.

## 수학적 정의

질의 x, gallery G, 압축 c에서 `s_c(x,g)=-||x-Q_c(g)||²`, `S1_c(x)=max_g s_c(x,g)`다. FIQA q에 대한 threshold τ_c(q)를 사용한다.

`FPIR_c = P(S1_c(x) >= τ_c(q(x)) | non-mated)`

`TPIR20_c = P(rank_c(x,g_true) <= 20 and s_c(x,g_true) >= τ_c(q(x)) | mated)`

단위 정규화된 origin 음의 L2는 2*cosine-2로 정확히 변환할 수 있다. ADC의 재구성 gallery는 단위 노름으로 가정하지 않는다. Score 공간별 fitting이 필요하다.

동일 실제 FPIR α의 사후 진단 곡선에서 얻은 TPIR을 T(c,b;α)로 쓰면:

`I_c(α) = [T(c,FIQA;α)-T(c,Global;α)] - [T(origin,FIQA;α)-T(origin,Global;α)]`

이는 압축과 보정의 상호작용 진단이다. 원본 Global만 있으면 둘째 차이를 계산할 수 없다. 같은 목표 α만 지정하고 실제 FPIR가 다른 비교와 구분한다. Test sweep은 진단이며 test에서 고른 threshold를 운영 성능으로 보고하지 않는다.

고정 query·score·threshold와 nested gallery G1 ⊂ G2에서는 max_G2 s >= max_G1 s이므로 non-mated 수락률이 감소하지 않는다. 이 성질은 새로운 이론이 아니다. Codec과 core identities를 고정해야 원인 분리가 가능하고 gallery-conditioned threshold가 변하면 수락률 단조성을 자동 적용하지 않는다.

전이 후보는 `τ_target(q)=f_source(q)+δ_target`이며 target non-mated calibration residual로 δ를 정한다. 기존 residual calibration의 응용이고 미구현·검증 전이다.

## 남은 차별점과 검증 우선순위

1. P0: origin/PQ m128/m64/m32 × Global-safe/5-bin/Continuous. Score-space·분할·라벨 및 표본 예산을 맞추고 상호작용과 rank/threshold 실패 분리.
2. P1: 외부 방법 1종 이상. MagFace의 QMagFace 입력 가용성 확인, FairCal 대표 backbone 적용 검토. Pair mapper 학습 뒤 별도 safety의 1:N 최대 score 보정. 재정렬 여부와 비용 명시.
3. P2: 압축률 전이의 재보정 데이터 효율. Source 고정, target Global 재적합, 절편 갱신, 전체 conditional 재적합을 같은 target 예산으로 비교. 500/2,000/10,000 등 예산은 실제 가용량 확인 후 고정.
4. 선택 확장: 고정 core/probe에 distractor만 추가하는 gallery size 비교. Unknown identity·codec 고정·replay 비용 통제.
5. 공통 보고: 실제 FPIR·TPIR20·분모·CI·목표 초과·calibration time·codebook/원본까지 포함한 저장량. Validation에서 profile을 선택하고 미사용 outer cohort로 최종 확인.

현재 완료 결과는 조건별 empirical usefulness와 한계의 근거다. 압축 특이 이득, 작은 target 예산의 이득, 외부 보정법 대비 우위는 아직 입증되지 않았다. 부정적 결과라면 기여를 적용 연구·비교 평가·실패 조건 규명으로 좁힌다.

THESIS_RESEARCH_PLAN.md의 BCE 등록확률 모델·혼합 압축 정책은 실제 continuous quantile 구현과 동일한 현황이 아니다. 코드·완료 manifest를 기준으로 서술하며, 이번 자문으로 목표 구조를 자동 변경하지 않는다.
