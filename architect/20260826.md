### 변경 배경

기존 PQ 비교는 양쪽 query/gallery를 PQ encode-decode한 cosine 검색과 원본 float32 query를
PQ-code gallery에 적용한 ADC를 비교했다. 따라서 관찰된 차이를 query 보존 효과와
cosine 대 squared-L2 score-space 차이 중 어느 하나로 귀속할 수 없었다. 또한 ADC에는
origin cosine threshold가 적용될 수 없다는 기존 계약을 SDC까지 일반화할 필요가 있었다.

### 결정 내용

1. PQ 검색 조건을 다음 네 가지로 고정한다.
   - `pq_reconstruction_cosine`: PQ 복원 query / PQ 복원 gallery / cosine
   - `pq_one_sided_cosine`: 원본 float32 query / PQ 복원 gallery / cosine
   - `pq_adc_exhaustive`: 원본 float32 query / PQ code gallery / asymmetric squared L2
   - `pq_sdc_exhaustive`: PQ code query / PQ code gallery / symmetric squared L2
2. 모든 retrieval 행과 compact summary에 `query_representation`,
   `gallery_representation`, `distance_function`, `compressed_score_space`,
   `score_spaces_comparable`, `frozen_origin_threshold_applicable`를 기록한다.
3. cosine 조건만 `frozen_origin`과 `recalibrated_compressed`를 모두 산출한다. ADC와 SDC는
   cosine과 다른 score space이므로 `recalibrated_compressed`만 허용한다.
4. SDC는 새 검색 알고리즘 기여가 아니라 양쪽 PQ-code 조건의 보조 ablation으로 둔다.
   Faiss 8-bit native SDC를 우선하고, 더 작은 bit width의 smoke/legacy 검증에는 동일 Faiss
   SDC table을 사용하는 bounded NumPy 경로를 둔다.
5. 파생 artifact 계약을 v6로 올리고 기존 완료 v5 artifact를 덮어쓰지 않는다. v6는
   FPIR 1/5/10/20/30%, TPIR20, closed-set Rank-20 recall, Wilson CI, paired delta CI,
   realized FPIR, target-met 여부, payload/codebook/amortized storage를 함께 보고한다.
6. 공통 보고서는 Origin, frozen/recalibrated compressed 행을 명시적으로 만들고
   `pq_query_gallery_operating_points.csv`를 별도 출력한다. `target_met_on_test=False` 행은
   목표 FPIR operating-point 결과로 인용하지 않는다.
7. `00_batch_experiment_runner.ipynb`와 `00_cross_dataset_results.ipynb`는 얇은 진입점으로
   유지한다. 실행·쓰기·덮어쓰기는 기본 비활성화하며 실제 계산과 검증은 공통 `.py`에 둔다.
8. TinyFace 표준 closed-set distractor protocol은 현재 open-set 표에 섞지 않는다.
   추가하려면 `TinyFace-Custom`의 non-mated probe와 calibration/test protocol UID를 먼저
   별도 고정해야 한다.

### 데이터·모듈 흐름

```text
완료 run의 prepared origin embeddings + explicit PQ budget
  -> 공통 PQ fit / query-gallery condition별 exhaustive search
  -> score-space별 calibration threshold

  -> 명시적 4-model x 3-dataset matrix
  -> Origin + reconstruction + one-sided + ADC (+ SDC) 보고표
```

### 미해결 위험

- one-sided cosine과 ADC가 다르면 query precision뿐 아니라 norm 처리와 code-distance 정의가
  함께 영향을 줄 수 있다. norm diagnostics 또는 normalized-L2 해석을 논문에서 병기해야 한다.
- SDC는 8-bit Faiss native 경로의 정식 대규모 latency를 아직 반복 측정하지 않았다.
- probe-level CI는 identity-cluster와 checkpoint-training uncertainty를 포함하지 않는다.
- LFW, SurvFace, RFW-Custom은 protocol/population 난이도가 다르므로 절대 TPIR/FPIR을 동일
  난이도로 해석하지 않는다.
