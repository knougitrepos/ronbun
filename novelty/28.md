## 수학적 정의와 현재 관찰

압축 조건 c, 질의 x, gallery G에서 `S_c(x)=max_g s_c(x,g)`다.

`FPIR=P(S_c(x)>=tau_c(q(x)) | non-mated)`.

`TPIR20=P(rank_c(x,g*)<=20 and s_c(x,g*)>=tau_c(q(x)) | mated)`.

query 공통 threshold는 순위를 바꾸지 않는다. 기존 ArcFace/SurvFace Origin rank-20 ceiling은 16.8479%다. TPIR과 ceiling의 차이를 전부 해결 가능한 이득으로 취급하지 않는다. FPIR 제약이 남기 때문이다.

같은 test의 20 fit/safety 분할, 목표 FPIR 10%에서 Global→Continuous의 TPIR 중앙값은 Origin 1.2892→1.4862%, m128 1.2570→1.4564%, m64 1.0402→1.1386%, m32 0.8292→0.8085%다. 실제 FPIR은 서로 다르며 전체 분모·실제 FPIR은 종합 보고서와 audit에 기록했다. 중앙값 차이는 paired 차이의 중앙값이나 독립 실험 효과 추정량이 아니다.

같은 실제 FPIR 진단의 보정 이득을 T로 정의하면 `I_c=[T(c,FIQA)-T(c,Global)]-[T(origin,FIQA)-T(origin,Global)]`로 압축 상호작용을 살핀다. 이는 새로운 이론이나 인과 효과 추정의 보장이 아니다.

## 직접·인접 경쟁 논문과 중복 경계

- FALCON, WACV 2025 정식: 연속 local threshold 예측은 이미 존재한다. [공식 논문](https://openaccess.thecvf.com/content/WACV2025/papers/Al-Refai_FALCON_Fair_Face_Recognition_via_Local_Optimal_Feature_Normalization_WACV_2025_paper.pdf). 이번 검색으로 KRR/local threshold 구성을 확인했다. pair score 조정과 현재 query 공통 1:N threshold는 구분한다.
- Hofer 등, ICPRS 2024 정식: 압축 얼굴 표현의 verification 성능을 다루는 직접 인접 연구다. [DOI](https://doi.org/10.1109/ICPRS62101.2024.10677816). 이번 공식 검색으로 제목·출판을 재확인했으며 세부 threshold 절차는 26의 분석을 따른다.
- PETALface, WACV 2025 정식: 저해상도 적응 인식기 비교 후보이며 현재 threshold 방법의 직접 baseline은 아니다. [저자 코드](https://github.com/Kartik-3004/PETALface). 품질 조건부 LoRA가 이미 기반 모델에 있으므로 추가 보정 효과를 별도로 측정한다.
- MRQ 압축 오차 reranking, KWS quantization score calibration, NP/conformal threshold, uncertainty rejection의 중복 경계를 24–27에서 유지한다. 이번에는 이 네 계열의 새 원문 전수 감사를 수행하지 않았다. 압축 오차 보정·안전 offset·거절/fallback을 새 이름으로 부르는 것은 새 기여가 아니다.

남는 차별점 후보는 고정 인식기/PQ 1:N 검색에서 보정의 효과·실패·총비용과 제한된 재보정 데이터 예산의 실증이다. `S>=tau(q)`와 `S-tau(q)>=0`의 동치적 표기 차이는 차별점이 아니다. 이번 범위는 최초성·SOTA 우월성·formal 보장을 뒷받침하지 않는다.

## 완료 전 검증 항목

1. 강한 인식기를 고정하여 Origin/PQ×Global/Continuous를 같은 cohort와 budget으로 비교.
2. 외부 보정법 최소 1종의 호환성·adaptation·정보/연산 비용을 명시하고 동일 프로토콜 비교.
3. calibration-fixed test 지표와 같은 실제 오탐의 사후 진단 분리, counts·paired CI·순위/threshold 실패 동시 보고.
4. code payload 외 codebook·인덱스·FIQA 모델과 지연시간, 실제 DB 측정의 경계 명시.
5. LFW 1:1 전환 시 새로운 분할·FMR/TAR 계약을 고정하고 기존 완료 1:N 결과 보존. 신규 실행 계획은 성과로 표현하지 않음.
