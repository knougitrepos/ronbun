# ArcFace·AdaFace PQ-m128 결과와 FIQA/Saliency 조건부 threshold 보정의 게재 수준 재평가

- 작성일: 2026-08-31 (KST)
- 상태: 분석 완료, FIQA-conditioned calibration은 제안/미구현
- 코드 기준: Git `a1e4d07af9bb9f2038652544cca19e59151659b3` (`step10`)
- 작성 목적: `novelty/13.md`의 ArcFace SDC 수치를 실제 artifact로 재검증하고, AdaFace 결과 및 향후 FIQA/Saliency 조건부 보정을 포함한 게재 가능성과 학위논문 가치를 과장 없이 재평가한다.

## 1. 핵심 결론

1. 현재 구현과 ArcFace·AdaFace 결과는 **재현 가능한 응용·시스템 특성화 연구**로서 석사학위논문의 가치가 충분하다. 그러나 새 알고리즘의 강한 이론적 novelty나 분야 최고 수준의 성능 향상으로 보기는 어렵다.
2. 현재 확인된 결과만으로는 “threshold를 유지하면서 성능을 개선했다”고 쓸 수 없다. ArcFace SurvFace PQ-m128은 FPIR 1%, 5%에서 모든 검색 방식이 `target_met_on_test=False`이고, AdaFace의 압축 방식은 원본 대비 TPIR20 차이의 paired bootstrap 95% CI가 모두 음수이다.
3. FIQA/Saliency 조건부 보정이 작은 수치 향상을 내더라도, 동일 test cohort에서 목표 FPIR 충족, paired CI, 여러 모델·데이터셋 재현이 없으면 exploratory result이다. 조건을 만족하면 IEEE Access 또는 FG/ICPR/IJCB 계열의 응용 논문 설득력이 올라가지만, CVPR/ICCV/ECCV 또는 Pattern Recognition/T-BIOM의 강한 방법론 논문 수준으로 자동 상승하지 않는다.
4. ArcFace SDC PQ-m128은 보조 ablation으로 남길 가치가 있지만, 장시간 비용 때문에 추가 SDC 실행을 중단하는 결정은 자원 제약 하에서 합리적이다. 단, ArcFace 단일 모델 결과를 근거로 SDC 일반 열세를 주장해서는 안 된다. AdaFace와의 주 비교에서는 SDC를 제외하고 공통 조건인 origin/reconstruction/one-sided/ADC만 사용한다.
5. 한국방송통신대학교 소속, 학생 제1저자·교수 교신저자라는 저자 구성은 일반적이며 논문의 과학적 수준을 높이거나 낮추는 근거가 아니다. “학과 역사상 상위 몇 %”는 공개 비교 자료가 없어 판단 불가하다.

## 5. FIQA/Saliency 조건부 threshold 보정의 수학적 정의와 성공 기준

Calibration split에서 probe의 외부 품질 점수 `q_i` 또는 saliency-derived covariate `z_i`를 train-only quantile로 구간화한다.

\[
g_i = \operatorname{bin}(q_i; q_{33}^{cal}, q_{67}^{cal}), \qquad
\tau_{g,\alpha}=Q_{1-\alpha}(S_{nonmated}^{cal}\mid g_i=g).
\]

Test에서는 구간 경계와 임계값을 다시 학습하지 않고 `\tau_{g_i,\alpha}`를 적용한다. Global, FIQA-conditioned, Saliency-conditioned는 같은 calibration/test split, 같은 score space, 같은 target FPIR에서 비교한다. ADC score space와 cosine score space의 threshold는 공유하지 않는다.

작은 개선을 논문 기여로 인정하려면 최소한 다음을 모두 보고해야 한다.

- `realized_fpir <= target_fpir` 또는 사전 정의한 통계적 보장 기준 충족
- TPIR20의 paired difference CI와 원시 성공/분모 수
- closed-set Rank-20, 저장량, latency와 fallback/coverage 비용
- ArcFace와 AdaFace에서 같은 방향, 적어도 두 open-set dataset에서 재현
- bin 경계·threshold의 calibration-only 학습과 test leakage 부재
- sparse bin에서 최소 표본 수, shrinkage 또는 fail-closed fallback
- FIQA와 Saliency의 결합은 단일 방식 결과를 확인한 뒤 별도 사전 정의 ablation으로 수행

“0.1%p 좋아짐” 자체는 충분하지 않다. FPIR를 초과하거나 CI가 0을 포함하거나 한 모델·한 셀에서만 나타나면 탐색적 결과로 제한한다.

## 6. 직접 경쟁·인접 연구와 novelty 경계

- Product Quantization은 Jégou 등의 고전적 ANN/압축 기법이며 ADC가 reconstruction보다 정보 손실을 덜 유발할 수 있다는 사실 자체는 새로운 알고리즘이 아니다.
- MagFace (CVPR 2021)는 embedding magnitude에 얼굴 품질을 내재화한다. 따라서 단순 norm-based quality binning은 강한 novelty가 아니다.
- CLIB-FIQA 등 최신 FIQA는 품질 추정 자체를 연구한다. 본 연구는 FIQA 모델을 새로 학습하는 것이 아니라 pretrained scalar를 calibration covariate로 쓰는 응용이다.
- Gallery-aware uncertainty 및 open-world threshold calibration 연구는 품질/불확실성과 gallery context를 open-set decision에 활용한다. 따라서 “품질별 threshold”만으로 최초성을 주장할 수 없다.
- 남는 차별점은 **압축 얼굴 임베딩 1:N 검색**에서 query/gallery 표현과 score space를 분리하고, 동일한 open-set protocol 아래 global/FIQA/saliency calibration을 비교하며 realized FPIR·TPIR20·Rank-20·storage·latency를 공동 보고하는 재현 가능한 실증 설계이다.

SciSpace와 alphaXiv로 2026-08-31까지 제한 검색했으며, 검색 범위 밖 선행연구의 부재를 보장하지 않는다. peer-reviewed 출판과 preprint는 원고에서 구분해야 한다.

## 7. 게재 수준의 솔직한 평가

아래 확률은 공식 acceptance rate가 아니라 현재 근거와 일반적인 novelty 요구를 바탕으로 한 주관적 범위이다.

| 상태 | 현실적 목표 | 주관적 전망 |
|---|---|---|
| 현재 ArcFace+AdaFace 특성화, FIQA 개선 미검증 | 응용 workshop, 국내/지역 국제학회, 보완 후 IEEE Access | IEEE Access 약 20–35%; FG/ICPR/IJCB main 약 10–25% |
| 조건부 보정이 다중 모델·다중 데이터셋에서 목표 FPIR를 만족하며 작은 but CI-supported TPIR20 개선 | IEEE Access, FG/ICPR/IJCB | IEEE Access 약 30–45%; FG/ICPR/IJCB 약 20–35% |
| 외부 dataset, strong baselines, statistical guarantee, pgvector end-to-end latency/fallback cost까지 완결 | IEEE Access의 강한 원고, FG/ICPR/IJCB 경쟁력 상승; T-BIOM/WACV 도전 | T-BIOM/WACV 약 10–20%의 stretch |
| 현 구조 그대로 최상위 CV/강한 방법론 journal | CVPR/ICCV/ECCV, Pattern Recognition 등 | 대체로 5% 미만; 새로운 일반화 가능한 방법론이 필요 |

IEEE Access는 공식적으로 응용·실험·measurement 연구를 scope에 포함하지만, 명확한 기존 지식 대비 진전과 높은 기술적 완성도를 요구한다. 현재 연구에는 scope fit이 있으나 자동으로 쉬운 venue는 아니다.

## 8. 학위논문과 국제학계에서의 가치

### 석사학위논문

실제 완료 run, 명시적 score-space 분리, open-set calibration, paired CI, 저장량·latency를 갖춘다면 **충분히 강한 공학형 석사학위논문**이다. 특히 혼자 구현·실험·분석했다면 연구 수행 역량을 보여주는 좋은 증거다. 다만 학위 수여와 학과 내 상대 순위는 지도교수·심사위원·학칙의 판단이며 현재 자료로 확인할 수 없다.

### 국제학계

가치는 “새로운 얼굴인식 원리를 만든 연구”보다 “압축 검색 조건이 실제 open-set operating point에 미치는 영향을 엄밀히 분해한 재현 가능한 empirical/system study”에 있다. 잘 완성되면 인용 가능한 실용 자료가 될 수 있지만, 현 단계에서 field-changing 또는 top-tier breakthrough로 평가하기는 어렵다.

저자 구성이 학생 제1저자, 교수 교신저자인 것은 정상적이다. 단독 실무 수행 여부보다 contribution statement, 재현성, 데이터와 통계의 타당성이 평가를 결정한다.

| 이전 쟁점 | 판정 | 근거 |
|---|---|---|
| Query/gallery/scoring 조건 분리 | 개선됨 | origin, reconstruction, one-sided, ADC, SDC가 artifact에서 별도 score space와 표현으로 기록됨 |
| One-sided control 부재 | 개선됨 | ArcFace·AdaFace 완료 campaign에 존재 |

| ADC threshold를 cosine과 공유할 위험 | 개선됨 | `recalibrated_compressed`와 별도 score-space threshold 사용 |
| 목표 FPIR 유지 주장 | 미개선 | ArcFace SurvFace의 해당 operating points가 모두 실패; AdaFace도 ADC 1% 실패 |
| Saliency의 threshold 보정 효과 | 검증 불가 | association artifact와 실제 conditional calibration 결과는 동일하지 않음 |
| FIQA baseline | 미구현 | pretrained FIQA inference와 group calibration 결과 없음 |
| pgvector end-to-end DB 증거 | 미개선 | 현재 artifact는 로컬 evaluator/search 조건이며 운영 DB 결과가 아님 |
| 학과 내 percentile·역사적 순위 | 검증 불가 | 비교 가능한 공식 자료 없음 |

## 10. 최종 권고

1. SDC는 ArcFace PQ-m128 보조표에 남기고 추가 실행은 중단한다. 원고에 계산비용 때문에 prespecified bounded ablation으로 제한했다고 명시한다.
2. 주 분석은 ArcFace·AdaFace 공통 조건과 동일 operating-point 계약으로 구성한다.
3. 새 노트북은 inference/분석 orchestration만 담당하고, FIQA score 생성과 conditional calibration의 canonical logic은 `.py` 모듈로 둔다.
4. 첫 성공 판정은 “평균 TPIR20 증가”가 아니라 `target_met_on_test=True` 전환과 paired CI이다.
5. 결과가 작고 불안정하면 논문을 실패로 보지 말고 “일반 영상 품질과 FR-specific saliency 중 어떤 covariate가 calibration transfer를 설명하는가”라는 negative/diagnostic finding으로 정리한다.
