# Motivation 그룹

## 1. Toward Open-Set Face Recognition (2017-cvpr)

*정식 출판: CVPR Workshops, 2017 · [공식 논문](https://openaccess.thecvf.com/content_cvpr_2017_workshops/w6/html/Gunther_Toward_Open-Set_Face_CVPR_2017_paper.html)*

### Abstract

실제 얼굴검색에서는 gallery에 없는 probe identity를 unknown으로 거부해야 한다. 이 논문은 verification-like score를 단순 thresholding하는 방식이 open-set identification에 충분하지 않음을 지적하고, LFW open-set protocol에서 cosine, LDA, EVM을 비교한다.

- **Known unknown**: 학습에서는 보았지만 gallery에는 등록되지 않은 identity
- **Unknown unknown**: 학습과 gallery에서 모두 보지 못한 identity

### Introduction

Verification은 1:1 동일인 판단이고 open-set identification은 unknown 선택을 포함한 1:N 문제다. 실험은 정렬된 LFW 얼굴에서 VGGFace의 4096D fc7 feature를 추출하고 libMR로 EVT 보정을 수행했다. EVM은 단순 z-normalization이 아니라 Extreme Value Theory를 이용해 gallery class에 포함될 확률을 추정한다.

### Conclusion

Verification 성능이 좋아도 open-set identification 성능이 자동으로 좋은 것은 아니다. LDA는 verification에서는 강했지만 closed-set identification에서는 불리했고 unknown unknown에서 저하됐다. EVM probability thresholding은 verification-like score보다 전반적으로 우수했다. 다만 LFW protocol의 규모와 unknown 표본 수가 작다는 한계가 있다.

### 나의 연구와 관련하여 참고가능 한 부분

- registered subject, known unknown, unknown unknown을 분리한 평가 설계
- 1:1 verification threshold를 1:N open-set에 그대로 적용하지 않는 근거
- 압축 전후 동일 protocol에서 threshold 이동을 비교하는 방법
- cosine·LDA·EVM baseline과 낮은 FPIR의 표본 수 주의

## 2. Open-Set Biometrics: Beyond Good Closed-Set Models (2024-eccv)

*정식 출판: ECCV, 2024 · [공식 논문](https://www.ecva.net/papers/eccv_2024/papers_ECCV/html/7925_ECCV_2024_paper.php)*

### Abstract

기존 softmax·triplet loss는 open-set 평가에서 중요한 probe별 최대 impostor score를 충분히 고려하지 않는다. 논문은 minibatch에서 open-set 평가를 모사하고 Identification-Detection Loss(I-DL)와 Relative Threshold Minimization(RTM)을 제안한다.

### Introduction

Open-set biometrics는 다음 두 문제를 함께 해결해야 한다.

1. mated probe의 identity를 올바르게 찾는 identification
2. non-mated probe를 gallery 밖으로 거부하는 detection

목표 FPIR threshold는 non-mated probe마다 최대 gallery score를 계산한 뒤 그 분포에서 정한다. Mated probe가 threshold 또는 지정 rank 조건을 만족하지 못하면 FNIR에 포함된다. 얼굴·보행·person re-identification을 함께 평가한다.

### Conclusion

I-DL과 RTM은 여러 biometric task에서 open-set 성능을 개선하면서 closed-set 성능도 유지하거나 향상했다. 다만 모델 재학습이 필요한 방법이므로 frozen ArcFace의 사후 보정을 다루는 현재 연구와 직접 방법은 다르다.

### 나의 연구와 관련하여 참고가능 한 부분

- FNIR@FPIR 계산과 non-mated probe별 최대 score 분포
- 지정 rank·threshold에서 DIR을 계산하는 open-set protocol
- frozen ArcFace 보정과 open-set 전용 재학습의 비교
- 낮은 FPIR에서 여러 split·신뢰구간을 사용하는 평가 방식

## 3. On the Intrinsic Dimensionality of Image Representations (2019-cvpr)

*정식 출판: CVPR, 2019 · [공식 논문](https://openaccess.thecvf.com/content_CVPR_2019/html/Gong_On_the_Intrinsic_Dimensionality_of_Image_Representations_CVPR_2019_paper.html)*

### Abstract

DNN 표현의 intrinsic dimensionality(ID)를 추정하고, geodesic 관계를 보존하는 비선형 mapping인 DeepMDS를 제안한다. SphereFace 512D와 ResNet 512D 표현의 ID는 각각 약 16과 19로 추정됐다.

### Introduction

- **Ambient dimension**: 저장된 벡터의 외형적 차원
- **Linear dimension**: PCA 같은 선형 부분공간으로 설명되는 차원
- **Intrinsic dimension**: 비선형 manifold까지 고려한 실제 자유도

DeepMDS를 PCA, Isomap, denoising autoencoder 등과 비교한다.

### Conclusion

IJB-C에서 SphereFace는 16D DeepMDS로 59.75% TAR@0.1% FAR, 512D 원본으로 71.26% TAR를 기록했다. 원 메모의 “512D에서 71.26% FAR”는 **TAR**가 맞다. 낮은 intrinsic dimension은 압축 동기를 제공하지만 16D에서 원본 성능이 무손실로 유지된다는 뜻은 아니다. 또한 SphereFace 결과이므로 ArcFace에는 별도 검증이 필요하다.

### 나의 연구와 관련하여 참고가능 한 부분

- 고차원 얼굴 embedding에 중복이 있을 수 있다는 압축 동기
- PCA explained variance와 intrinsic dimension의 차이
- 데이터셋·모델별 최소 유효 차원의 차이
- “ID가 16이므로 ArcFace도 16D면 충분하다”는 과도한 해석 방지

## 4. Product Quantization for Nearest Neighbor Search (2011-ieee)

*정식 출판: IEEE TPAMI, 2011 · DOI [10.1109/TPAMI.2010.57](https://doi.org/10.1109/TPAMI.2010.57)*

### Abstract

PQ는 고차원 벡터를 여러 저차원 subspace로 나누고 각 subvector를 codebook index로 표현한다. 짧은 code와 lookup table을 이용해 두 벡터의 Euclidean distance를 빠르게 근사한다.

### Introduction

Exact NN의 O(nD) 계산과 메모리 비용을 줄이는 것이 목적이다. Asymmetric Distance Computation(ADC)은 query를 원본으로 유지하고 database vector만 양자화한다.

*(각기 다른 분해 방법 또는 평행사변형·삼각형의 거리 유추 방식인 듯 → 실제로는 원본 query subvector와 양자화된 sub-codeword 사이의 거리를 lookup하는 방식)*

`vector-to-centroid`의 centroid는 이진트리 분기점이 아니라 sub-codebook의 대표 벡터다.

*(이진트리에서 분기되는 지점인 듯 → 실제로는 subspace k-means의 대표 codeword)*

### Conclusion

PQ는 SIFT·GIST에서 높은 memory–accuracy trade-off를 보였고 inverted file과 결합해 대규모 검색으로 확장됐다. ADC는 query 양자화를 생략해 symmetric distance보다 보통 정확하다.

### 나의 연구와 관련하여 참고가능 한 부분

- PCA와 구분되는 핵심 압축 baseline
- ADC와 symmetric distance 비교
- code size·Recall@K·latency·reconstruction error 공동 평가
- 얼굴 embedding에서는 cosine·angular score drift와 FPIR/DIR를 추가 평가

## 5. Optimized Product Quantization for Approximate Nearest Neighbor Search (2013-cvpr)

*정식 출판: CVPR, 2013 · [공식 논문](https://openaccess.thecvf.com/content_cvpr_2013/html/Ge_Optimized_Product_Quantization_2013_CVPR_paper.html)*

### Abstract

PQ의 성능은 고차원 공간을 어떻게 subspace로 분할하는지에 크게 좌우된다. OPQ는 quantization distortion을 최소화하도록 공간분해와 codebook을 함께 최적화한다.

### Introduction

기본 PQ는 원래 좌표축을 따라 subspace를 나누므로 분산이 불균형할 수 있다.

- 비모수 방법: 공간 변환과 codebook을 번갈아 최적화
- 모수 방법: Gaussian 가정 아래 eigenvalue allocation을 최적화

### Conclusion

데이터 분포에 맞춘 회전과 공간분해는 기본 PQ, transform coding, ITQ보다 ANN 정확도를 개선했다. 핵심은 압축 전에 좌표계를 재배치해 subspace별 distortion을 낮추는 것이다.

### 나의 연구와 관련하여 참고가능 한 부분

- PQ와 OPQ를 분리한 baseline
- reconstruction error뿐 아니라 angular error와 score drift 비교
- OPQ의 ANN recall 향상이 FPIR threshold 안정성을 자동 보장하는지 검증
- distortion–DIR–FPIR trade-off 설계

## 6. Rotation Consistent Margin Loss for Efficient Low-Bit Face Recognition (2020-cvpr)

*정식 출판: CVPR, 2020 · [공식 논문](https://openaccess.thecvf.com/content_CVPR_2020/html/Wu_Rotation_Consistent_Margin_Loss_for_Efficient_Low-Bit_Face_Recognition_CVPR_2020_paper.html)*

### Abstract

Open-set 얼굴인식은 closed-set classification보다 quantization error에 민감하다. 논문은 angular quantization error(A-QE)를 class error와 individual error로 분해하고, intra-class 구조를 훼손하는 individual error를 줄이는 RCM loss를 제안한다.

### Introduction

이 논문의 양자화 대상은 저장된 512D embedding code가 아니라 얼굴인식 network의 **weight와 activation**이다. 모델 양자화 후 closed-set Top-1은 비교적 유지되지만 open-set TPR은 크게 감소하고 positive-pair angle은 증가했다.

*(Top-1은 동일하므로 오탐 후보를 출력한다는 의미인가? → 아니다. closed-set 분류 Top-1 유지와 open-set pair TPR 저하의 차이를 보여준 것)*

### Conclusion

전체 angular error 크기를 줄이는 것보다 identity 내부 상대 구조를 보존하는 것이 중요했다. RCM은 여러 benchmark에서 low-bit FR 성능을 개선했다.

### 나의 연구와 관련하여 참고가능 한 부분

- reconstruction error만으로 인식 손실을 설명하기 어렵다는 근거
- class-level rotation과 sample-level deviation의 구분
- 압축 후 intra-class compactness 변화 측정
- 모델 양자화와 저장 embedding 압축을 명확히 구분

## 7. CLIB-FIQA: Face Image Quality Assessment with Confidence Calibration (2024-cvpr)

*정식 출판: CVPR, 2024 · [공식 논문](https://openaccess.thecvf.com/content/CVPR2024/html/Ou_CLIB-FIQA_Face_Image_Quality_Assessment_with_Confidence_Calibration_CVPR_2024_paper.html)*

### Abstract

기존 quality-fitting FIQA는 recognition model이 만든 부정확한 quality anchor도 같은 신뢰도로 취급할 수 있다. CLIB-FIQA는 blur, pose, expression, occlusion, illumination을 결합해 quality distribution의 confidence를 보정한다.

### Introduction

객관적 품질요인의 joint distribution을 merged-factor distribution으로 만들고, vision-language alignment model을 이용해 recognition-derived quality distribution을 보정한다. CLIP image/text encoder와 학습 모듈을 사용한다.

*(예전 텀프로젝트의 z-score와 반대로 사용한 듯 → 여기서는 품질점수 분포를 표준화·비교해 calibration 효과를 분석하는 맥락으로 보는 것이 안전함)*

### Conclusion

8개 데이터셋에서 기존 FIQA보다 전반적으로 우수했다. 특정 데이터셋의 pAUC 관찰만으로 “LFW에서 일반적으로 성능이 낮다”고 단정할 수는 없다.

### 나의 연구와 관련하여 참고가능 한 부분

- blur·pose·occlusion·illumination을 보정 feature로 사용하는 근거
- 품질점수 자체도 불확실할 수 있다는 관점
- saliency가 기존 quality variable의 대리인지 확인하는 ablation
- `압축오차만 → 품질 추가 → saliency 추가`의 단계적 비교

## 8. Quantization-Based Score Calibration for Few-Shot Keyword Spotting with Dynamic Time Warping in Noisy Environments (2026-icassp)

*정식 출판: IEEE ICASSP, 2026 · DOI [10.1109/ICASSP55912.2026.11464442](https://doi.org/10.1109/ICASSP55912.2026.11464442)*

### Abstract

Template-based open-set few-shot KWS에서는 validation set에서 선택한 threshold가 미관측·노이즈 환경에서 불안정할 수 있다. 논문은 embedding 양자화와 quantization-error 기반 DTW score normalization을 결합해 threshold 선택을 안정화한다.

### Introduction

KWS는 관심 keyword 이외의 음성·비음성 구간이 대부분이므로 open-set temporal detection으로 볼 수 있다. Few-shot·제한된 장치 자원도 연구 배경이다.

- onset/offset: **탐지된 keyword의 시작 시점과 종료 시점**
  *(흥미지점의 시작과 끝을 의미하는 듯 → 정확히는 탐지된 keyword event의 시작·종료 시점)*
- DTW: 길이가 다른 feature sequence의 정렬 경로를 찾아 유사도를 계산
- pipeline: embedding → 학습된 center 기반 quantization → quantization error → score normalization → thresholding

*(양자화의 필요성을 의미하는 듯 → 제한된 자원도 배경이지만, 이 논문에서 양자화의 핵심 역할은 저장 축소보다 calibration 신호 생성임)*

### Conclusion

KWS-DailyTalk의 simulated high-frequency radio channel에서 threshold 선택을 단순화하고 noisy test 성능을 개선했다. 다만 validation·높은 SNR을 포함한 모든 조건에서 항상 향상되는 것은 아니다. 이 방법의 quantization은 일반적인 PQ 저장압축과 동일하지 않다.

### 나의 연구와 관련하여 참고가능 한 부분

- quantization error를 score calibration 변수로 쓰는 가장 직접적인 선행연구
- 미관측 환경에서 threshold 안정성을 평가하는 설계
- 차별화 필요: 얼굴 1:N gallery, angular distortion, FPIR/DIR, candidate miss, accept/reject/defer, 실제 DB fallback 비용

## 9. Quantization Meets Projection: A Happy Marriage for Approximate k-Nearest Neighbor Search (2026-pvldb)

*정식 출판: PVLDB 19(6), 2026 · DOI [10.14778/3797919.3797931](https://doi.org/10.14778/3797919.3797931) · [공식 PDF](https://www.vldb.org/pvldb/vol19/p1240-yang.pdf)*

### Abstract

MRQ는 projection 후 정보가 leading dimension에 집중되는 점을 이용해 선두 차원은 정밀 양자화하고 tail residual은 경량 통계로 요약한다. Codebook lookup 비용과 원본 차원에 묶인 code length 문제를 줄이며 임의의 compression ratio를 지원한다.

### Introduction

PCA 후 dimension별 variance는 long-tailed distribution을 보인다. MRQ는 다음 단계로 후보를 정밀화한다.

1. quantized projected vector로 빠른 거리 추정
2. 원본 projected component로 정밀화
3. 필요한 후보는 projected+residual 전체 원본으로 exact distance 계산

RaBitQ 계열 양자화와 residual statistics·error bound를 결합한다.

### Conclusion

비교 가능한 정확도에서 최대 3배 빠른 검색과 약 1/3 수준의 quantization bits를 보고한다.

*(3배, 1/3 양자화보다 빠르다는 뜻인가? → 비교 가능한 정확도에서 검색은 최대 3배 빠르고 quantization bits는 약 1/3이라는 뜻)*

정밀화를 위해 원본 정보도 사용하므로 quantized code 크기만 전체 저장비용으로 해석하면 안 된다.

### 나의 연구와 관련하여 참고가능 한 부분

- PCA leading dimension과 residual statistics 활용
- error-bound 기반 progressive refinement와 exact reranking
- 최소 차원·memory budget 설계
- **중간~높은 충돌**: projection+quantization+단계적 정밀화는 이미 존재
- 남는 차이: 얼굴 open-set threshold, FPIR/DIR, candidate miss와 compression decision error 분리, 실제 cold DB fallback 비용

## 10. LocalScore: Local Density-Aware Similarity Scoring for Biometrics (2026-preprint 미발매)

*현재 상태: arXiv preprint, 2026 · [arXiv:2602.01012](https://arxiv.org/abs/2602.01012) · 2026-07 현재 정식 출판·동료심사 확인 불가*

### Abstract

Multi-sample gallery를 하나의 class center로 축약하면 identity 내부의 pose·조명·viewpoint cluster를 잃는다. LocalScore는 gallery feature distribution의 k-th nearest similarity를 추가 신호로 사용해 open-set score를 보정한다.

### Introduction

Non-mated probe가 class center에는 가깝지만 실제 gallery sample cluster에서는 멀 수 있다. LocalScore는 probe가 실제 gallery neighborhood에 얼마나 가까운지 반영한다. 큰 `k`는 부적절한 이웃을 포함할 수 있어 성능이 낮아졌으며 주요 실험에서는 작은 `k`, 특히 `k=1`이 안정적이었다.

Per-media gallery feature를 유지해야 하므로 class center만 저장하는 방식보다 추가 저장비용이 생길 수 있다.

### Conclusion

얼굴·보행·person re-identification에서 여러 backbone과 loss에 걸쳐 성능을 개선했다. 보고된 예시에서는 FNIR@FPIR이 53%에서 40%로 감소하고 TAR@FAR이 51%에서 74%로 증가했다. 현재는 preprint 결과로 해석해야 한다.

### 나의 연구와 관련하여 참고가능 한 부분

- class mean, score averaging, LocalScore의 직접 baseline 비교
- 압축 전후 local neighborhood 왜곡 분석
- per-media storage와 계산비용 측정
- **부분 충돌**: local density score 보정 자체는 novelty로 주장할 수 없음

## 11. DAM: Discrepancy Alignment Metric for Face Recognition (2021-iccv)

*정식 출판: ICCV, 2021 · [공식 논문](https://openaccess.thecvf.com/content/ICCV2021/html/Liu_DAM_Discrepancy_Alignment_Metric_for_Face_Recognition_ICCV_2021_paper.html)*

### Abstract

ArcFace·CosFace·triplet 계열 loss는 positive와 negative score의 상대적 차이를 최적화하지만, verification에서는 absolute cosine score를 thresholding한다. DAM은 각 얼굴의 Local Inter-class Discrepancy(LID)를 이용해 similarity를 정규화한다.

### Introduction

Figure 1은 threshold와 margin이 같다는 뜻이 아니다. 같은 positive–negative margin을 가진 identity라도 absolute score 위치가 다르면 고정 threshold에서 결과가 달라질 수 있음을 보인다.

- reference-based LIDE: anchor/reference set의 neighbor로 LID 추정
- learning-based LIDE: regression module로 LID 예측
- 학습 reference의 다양성을 위해 실제 sample 또는 GAN 생성 얼굴 활용

### Conclusion

DAM은 backbone이나 training loss를 바꾸지 않고 적용 가능한 plug-and-play metric이며 여러 얼굴인식 benchmark에서 cosine score를 개선했다.

### 나의 연구와 관련하여 참고가능 한 부분

- local difficulty 기반 cosine calibration의 직접 baseline
- gallery neighbor discrepancy feature 설계
- 압축 전후 DAM score 안정성 비교
- **부분 충돌**: local discrepancy calibration을 단독 novelty로 주장할 수 없음

## 12. Explanation of Face Recognition via Saliency Maps (2023-cbmi)

*원 메모 표식: 2023-cbmi · 확인된 정식 출판: Applications of Digital Image Processing XLVI, SPIE, 2023 · DOI [10.1117/12.2677353](https://doi.org/10.1117/12.2677353) · [공식 서지](https://infoscience.epfl.ch/entities/publication/4bde30e3-8d09-4fcf-b05d-e9198eba095f)*

### Abstract

얼굴인식 모델이 왜 특정 face pair를 match/non-match로 판단했는지 설명하기 위해 similarity-based RISE(S-RISE)를 제안한다. S-RISE는 face-pair similarity에 기여한 영역을 saliency map으로 나타내고 explanation reliability를 평가한다.

### Introduction

분류 saliency는 class logit을 설명하지만 얼굴인식은 두 얼굴의 similarity를 설명해야 한다. S-RISE는 한 얼굴에 random mask를 적용하고 고정된 얼굴인식 모델의 pair cosine similarity를 mask weight로 누적한다.

*(두 얼굴이 왜 같은 사진인지 또는 다른 사진인지 기준이 모호하다는 뜻 → 두 얼굴의 similarity 결정에 기여한 픽셀 영역을 pair-conditioned 방식으로 설명한다는 뜻)*

원 메모의 “Grad-CAM을 사용한다”는 해석은 올바르지 않다. **S-RISE는 gradient가 아니라 perturbation 기반 방법**이다.

### Conclusion

S-RISE는 saliency map과 Deletion/Insertion 계열 평가를 제안했다. 정식 SPIE판은 설명 기본값을 500 masks로 기술하고 10·100·500·1000 masks를 비교한다. 원 메모가 참고한 CBMI 표기본은 1000회 설명을 사용하지만, 확인 가능한 정식 venue는 CBMI가 아니라 SPIE다.

### 나의 연구와 관련하여 참고가능 한 부분

- pair-conditioned saliency의 직접 선행연구
- Grad-CAM saliency가 실제 similarity 설명인지 검증하는 S-RISE baseline
- landmark 영역별 saliency 집계와 occlusion faithfulness 평가
- saliency가 동일 query–candidate compression residual을 추가 예측하는지 검증
- **부분~높은 충돌**: face-pair spatial evidence 자체는 이미 제안됐으므로 단독 novelty가 아님

- quantization error로 score를 보정한다.
- local density를 사용한다.
- 불확실하면 원본으로 정밀화한다.
- face-pair saliency를 만든다.

가장 방어 가능한 연구 중심은 다음과 같다.

> 압축 ArcFace 임베딩의 1:N open-set PostgreSQL/pgvector 검색에서 ANN candidate miss와 후보 집합 내 compression decision error를 분리하고, FPIR·DIR 및 hot/cold 접근비용 제약 아래 accept/reject/defer와 선택적 origin fallback을 평가한다.

| 용어 | 간단한 의미 |
|---|---|
| **Gallery** | 시스템에 등록된 identity와 얼굴 template 집합 |

| **Non-mated probe** | probe identity가 gallery에 존재하지 않음 |

| **Unknown unknown** | 학습과 gallery에서 모두 보지 못한 identity |
| **Genuine score** | 동일인 pair의 유사도 점수 |
| **Impostor score** | 서로 다른 사람 pair의 유사도 점수 |
| **Verification** | 두 얼굴 또는 주장된 identity가 같은지 판단하는 1:1 문제 |

| **FPIR** | non-mated probe를 gallery identity로 잘못 식별·수락한 비율 |

| **DIR** | mated probe를 지정 rank 안에서 올바르게 식별하고 threshold 이상으로 수락한 비율 |
| **TAR/TPR** | 실제 positive 또는 동일인 trial을 올바르게 수락한 비율 |
| **FAR/FMR** | 1:1 non-match trial을 동일인으로 잘못 수락한 비율. 1:N의 FPIR과 구분 |
| **Rank-K** | 정답 identity가 상위 K개 검색 결과에 포함되는 조건 또는 비율 |
| **ANN/AKNN** | 근사 최근접 이웃 / 근사 K-최근접 이웃 검색 |
| **Recall@K** | exact 기준의 정답 또는 이웃이 ANN 상위 K개에 포함된 비율 |
| **PQ** | 벡터를 subspace별 codebook index로 양자화하는 방법 |
| **OPQ** | 회전을 학습해 PQ distortion을 줄이는 방법 |
| **ADC** | query는 원본으로 두고 양자화된 database code와 근사거리를 계산하는 방식 |
| **Intrinsic dimension** | 비선형 manifold까지 고려한 표현의 실제 자유도 |
| **A-QE** | 얼굴인식 특징의 angular quantization error |
| **LID** | DAM 문맥에서 얼굴 주변의 Local Inter-class Discrepancy |
| **DAM** | LID로 absolute cosine similarity를 보정하는 metric |
| **FIQA** | 얼굴 이미지가 인식에 적합한 정도를 예측하는 품질 평가 |
| **XFR** | 얼굴인식 결정 근거를 설명하는 Explainable Face Recognition |
| **S-RISE** | random mask에 따른 face-pair similarity 변화로 saliency를 생성하는 방법 |
| **EVM** | Extreme Value Theory로 class inclusion probability를 추정하는 open-set 방법 |
| **I-DL / RTM** | open-set identification·detection loss / 최대 negative score를 낮추는 relative-threshold loss |
| **DTW** | 길이가 다른 sequence의 정렬 경로를 찾아 비교하는 방법 |
| **KWS** | 음성에서 특정 keyword 구간을 탐지하는 작업 |
