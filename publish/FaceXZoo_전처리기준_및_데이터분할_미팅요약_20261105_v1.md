# FaceX-Zoo 전처리 기준과 데이터셋 분할 — 교수님 미팅 요약

작성일: 2026-11-05 KST. 확인 대상: 현재 FaceX-Zoo 설정·전처리 완료 기록, 공유 protocol/roles/train 목록, ronbun 소비 코드, UCFace 본문·부록.

**보고할 핵심:** UCFace의 실험 구성을 참고하고 FaceX-Zoo의 정렬 구현을 사용했다. 여기에 압축·임계값 보정 연구를 위한 역할 분할을 추가했다. 따라서 전체 설정을 ‘UCFace 완전 재현’이라고 표현하지 않는다.

## 1. VGGFace2 전처리는 무엇을 기준으로 했는가?

| 항목 | 현재 적용 | 근거·구분 |
|---|---|---|
| 사전학습 데이터 | VGGFace2 공식 training: 8,631명, 3,141,890장 | VGGFace2 제공 자료와 현재 학습 목록. 이 정확한 목록을 UCFace 저자가 사용했다고 확인한 것은 아님 |
| 얼굴 위치 정보 | 제공된 5개 landmark: 양 눈, 코, 양 입꼬리 | VGGFace2 `bb_landmark.tar.gz` 안의 `loose_landmark_train.csv` |
| 정렬·crop 구현 | FaceX-Zoo 원본 `FaceRecImageCropper`로 similarity transform 및 warp | **FaceX-Zoo 기준**. 별도 얼굴 검출기를 다시 실행하지 않음 |
| 모델 입력 크기 | 112×112 | **UCFace 부록 Augmentations에 명시** |
| 보간·경계·색상 | warpAffine 기본 linear, 검은 경계, BGR | FaceX-Zoo 구현·현재 저장된 policy |
| 입력 정규화 | `(pixel - 127.5) / 128` | FaceX-Zoo에 맞춘 loader 설정. PNG 저장과 모델 입력 시 정규화는 별도 단계 |

교수님께 전달할 문장:

> VGGFace2는 제공된 5점 landmark와 FaceX-Zoo의 ArcFace 정렬 코드를 이용해 112×112로 전처리했습니다. 입력 크기는 UCFace 논문에 맞췄고, 논문에서 구체적으로 확인되지 않는 정렬 세부 구현은 FaceX-Zoo 기준을 적용했습니다. 따라서 UCFace의 전처리를 완전히 동일하게 재현했다고 주장하지는 않습니다.

현재 전처리 `report.json`은 `completed=true`, 처리·준비 3,141,890장, 실패 0장을 기록한다. 이번 점검은 해당 완료 기록·설정·코드의 확인이며, 전체 이미지를 다시 decode한 검사는 아니다. 전처리 완료와 parent 모델 학습 완료는 별개다.

TinyFace·SurvFace·SCFace의 현재 학습 전처리 정책은 제공된 얼굴 crop 전체를 bicubic으로 112×112 resize하는 방식이다. 이 단계에서 재검출·5점 재정렬을 하지 않는다. 이는 사용자와 합의한 저해상도 crop 처리 정책이며, UCFace 저자의 세부 정렬 방식과 동일하다고 검증된 것은 아니다. 학습 중 회전·scale augmentation도 사전 landmark 정렬과 구분한다.

## 2. 데이터셋별로 어떻게 나누었는가?

FR은 얼굴인식 모델 학습, gallery는 등록 얼굴, probe는 검색 질의 얼굴을 뜻한다. PCA/PQ는 압축기 학습이다. 아래는 현재 입력 목록과 코드의 구성이지, 모든 모델과 평가가 완료되었다는 뜻이 아니다.

| 데이터셋 | FR 학습 | 보정·압축기 학습 | 최종 평가 |
|---|---|---|---|
| VGGFace2 | Parent: 8,631명 / 3,141,890장 | 이 workflow의 임계값 보정용으로 사용하지 않음 | VGGFace2 test를 이번 주요 평가에 사용하지 않음. 별도 95:5 validation 분할 없음 |
| TinyFace | Fine-tune: 2,570명 / 7,804장 | 같은 training set을 PCA/PQ 학습에 사용. 별도 fit/safety 없음 | Gallery 4,443장, probe 3,728장, distractor 153,428장. Rank 기반 평가 |
| SCFace | Fine-tune: 50명 / 800장 | 같은 50명 / 800장을 PCA/PQ 학습에 사용. 별도 fit/safety 없음 | 나머지 80명. Gallery 80장, probe 1,200장. 촬영 거리별 rank 평가 |
| SurvFace | Fine-tune: 4,255명 / 176,205장 | FR 내부 PCA/PQ 1,255명 / 52,227장. FR에서 제외한 fit 744명 / safety 320명 | Gallery 60,294장, 등록 probe 60,423장, 미등록 probe 121,736장. 1:N FPIR·TPIR@20 |
| LFW | FR 학습 없음 | 다른 학습 데이터셋에서 맞춘 PCA/PQ 재사용. Test fold 외 pair로 fit/safety 구성 | 공식 6,000 pairs, 10 folds. 1:1 TAR/FMR |
| RFW | FR 학습 없음 | 다른 학습 데이터셋에서 맞춘 PCA/PQ 재사용. 그룹·fold별 fit/safety 구성 | 4개 그룹 각각 6,000 pairs, 총 24,000 pairs. 1:1 TAR/FMR |

### SCFace: 50명/80명은 같지만, 인물 명단은 연구자가 고정

전체 130명에서 seed 8972로 50명을 학습용으로 고정하고 나머지 80명을 평가에 사용한다. UCFace 부록의 학습 50명·800장 / 평가 80명·gallery 80장·probe 1,200장과 **규모는 일치**한다. 저자가 선택한 정확한 50명 명단과 동일하다는 근거는 없다.

- 학습: 1명당 정면 사진 1장 + 가시광 카메라 5대 × 거리 3개 = 16장. 50명 × 16장 = 800장.
- 평가: 80명의 정면 사진 각 1장이 gallery. 80명 × 5대 × 3거리 = 1,200장이 probe.
- 거리 d1/d2/d3은 각각 4.2m/2.6m/1.0m이며, 거리당 probe 400장이다.
- 학습에는 정면 사진도 포함되므로 ‘800장 모두 저해상도 감시 영상’이라고 표현하지 않는다. 현재 구성은 가시광 카메라를 사용한다.

### SurvFace: 공식 학습 pool에서 연구용 보정 집합을 분리

공식 training pool은 **5,319명 / 220,888장**이다. 현재는 다음과 같이 나눴다. 분할 seed는 8972이며, 기존 development/calibration 인물 배정 목록을 고정해 사용한다.

| 공식 training pool 내부 역할 | 인물 수 | 이미지 수 | FR fine-tune 사용 |
|---|---:|---:|---|
| PCA/PQ development | 1,255 | 52,227 | 사용 |
| 보정 gallery | 3,000 | 61,433 | 사용 |
| 보정 등록 probe | 위 gallery와 같은 3,000명 | 62,545 | 사용 |
| 보정 fit: 미등록 probe | 744 | 33,754 | 제외 |
| 보정 safety: 미등록 probe | 320 | 10,929 | 제외 |

따라서 FR 학습은 **1,255 + 3,000 = 4,255명 / 176,205장**, FR에서 제외한 보정 인물은 **744 + 320 = 1,064명 / 44,683장**이다. PCA/PQ 1,255명은 FR 학습 4,255명의 부분집합이므로 두 수를 다시 더하지 않는다. fit과 safety는 인물 단위 hash로 약 70:30 배정한다. 실제 인물·이미지 수가 정확한 70:30은 아니다.

보정 gallery와 보정 등록 probe는 같은 3,000명의 서로 다른 이미지이며, **둘 다 FR 학습에 사용된 이미지**다. fit/safety의 미등록 인물은 FR 학습과 분리되어 있다. 따라서 ‘보정 데이터 전체가 FR 모델이 보지 못한 인물’이라는 설명은 틀리다. safety는 임계값의 별도 보정 단계이며 수학적 FPIR 보장을 뜻하지 않는다.

최종 test는 다음과 같다.

| 최종 test 역할 | 인물 수 | 이미지 수 |
|---|---:|---:|
| Gallery | 3,000 | 60,294 |
| 등록 probe | Gallery와 같은 3,000명 | 60,423 |
| 미등록 probe: identity label 있음 | 2,319 | 93,260 |
| 미등록 probe: identity label 없음 | 확인 불가 | 28,476 |
| 미등록 probe 합계 | 위 두 행의 합계; 총 고유 인물 수는 확인 불가 | 121,736 |

미등록 probe 121,736장 전체를 ‘2,319명의 이미지’라고 설명하지 않는다. identity가 없는 28,476장의 고유 인물 수는 확정하지 않는다. 학습·fit·safety·test의 분리는 확인 가능한 native identity label을 기준으로 점검했다.

이 구성은 UCFace의 5,319명 전체 fine-tune 설정에 보정용 holdout을 추가한 **우리 연구의 변경**이다. 학습 인물 수가 달라지므로 UCFace 논문 성능표와 완전히 같은 조건의 재현 성능이라고 직접 비교하지 않는다.

### LFW·RFW: 공식 test pairs 유지, 보정 절차는 연구자가 추가

각 test fold는 600 pairs = 동일인 300 + 타인 300으로 유지한다. 나머지 9 folds의 5,400 pairs에서 test 인물이 등장하는 pair를 제거한 뒤, 인물을 seed 8972의 약 70:30 hash 배정으로 fit/safety에 나눈다. 두 인물이 서로 다른 역할에 배정된 pair는 보정에서 제외한다. test pairs는 이 과정에서 제거하지 않는다.

현재 파일과 코드를 실행해 얻은 fold별 실제 보정 규모는 다음 범위다. 이는 10개 fold의 최솟값–최댓값이며 합계·신뢰구간이 아니다.

| 데이터셋·그룹 | Fit pairs 범위 | Safety pairs 범위 | 매 fold test pairs |
|---|---:|---:|---:|
| LFW | 3,108–3,192 | 1,031–1,102 | 600 |
| RFW African | 2,308–2,411 | 756–816 | 600 |
| RFW Asian | 1,896–2,130 | 712–797 | 600 |
| RFW Caucasian | 2,208–2,302 | 831–883 | 600 |
| RFW Indian | 2,276–2,339 | 789–836 | 600 |

이번 LFW 목록은 fold 간 pair 등장 인물이 이미 분리되어 test 인물 제거 건수가 0이다. RFW는 test 인물 제거와 fit/safety 교차 pair 제외 때문에 보정 pair 수가 더 줄어든다. LFW·RFW에서 FR을 재학습하지 않으며, PCA/PQ도 해당 FR 모델의 학습 데이터셋에 지정된 development에서 학습한 것을 사용한다. ‘공식 pair 평가’와 ‘추가한 보정·압축 실험’은 구분해 명명한다.

## 3. 논문과 같은 부분·다른 부분

| 항목 | 보고 가능한 설명 |
|---|---|
| 사전학습 후 저해상도별 후속학습 | UCFace의 큰 실험 구조를 참고. 각 데이터셋의 학습·평가 역할을 분리 |
| 입력 112×112, MobileFaceNet 1,024D | UCFace 명시 조건을 참고 |
| VGGFace2 landmark 정렬 | 제공 landmark + FaceX-Zoo 구현. UCFace 저자의 정확한 정렬 세부와 일치 여부는 미확인 |
| SCFace 50명/80명 | 규모 일치. 정확한 인물 명단은 연구자 고정 |
| TinyFace | 배포된 training/testing 및 MATLAB 목록을 사용. 추가 fit/safety 없음 |
| SurvFace | 공식 training pool 내부에 우리 연구의 fit/safety holdout을 추가하여 FR 학습 인물 수가 감소 |
| LFW/RFW fit/safety, PCA/PQ | 우리 압축·임계값 보정 연구를 위해 추가한 절차 |
| 데이터셋 간 parent 인물 중복 | VGGFace2와 후속 평가 데이터셋 사이 인물 중복은 미감사. 완전 비중복이라고 주장하지 않음 |

논문 표와 배포 목록의 집계 차이도 확인했다.

1. **TinyFace:** UCFace 부록 Table IX는 probe를 2,569명으로 표기한다. 현재 배포 `probe_img_ID_pairs.mat`에는 3,728행·고유 ID 2,563개가 있으며, 현재 roles도 이에 일치한다. Gallery는 4,443장·2,569명이다. 표의 인물 수를 맞추려고 현재 목록을 바꾸지 않았다.
2. **SurvFace:** 부록 Table IX는 probe 60,294 / gallery 60,423으로 적혀 있다. 현재 배포 MATLAB 파일은 `gallery_img_ID_pairs.mat` 60,294행 / `mated_probe_img_ID_pairs.mat` 60,423행이며, 현재 roles도 배포 파일과 일치한다. 이 보고서는 배포 파일의 역할을 기준으로 적었다. 저자의 실제 실행 목록까지 확인한 것은 아니다.

## 4. 교수님께 바로 전달할 요약

> 이번에는 성능 수치보다 실험 입력과 데이터 역할을 명확히 정리했습니다. VGGFace2는 공식 5점 landmark와 FaceX-Zoo 정렬 코드로 112×112 전처리를 완료했습니다. TinyFace는 배포 분할을 사용하고, SCFace는 UCFace와 같은 50명 학습·80명 평가 규모로 인물 명단을 고정했습니다. SurvFace는 임계값 보정을 위해 공식 학습 인물 5,319명 중 1,064명을 별도로 남겨, 얼굴인식 모델에는 4,255명만 학습하도록 구성했습니다. LFW와 RFW는 모델 학습용이 아니라 1:1 검증용입니다. 따라서 UCFace를 참고한 기준 모델에 우리 압축·보정 연구의 분할을 추가한 설정으로 보고하려고 합니다.

우선 논의할 사항은 **SurvFace를 압축된 1:N 검색의 주요 FPIR·TPIR 평가로 두고, TinyFace·SCFace의 rank 평가와 LFW·RFW의 1:1 검증을 보조 근거로 두는 역할 배치**, 그리고 **SurvFace 보정 gallery/등록 probe가 FR 학습에 사용된 구성의 적절성**이다. 현재 분할을 모든 역할이 FR 학습과 완전히 분리된 설정으로 표현하면 안 된다.
