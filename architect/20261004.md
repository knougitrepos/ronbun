상태: 구현됨 / 단위·회귀·새 커널·실제 40-job 실행 검증됨. 전체 800-job 연구 결과가 완료되었다는 뜻은 아니다.

## 배경과 이전 결정 변경

사용자는 UCFace의 LFW 평가처럼 1:1 verification 방향으로 LFW를 수정하도록 요청했다.
본문 §IV-A의 open-set verification과 보충자료 §II-A의 6,000쌍 프로토콜을 기준으로 한다.
closed-set identification으로 이름을 바꾸는 작업이 아니다. 보충자료에 명시되지 않은
UCFace의 구체적 threshold 선택법·학습/전처리를 재현했다고 주장하지 않는다.

20261002의 BLUFR 공개 gallery 1,000명·calibration gallery 100명·7개 개발 비율은
LFW **기본 실행 경로에서 폐기**한다. 과거 YAML/계산 모듈/완료 artifact 및 선택 분기는 보존한다.
20261002 전체 deepfunneled resize의 명시적 FR/FIQA source는 재사용한다. 원본/PQ 각각 보정,
동일 cohort 대조, 보정/test 분리 원칙을 유지한다. SurvFace 1:N, RFW와 DB schema는 바꾸지 않는다.
노트북에 캐시된 이전 출력은 새 기본 프로토콜 결과와 혼동하지 않도록 제거하며, 원본 run/report는 유지한다.

## 확정 프로토콜

- FaceNet mirror의 LFW View-2 목록을 SHA-256으로 고정하고 실제 10 folds의 identity 비중첩을 검증한다.
  고정 SHA: `ea42330c62c92989f9d7c03237ed5d591365e89b3e649747777b70e692dc1592`.
  UCFace가 같은 mirror를 사용했다는 의미는 아니다.
- 공식 test pair는 6,000개 그대로 유지한다. 한 fold당 300 genuine + 300 impostor.
  개발 인물은 모든 pair에 한 번도 등장하지 않는 1,468명, 이미지 1,549장이다.
  개발 집합은 모델/fold/seed 사이에서 고정하며 인식기 학습에는 쓰지 않고 PQ만 적합한다.
- 한 fold를 test로, 나머지 9개 fold를 calibration 후보로 사용한다. 20 seeds의 identity hash로
  fit/safety를 분리하고 양 끝 identity가 서로 다른 partition에 속한 pair는 calibration에서 제외한다.
  test 600쌍은 제외/교체하지 않는다. 역할별 수와 제외 수·assignment hash를 기록한다.
- 기존 4모델, Origin+PQ m128/m64/m32, Global-safe/FIQA 5-bin/Continuous FIQA, 5 targets를 유지한다.
  1:1 target FMR는 .01/.05/.10/.20/.30이며 4×10×20=800 jobs다. 7개 개발 비율은 이 방향에서 폐기한다.
- 왼쪽 원본 query와 오른쪽 원본/PQ reference로 비대칭 점수를 계산한다. 품질은 왼쪽 CR-FIQA L.
  원본 cosine/PQ negative squared-L2 lookup ADC를 각자의 점수 공간에서 보정한다.
- 세 결과를 구분한다: nine-fold global accuracy-max threshold의 Accuracy, calibration-fixed FMR/TAR,
  고정 보정함수의 test curve에서 FMR ceiling 이하의 가능한 TAR. 보간이나 test fitting을 운영 결과로 섞지 않는다.
  실제 FMR/counts도 보고하며 동일 target을 실제 FMR 일치로 해석하지 않는다.

### 보존과 산출물

KEEP_RAW_RESULTS는 입력 준비·Python wrapper·노트북·CLI·평가 단계에 연결했다.
False에서는 전체 설정 모델과 FIQA의 게시·검증 및 경량 준비 요약/해석 안내 생성 후 이번 추출의 중복 SQLite를 정리한다.

재사용 population, resize, FR/FIQA, registry는 유지하는 cache/입력이며 False가 모든 생성 파일의 삭제를 뜻하지 않는다.

준비 JSON/해석 Markdown, source/FIQA 경량 manifest와 model registry는 출처 증거로 남긴다.
이번 재사용 입력 보관량은 약 612 MiB다.
