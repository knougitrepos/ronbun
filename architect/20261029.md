### 배경과 유지한 결정

20261028의 외부 공유 저장소와 두 저장소 독립성을 유지한다. FaceX-Zoo가 FR을 학습·export하고,
ronbun은 파일 계약으로 모델을 사용한다. 학습 데이터셋은 SurvFace/TinyFace/SCFace,
LFW/RFW는 실험 전용이다. 분할 인물·수량, 1024D, target-only 경계 정책과 학습 수식은 바꾸지 않는다.

선행 위험 보고서는 기존 NPY의 label 변조 재사용, RFW의 정답/인물 모순과 그룹별 fold 누락 허용,
export 두 파일 사이의 중단 후 재시도 실패를 재현했다. 최종 singleton batch에 관한 선행 판단은
정정한다. 기존 `build_dataloader`가 이미 학습 전에 거절했으며 설정 검증과 직접 batch=1 forward만으로
실제 학습 경로도 실패한다고 판단할 수 없었다.

### 결정과 데이터 흐름

1. FaceX-Zoo 목록 → `path_index_v2` cache: source/root/schema, NPY hash/행 수/dtype 및 모든
   path/label을 대조한다. 불완전·손상 cache는 중단하고 원본·기존 cache를 보존한다. 새 cache 디렉터리가
   복구 경로다. 생성 과정은 원본 목록의 임시 스냅샷을 사용하고 원본 변경을 확인하며 writer lock을 둔다.
2. FaceX-Zoo 완료 checkpoint → export: 목적지 lock 안에서 처리한다. PT/sidecar 각 파일을 원자적으로
   게시하며 둘 전체의 원자성을 주장하지 않는다. PT만 남으면 같은 source의 가중치·내장 출처를 검증한 뒤
   sidecar만 복구한다. 기존 PT와 완료 export는 기본 정책에서 덮어쓰지 않는다.
   반복 데이터 검증의 실행 receipt만 출처 비교에서 제외하며, source/config/protocol의 일치는 요구한다.
3. ronbun pair 입력: RFW 4그룹 × 10fold × 600쌍, fold별 300/300, 정답과 인물 ID 일치,
   비어 있지 않은 ID와 image/identity 대응을 추출·보정 전에 검사한다. 공식 파일의 출처 인증과는 구별한다.
4. DataLoader: 기존 최종 singleton 차단을 유지하고 batch_size 입력 검증/메시지를 보완한다.
   샘플 삭제·batch 병합·학습 조건 변경을 자동으로 수행하지 않는다.

### 영향받는 파일과 재실행 범위

- FaceX-Zoo: `fine-tune/modules/input_pipeline.py`, `dataset.py`, `checkpoint_manager.py`,
  `notebook_workflow.py`, 관련 tests와 `fine-tune/README.md`.
- ronbun: `research/protocols/facex_handoff.py`, 회귀 테스트, `notebooks/WORKFLOW_GUIDE.md`.
- DB schema, raw 이미지, 공유 protocol, 기존 완료 run은 수정하지 않는다.
- 커널 재시작 후 실행한다. v1 cache는 재사용하지 않고 새 schema cache를 만든다.
  ronbun의 코드 fingerprint가 바뀌므로 새 실행은 새 입력/결과 UID를 사용한다.
  기존 정식 실험을 이 감사만을 이유로 소급 재실행하거나 덮어쓰지 않는다.

### 검증 기준과 남은 범위

유효한 label 범위 내의 손상도 거부하고, export 두 번째 게시 실패 후 동일 파일을 복구하며,
서로 다른 가중치·출처의 복구를 거부해야 한다. 실제 notebook export 재시도, 독립 consumer 로딩,
기존 학습/재개 테스트를 함께 확인한다. 테스트는 정식 연구 성능 결과가 아니다.

작은 calibration tail 표본, SurvFace calibration gallery의 FR-seen 조건, 부모 identity overlap은
코드 결함 수정으로 사라지지 않는다. 해석 안내를 강화하되 임의 데이터 재분할은 하지 않는다.
정식 모델 등록과 전체 학습/평가, Linux/A100 실증은 별도 작업이다.
