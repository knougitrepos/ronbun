상태: 구현됨 / 단위·회귀 테스트 및 아래 명시적 실제 조건에서 검증됨.
기준: step11, HEAD ec9d7f2dafecc3b4f636ba2f8df29a4e78595e28 + 현재 변경.

## 배경과 결정

20260908의 FIQA 동일 split 진단과 genuine-score-topk-v2 정의는 유지한다.
그 문서에서 FIQA 진단에만 있던 mated identity-cluster CI를 공통 평가로 확장한다.
원본 대비 압축 TPIR의 점추정치를 바꾸는 작업이 아니라, 동일 인물의 여러 query가
독립적이지 않을 수 있다는 점을 반영하는 불확실성 보강이다.

- 기존 Wilson 및 query-paired bootstrap 열·의미·값은 유지한다.
- 원본/압축 TPIR와 압축−원본 차이에 `*_tpir_at_rank_k_identity_cluster95_low/high`를 추가한다.
- 2,000회, seed 42, 양측 percentile 95%. 모든 방법에 같은 identity 가중치를 사용한다.
- 각 draw에서 성공 query 수 / 전체 query 수를 계산한다. 인물별 TPIR의 단순 평균으로 바꾸지 않는다.
- `tpir_rank=20`인 행의 해당 열이 TPIR20 CI다. 다른 K를 TPIR20로 부르지 않는다.
- `tpir_cluster_ci_status=ok`만 사용한다. label 미제공, mated 0개, cluster 1개는 NaN과 사유를 기록한다.
  빈 문자열/null/비이진 사건 등 잘못된 입력은 오류로 중단한다.
- FPIR은 query 단위 유지. SurvFace unknown probe의 임시 ID를 실제 인물 ID로 간주하지 않는다.
- threshold/gallery 고정, calibration 재적합·분할 변동·다중 비교·모델 재학습은 포함하지 않는다.
  사건이 없거나 전부 같은 경우 percentile CI가 퇴화할 수 있으며 위험 0 보장이 아니다.
