# 2026-10-08 — MobileFaceNet 512D FR 베이스라인 재현 학습 및 SurvFace 4-Role Identity 격리 체계 구축

## 2026-10-08 23:00 KST — UCFace 재현용 MobileFaceNet 512D 베이스라인(ArcFace, AdaFace, MagFace)과 SurvFace 무누출 프로토콜 아키텍처

상태: 구현됨·검증됨 (단위/통합 테스트 통과). 실제 대규모 전체 40-epoch 학습 캠페인은 미실행 (코드베이스, 프로토콜 분할, 런북, 대화형 노트북 구축 완료).

### 변경 배경

1. **UCFace 논문 및 저자 공식 회신 반영**:
   - UCFace (IEEE T-IFS 2024, DOI: [10.1109/TIFS.2024.3426973](https://doi.org/10.1109/TIFS.2024.3426973))는 경량 백본인 **MobileFaceNet**을 공통 아키텍처로 채택하고, 대표 얼굴인식(FR) 손실 함수인 ArcFace, AdaFace, MagFace를 VGGFace2 사전학습 후 QMUL-SurvFace 학습 데이터로 미세조정(Fine-Tuning)하여 비교함.
   - UCFace의 제안 손실함수(UCFace loss, uncertainty module, contrastive projection head)는 연구 범위 외이므로 제외하고, **동일 백본·동일 레시피 하의 정직한 베이스라인 재현 파이프라인**을 구축함.
2. **512D 임베딩 차원 고정**:
   - UCFace 원문 표기의 1024D 대신 저장소 전반의 공통 계약인 512D 임베딩을 유지함. 이는 기존 PostgreSQL/pgvector 스키마, PQ 코덱($m=128, 64, 32$), LFW/RFW/SurvFace/TinyFace 평가 계약과의 100% 호환성을 보장하기 위함임.
3. **SurvFace Identity 누출(Identity Leakage) 원천 차단**:
   - SurvFace `training_set`은 총 5,319명의 인물(220,888장)로 구성됨.
   - 기존 `training_3000_half_gallery_v2` 프로토콜은 5,319명 전원(갤러리 3,000명 + 비등록 프로브 2,319명)을 사후 임계값 보정 풀로 소진하였으므로, 이 상태에서 SurvFace 전체로 FR 백본을 미세조정하면 1:N 보정 시 심각한 인물 누출이 발생함.
   - 기존 완료 run의 불변 매니페스트(`training_manifest.csv`)를 훼손하지 않으면서, 새로운 4-Role 무누출 매니페스트(`training_manifest_v2_finetune.csv`)를 도입해야 함.

### 결정 (Architectural Decisions)

1. **공통 MobileFaceNet 512D 백본 아키텍처 확립**:
   - InsightFace 및 FaceX-Zoo의 검증된 표준 토폴로지 채택:
     - FaceX-Zoo 소스 커밋 고정: `ba50bce7bb0811e9f13883a48e7e1ddc44566c75` ([JDAI-CV/FaceX-Zoo](https://github.com/JDAI-CV/FaceX-Zoo/tree/ba50bce7bb0811e9f13883a48e7e1ddc44566c75))
     - 입력 $112 \times 112 \times 3$, BGR 컬러 순서, $[-1.0, 1.0]$ 스케일링 전처리 계약 통일 (`FRDataset` 및 `ModelSpec` / `adapter.py` 100% 일치)
     - 채널 전개: $3 \to 64 \to 64 \to 64 \to 128 \to 128 \to 512 \to 512$
     - GDC (Global Depthwise Conv $7 \times 7$) + Flatten + Dropout(0.6) + Linear(512, 512, bias=False) + BatchNorm1d(512)
     - 총 파라미터 수: 1,200,512개 (~1.2M), 특징 출력: $(B, 512)$ pre-norm 텐서.
2. **3대 마진 손실 함수 분류기 구현**:
   - **ArcFace**: $m = 0.6, s = 64.0$, $\cos(\theta + m)$ 각도 마진 및 $\theta + m > \pi$ 경계 연속성 처리.
   - **AdaFace**: $m = 0.4, s = 64.0, h = 0.333$, 배치 특징 노름 그래디언트 차단(`safe_norms.clone().detach()`)을 통한 품질 추정 안정화, 배치 특징 노름 지수이동평균(EMA $\mu_z, \sigma_z$) 추적(단일 샘플 $N=1$ 시 std NaN 분기 보호), 화질 적응형 각도/가산 마진 $g_{\text{angle}} = -m \hat{n}, g_{\text{add}} = m \hat{n} + m$.
   - **MagFace**: $l_a = 10.0, u_a = 110.0, l_m = 0.45, u_m = 0.8, \lambda_g = 20.0, s = 64.0$, 특징 크기 기반 동적 마진 $m(a_i)$ (마진 연산 시 $a_i$ detach 적용) 및 크기 정규화 손실 $g(a_i) = 1/a_i + a_i / u_a^2$.
3. **SurvFace 4-Role Identity 분할 계약**:
   - 총 5,319개 인물을 결정론적 기준 시드(8972, 저장소 시드 마이그레이션 정책 준수)로 4개 상호 배타적 세트로 분할:
     - `train`: 1,600 인물 (FR 미세조정 분류기 학습)
     - `val`: 219 인물 (FR 미세조정 조기종료 및 손실 수렴 검증)
     - `calib_gallery`: 3,000 인물 (1:N 갤러리/Watchlist 사후 보정)
     - `calib_probe`: 500 인물 (1:N non-mated 탐색 사후 보정)
   - 분할 검증: $\text{train} \cap \text{val} = \emptyset$, $(\text{train} \cup \text{val}) \cap (\text{calib\_gallery} \cup \text{calib\_probe}) = \emptyset$, $\text{calib\_gallery} \cap \text{calib\_probe} = \emptyset$.
   - 총합: $1,600 + 219 + 3,000 + 500 = 5,319$ (100% 매핑, 누출 0%).
   - 매니페스트: `data/manifests/training_manifest_v2_finetune.csv`.
4. **엄격한 체크포인트 내보내기/다중 헤드 복제 계약**:
   - `build_fr_baseline_model(..., pretrained_backbone=...)`: 동일 사전학습 가중치를 ArcFace, AdaFace, MagFace에 비트 단위로 동일하게 복제하여 3갈래 분기.
   - `export_backbone_checkpoint`: 학습 모듈에서 분류기 헤드를 안전하게 제거하고 순수 백본 가중치만을 `{"state_dict": ..., "state_dict_backbone": ...}` 구조로 저장.
   - 공식 로더 `load_mobilefacenet_checkpoint`, `load_arcface_checkpoint`, `load_adaface_checkpoint`, `load_magface_checkpoint`에서 100% 왕복 로드 가능 여부를 내보내기 시점에 즉시 검증(`verify_load=True`).
5. **하드웨어 제약 및 VRAM 관리**:
   - NVIDIA GeForce GTX 1080 Ti (11GB VRAM) 환경을 위해 **Micro-batch 32 + Gradient Accumulation 2회** (실효 배치 64) 기본 적용.
   - `KEEP_RAW_RESULTS` 제어: `False` 설정 시 중간 에포크 체크포인트를 자동 정리하여 C 드라이브 저장 공간 절약. 남은 누적 배치 그래디언트의 자동 flush 보장.
