## 1. 핵심 결론

현재 코드는 이전의 좁은 `ADC 대 reconstruction` 비교를 실제로 다음 연구 질문으로 확장했다.

> 동일 gallery PQ code budget에서 query representation과 scoring/normalization 조건이 1:N open-set face identification의 ranking ceiling, threshold-constrained decision loss, target-FPIR validity 및 저장 효율에 어떤 영향을 주는가?

Origin, 양쪽 PQ reconstruction cosine, one-sided cosine, ADC와 SDC가 모두 구현됐고, cosine과 ADC/SDC의 threshold 정책도 score-space별로 분리됐다. 따라서 이전 비교의 가장 큰 confounding이었던 `query precision`과 `scoring rule`을 상당 부분 분해할 수 있다.

이 연구의 성격은 다음과 같다.

- 새 얼굴인식 backbone: 아님
- 새 PQ·ADC·SDC 알고리즘: 아님
- 새 calibration 알고리즘: 아님
- 강점: **deployment-aware applied/system characterization, open-set operating-point evaluation, 재현 가능한 실험 계약**
- algorithm novelty: 낮음
- evaluation/system novelty: 중간
- technical rigor: 중상~높음
- 재현성 잠재력: 높음

따라서 가장 현실적인 국제 게재 수준은 다음과 같이 판단한다.

1. **IEEE Access:** 가장 현실적인 journal 목표, 조건부 게재 가능성 `40~55%`
2. **IEEE FG / ICPR / ICIP:** 현실적인 국제 main-conference 목표, 대략 `20~40%` 범위
3. **IJCB:** 주제 적합성은 매우 높지만 biometrics novelty와 표준 protocol 요구 때문에 도전적, `15~30%`
4. **IEEE T-BIOM / WACV applications:** 의미 있는 상향 도전, `10~25%`
5. **Pattern Recognition:** 새 일반 방법 없이 현재 characterization만으로는 낮음, `5~10%`
6. **CVPR / ICCV / ECCV main, TPAMI:** 현재 core만으로는 매우 낮음, 대략 `1~5%`

이 수치는 공식 acceptance probability가 아니라, 완성된 원고의 기여 형태와 venue 심사 성격을 비교한 **주관적 조건부 연구-fit 구간**이다. IEEE Access가 공식적으로 제시하는 평균 acceptance rate 약 20%와 혼동하면 안 된다.

`research/compression/profiles.py`에는 `search_sdc`와 `search_sdc_with_metrics`가 구현돼 있다.

- 8-bit paper setting: Faiss native `ProductQuantizer.search_sdc`

SDC는 새 방법이 아니라 `ADC 대 SDC`에서 squared-L2 조건의 query compression penalty를 확인하는 control이다.

ADC와 SDC에는 `recalibrated_compressed`만 허용하므로 origin cosine threshold를 다른 score space에 잘못 재사용하지 않는다.

## 3. 수학적 기여 경계

원본 query와 gallery를 `q`, `g`, PQ encode/decode reconstruction을 `Q(x)=D(E(x))`라 둔다.

### Origin cosine

\[
s_{OO}^{cos}=\cos(q,g)
\]

### One-sided cosine

\[
s_{OQ}^{cos}=\cos(q,Q(g))
\]

### ADC

\[
s_{OQ}^{ADC}=-\lVert q-Q(g)\rVert_2^2
\]

### Both-reconstruction cosine

\[
s_{QQ}^{cos}=\cos(Q(q),Q(g))
\]

### SDC

\[
s_{QQ}^{SDC}=-\lVert Q(q)-Q(g)\rVert_2^2
\]

방법 `m`의 정답 identity rank를 `r_i^m`, genuine score를 `s_i^{+,m}`, score-space별 threshold를 `\tau_m(\alpha)`라 두면:

\[
R_{20}^{m}=\frac{1}{|M|}\sum_{i\in M}\mathbf 1[r_i^m\le20]
\]

\[
TPIR_{20}^{m}(\tau_m)=\frac{1}{|M|}\sum_{i\in M}
\mathbf 1[r_i^m\le20\land s_i^{+,m}\ge\tau_m]
\]

압축 손실은 다음처럼 분리할 수 있다.

\[
L_{rank}^{m}=R_{20}^{OO}-R_{20}^{m}
\]

\[
L_{decision}^{m}=R_{20}^{m}-TPIR_{20}^{m}(\tau_m)
\]

- `L_rank`: threshold 재보정으로 회복할 수 없는 ranking ceiling 손실
- `L_decision`: score distribution과 FPIR 제약 아래의 threshold-constrained rejection

논문의 지식 기여는 새 수식 자체가 아니라, 이 분해를 query/gallery/scoring 조건, 압축 강도, FR system, domain과 storage에 걸쳐 검증하는 것이다.

### 독립 novelty로 주장하면 안 되는 것

- PQ, ADC 또는 SDC 자체
- ADC가 symmetric query compression보다 유리한 일반적 경향
- score-space마다 threshold를 다시 calibration하는 절차
- FPIR, TPIR20, Rank20 또는 storage를 각각 보고하는 것
- 여러 pretrained FR 모델에서 같은 benchmark를 반복한 것

### 남는 차별점

> 동일 gallery PQ budget 아래 query precision과 scoring/normalization 조건을 factorial하게 분리하고, score-space별 held-out open-set threshold에서 target-FPIR validity, ranking ceiling, decision rejection 및 gallery-amortized storage의 상호작용을 여러 pretrained FR system과 domain에서 정량화한다.

이는 MRQ식 reranking, KWS식 learned score normalization, NP/conformal guarantee를 단순 재명명한 연구가 아니다. 반대로 그러한 새 방법을 구현했다고 주장해서도 안 된다. 현재 정체성은 **rigorous empirical characterization**이다.

## 6. Venue별 현실적 평가

### 6.1 IEEE Access

**판정: 가장 현실적인 국제 journal, 게재 가능성 중간~높음.**

- 주관적 조건부 추정: **40~55%**
- 강점: applied engineering, measurement/evaluation, negative result, 재현성, 넓은 multi-domain 분석과 잘 맞음
- 약점: 새 알고리즘이 없고, `ADC advantage`와 per-space recalibration은 알려진 요소임
- 주요 rejection 문장: “The paper is technically extensive but offers limited advance beyond known PQ behavior.”
- 방어 방법: algorithm claim이 아니라 query/gallery/scoring factorial에서 새로 얻은 operational knowledge를 핵심 contribution으로 제시

IEEE Access 공식 review 절차는 clear state-of-the-art advance를 요구하고 평균 acceptance rate를 약 20%로 제시한다. 따라서 `40~55%`는 base rate가 아니라 이 연구가 완성된 상태에서의 paper-specific fit 추정이다.

### 6.2 IEEE FG / ICPR / ICIP

**판정: 현실적인 국제 main-conference 범위.**

| Venue | 조건부 추정 | 평가 |
|---|---:|---|
| IEEE FG | 25~40% | face recognition·real-world deployment와 직접 맞음. 8-page long paper에서 factorial 결과와 protocol을 압축할 수 있어야 함 |
| ICPR | 25~40% | biometrics와 pattern recognition evaluation에 적합. 새 방법보다 분석 기여를 명확하게 보여야 함 |
| ICIP | 20~35% | face biometrics·resource-efficient ML scope에 들어가지만 짧은 지면에서 넓은 실험 계약을 설명하기 어려움 |

이 세 venue는 IEEE Access보다 단순히 상위 또는 하위라고 일렬로 놓기 어렵다. journal의 완결성과 conference의 분야 커뮤니티 가시성이 다르다.

### 6.3 IJCB

**판정: 주제 fit은 최고 수준이나 현재 기여 형태로는 도전적.**

- 주관적 조건부 추정: **15~30%**
- CFP상 evaluation protocol, benchmarking, performance modeling, compact models와 large-scale identification이 직접 scope에 포함됨
- 그러나 biometric specialist reviewer는 IJB 계열 표준 protocol, identity-level uncertainty, 가장 가까운 face compression 연구와의 직접 비교를 더 엄격히 볼 가능성이 큼

### 6.4 IEEE T-BIOM / WACV applications

**판정: 의미 있는 상향 도전이지만 현재 core의 안정적 목표는 아님.**

| Venue | 조건부 추정 | 병목 |
|---|---:|---|
| IEEE T-BIOM | 10~20% | 공식 지침이 제한된 novelty와 알려진 알고리즘의 단순 결합을 immediate-rejection 후보로 명시 |
| WACV applications | 12~25% | algorithm novelty는 필수가 아니지만 systems-level innovation, domain novelty, comparative assessment가 필요 |

다음이 추가되면 이 수준의 가능성이 올라간다.

1. 실제 PostgreSQL/pgvector index size, p50/p95 latency, throughput, rebuild/migration 비용
2. IJB-C 등 표준 open-set biometric protocol
3. identity-cluster 또는 model×dataset block inference
4. reconstructed norm과 normalized-L2 equivalence diagnostic
5. 사전 지정한 safe compression frontier 또는 profile selection rule

### 6.5 Pattern Recognition / CVPR·ICCV·ECCV / TPAMI

- Pattern Recognition: **5~10%**. OPQN·SAOPQ처럼 새 학습/quantization 방법 또는 더 일반적인 methodological contribution이 필요하다.
- CVPR/ICCV/ECCV main: **1~5%**. 현재의 engineering rigor는 장점이지만 새 vision/learning method와 강한 SOTA improvement가 부족하다.
- TPAMI: **1% 미만에 가까운 매우 낮음**. 현재 characterization은 flagship theory/method 수준과 거리가 있다.

Clean provenance는 모든 venue의 필요조건이지만, 방법 novelty 부족을 자동으로 해결하지는 않는다.

## 7. 한국방송통신대학교 정보과학과 석사학위논문으로서의 가치

### 7.1 종합 판정

학생이 제1저자이고 지도교수가 교신저자이며, 학생이 문제 정의·구현·실험·통계 분석·원고 작성과 revision을 실질적으로 주도했다면 다음처럼 평가한다.

> **석사 졸업논문으로서는 매우 높은 가치가 있다. 방송대 정보과학과 내부에서는 드문 국제 peer-review 완주 사례로 평가될 가능성이 높고, 국내 박사과정 지원이나 연구개발 직무에서도 강한 독립 연구 수행 증거가 된다.**

상위 몇 퍼센트인지에 대한 공식 학과 통계는 현재 자료로 확인할 수 없으므로 숫자로 단정하지 않는다.

### 7.2 왜 가치가 높은가

이 논문은 단순히 모델을 한 번 실행한 결과가 아니라 다음 전체 연구 lifecycle을 보여 준다.

1. 기존 ADC/PQ novelty의 한계를 스스로 경계함
2. confounding을 one-sided cosine과 SDC로 해소함
3. open-set threshold와 ranking을 구분함
4. target 실패를 숨기지 않고 realized FPIR와 CI로 보고함
5. 네 pretrained system과 여러 domain에서 반복성을 확인함
6. run manifest, SHA, immutable artifact, fail-closed report를 통해 재현성을 확보함
7. 제한된 GTX 1080 Ti 환경에서 수행 가능한 연구 범위를 완결함

이것은 석사과정에서 중요한 `새로운 알고리즘 발명` 한 가지보다 더 넓은 연구 역량, 즉 연구 질문을 수정하고 반론을 실험 설계로 바꾸며 결과를 재현 가능한 형태로 닫는 능력을 보여 준다.

KNOU위클리는 정보과학과 졸업생을 포함한 SCIE Q1 논문 게재를 대학원 성과로 별도 소개했고, 좋은 논문이 대학원 평가의 의미 있는 척도가 될 수 있다는 교수 평가를 전했다. 이 근거를 고려하면 재학 중 국제 저널 게재는 학과 내부에서 가시성이 큰 성과일 가능성이 높다. 다만 IEEE Access의 특정 연도 JCR quartile은 category와 연도에 따라 확인해야 하므로, 공식 확인 없이 `Q1`이라고 홍보해서는 안 된다.

### 7.3 제1저자·교신저자 관계의 해석

- 학생 제1저자: 연구와 원고의 주도성을 나타내는 강한 신호
- 교수 교신저자: 지도, 연구윤리, 제출·revision 책임을 맡는 일반적이고 자연스러운 구조
- 저자 2인의 논문이라면 형식상 `단독 저자 논문`은 아님
- 학생이 실질적으로 대부분 수행했더라도 교수의 실제 intellectual contribution이 있다면 저자로 포함하고 CRediT 역할을 정확히 기록해야 함
- 제1저자 표기만으로 독립성이 자동 증명되는 것은 아니며 공개 code, artifact, thesis, 발표와 추천서가 이를 강화함

방송대 출신이라는 사실이 peer-review 기준을 낮추지는 않는다. 반대로 게재 후에는 제한된 연구 환경에서 국제 심사를 통과한 실행력과 자기주도성을 보여 주는 서사가 될 수 있다.

### 7.4 학위논문 가치와 국제 venue 가치를 구분

| 평가 관점 | 판단 |
|---|---|
| 석사학위논문 완성도 | 매우 높음 |
| 방송대 정보과학과 내부 희소성·가시성 | 매우 높을 가능성 |
| 국내 박사과정 지원 | 강한 실증 연구·재현성 포트폴리오 |
| 산업 R&D 지원 | 압축 검색, biometrics, evaluation engineering 역량의 구체적 증거 |
| 국제 biometrics 학문 novelty | 중간 이하: 새 알고리즘보다 characterization 기여 |
| top-tier CV 연구 신호 | 제한적: CVPR/TPAMI급 방법론 기여를 뜻하지 않음 |

즉 `석사학위논문으로 매우 우수하다`와 `세계 최상위 방법론 논문이다`는 서로 다른 판단이며 동시에 참일 필요가 없다. 현재 연구는 전자에는 강하게 해당하고 후자에는 해당하지 않는다.

## 8. 원고에서 지켜야 할 contribution 문안

### 권장 영문

> We present a deployment-aware characterization of post-hoc product quantization for 1:N open-set face search under a fixed gallery-code budget. We factor query precision and scoring/normalization using full-precision-query ADC, one-sided cosine, symmetric reconstruction cosine, and SDC controls. With held-out, score-space-specific thresholds, we quantify ranking loss, threshold-constrained decision loss, realized FPIR, TPIR@20, Rank@20, confidence intervals, and gallery-amortized storage across multiple pretrained face-recognition systems and domains.

### 피해야 할 주장

- `We propose ADC for compressed face recognition.`
- `ADC universally outperforms reconstruction.`
- `Recalibration guarantees FPIR preservation.`
- `The four models prove architecture superiority.`
- `RFW-Custom is the official RFW open-set protocol.`
- `TinyFace confirms open-set TPIR20` — custom protocol 없이 사용 금지
- storage bytes만 측정하고 `PostgreSQL search latency improved`라고 주장

## 9. 최종 추천

졸업 전 국제 journal 게재가 우선이면 **IEEE Access를 1순위로 잡는 것이 과도하게 낮은 선택이 아니다.** 현재 연구의 실제 강점인 applied characterization, rigorous evaluation, reproducibility와 잘 맞는다.

분야 커뮤니티 노출과 짧은 일정이 더 중요하면 FG/ICPR/ICIP main paper도 현실적인 선택이다. IJCB는 연구 주제와 가장 직접적으로 맞지만, standard biometric protocol과 specialist novelty 기준 때문에 Access보다 안전한 선택은 아니다.

T-BIOM이나 WACV applications는 실제 DB system evidence와 표준 open-set benchmark를 추가할 때 상향 도전 대상으로 권한다. Pattern Recognition이나 CVPR급을 목표로 한다면 현재 원고를 단순 확장하는 것이 아니라, 일반화 가능한 새 risk-constrained compression/profile-selection 방법을 별도 기여로 개발해야 한다.

## 10. 최종 논문 전에 실험으로 확인할 항목

사용자의 clean 전체 재실행 전제 아래에서도 다음 항목은 최종 표와 claim에서 확인해야 한다.

1. 모든 primary cell의 `target_met_on_test` 및 false-accept count/denominator
2. target 실패 row를 same-FPIR 우세 count에서 제외했는지
3. ADC 대 one-sided cosine, one-sided 대 both-reconstruction, ADC 대 SDC의 사전 지정 contrast
4. reconstructed query/gallery norm 분포와 cosine–normalized-L2 equivalence
5. compression-strength trend의 model×dataset block 또는 identity-cluster uncertainty
6. code payload뿐 아니라 codebook과 gallery-amortized storage
7. LFW·RFW-Custom의 repository-defined protocol 명시
8. SurvFace protocol provenance와 mated/non-mated 구성
9. SDC를 primary 방법이 아니라 supplementary ablation으로 유지
10. 실제 PostgreSQL/pgvector 결과가 없다면 database latency·throughput 개선 claim을 제거
