## 1. 종합 판정

외부 GPT 답변은 다음 핵심 방향에서는 타당하다.

1. `ADC가 threshold 숫자를 유지한다`가 아니라 score-space별 재보정 후 open-set operating point를 평가해야 한다.
2. ADC 자체를 새 방법으로 주장하면 안 된다.
3. 연구는 method novelty보다 applied characterization/evaluation paper에 가깝다.
4. Rank, TPIR/DIR, realized FPIR, threshold policy, storage를 함께 봐야 한다.
5. IEEE Access는 이와 같은 applied engineering/measurement 연구와 scope fit이 있다.

그러나 현재 코드·결과와 맞지 않거나 과장된 중요한 부분이 있다.

1. unknown-X 설명에서 current reconstruction을 `원본 새 query 대 복원 gallery cosine`처럼 기술했지만, 실제 `pq_reconstruction_cosine`은 query와 gallery를 **모두 PQ encode/decode**한다.
2. ADC와 reconstruction을 `동일 PQ budget`이라고 부르려면 **동일 gallery code budget**이라고 한정해야 한다. query information condition은 다르다.
3. ADC와 reconstruction은 query precision뿐 아니라 L2 대 cosine metric도 달라 현재 결과만으로 원인을 분리할 수 없다.
4. ADC가 여러 조건에서 operating point를 일관되게 재현했다고 표현하기에는 현재 target 실패가 남아 있다.
5. TinyFace 추가는 선택적 확장이지 우선 보강이 아니다. 새 dataset은 현재 비교의 confounding을 해결하지 않는다.
6. `reconstruction할 필요가 없다`는 것은 알려진 ADC의 system implication이며 독립 novelty가 아니다.

따라서 답변은 **방향상 타당하나, 논문 주장으로는 수정이 필요한 조건부 타당**으로 판정한다.

## 2. 문장별 주요 판정

| unknown-X에서 reconstruction은 원본 새 query 대 복원 gallery cosine | **현재 코드와 불일치** | current `pq_reconstruction_cosine`은 query와 gallery를 모두 압축·복원 |

## 3. 현재 코드가 실제로 실행하는 비교

원본 query/gallery를 \(q,g\), PQ encoder/decoder를 \(E,D\)라고 둔다.

### Origin

\[
s_{OO}=\cos(q,g)
\]

### Current reconstruction-cosine

\[
s_{QQ}^{cos}=\cos(D(E(q)),D(E(g)))
\]

`step2_compression.py:1544-1548`은 calibration query와 gallery를 모두 `_compressed_matrix`에 통과시킨다. `compare_cosine_retrieval`은 두 compressed matrix를 각각 L2 정규화한다.

### Current ADC

\[
s_{OQ}^{ADC}=-\|q-D(E(g))\|^2
\]

`profiles.py:422-424`는 query가 original float32에 남고 gallery가 PQ code로 유지된다고 명시한다.

### 외부 GPT의 unknown-X reconstruction 설명

외부 답변이 설명한 다음 방식은 current reconstruction이 아니라 추가해야 할 one-sided baseline이다.

\[
s_{OQ}^{cos}=\cos(q,D(E(g)))
\]

이 baseline은 중요하다. `one-sided cosine`과 ADC를 비교해야 query/gallery information condition을 고정한 채 metric 차이를 볼 수 있다.

## 4. 현재 결과가 실제로 보여 주는 일관성

Target FPIR 10%, `recalibrated_compressed` 40개 paired cell:

| 항목 | 결과 |
|---|---:|
| ADC TPIR20 우세 | 26/40 |
| 동률 | 9/40 |
| reconstruction 우세 | 5/40 |
| ADC target 충족 | 34/40 |
| reconstruction target 충족 | 26/40 |

Profile별:

| PQ profile | ADC 우세/동률/reconstruction 우세 | ADC target 충족 | reconstruction target 충족 |
|---|---:|---:|---:|
| M=8 | 8/0/0 | 5/8 | 2/8 |
| M=16 | 7/0/1 | 7/8 | 4/8 |
| M=32 | 5/2/1 | 7/8 | 7/8 |
| M=64 | 3/4/1 | 7/8 | 7/8 |
| M=128 | 3/3/2 | 8/8 | 6/8 |

해석:

- coarse PQ에서 ADC raw TPIR20 우세 경향은 분명하다.
- 그러나 M=8에서 ADC도 3/8 operating point가 target을 실패했다.
- M=128에서는 두 방식의 차이가 작고 reconstruction 우세도 존재한다.
- 따라서 `ADC가 일관되게 더 좋다`보다 `ADC 우세 경향이 coarse PQ에서 강하지만 operating-point validity와 효과 크기는 조건 의존적이다`가 정확하다.
- 현재 RFW-Custom common TPIR20 table에는 matched PQ rows가 없으므로 `여러 데이터셋 전체에서 일관됨`에는 LFW·SurvFace만 포함된다고 명시해야 한다.

## 5. contribution 제안의 수정

외부 GPT의 세 contribution은 방향상 좋지만 다음처럼 고치는 것이 안전하다.

### Contribution 1 — 타당

\[
Retrieval\ preservation\not\Rightarrow Decision\ preservation
\]

Rank20이 유지돼도 genuine score가 threshold 아래면 TPIR20이 실패할 수 있고, threshold 재보정이 score shift를 회복해도 Rank20 이탈은 회복하지 못한다는 분해는 방어 가능하다.

### Contribution 2 — 조건 수정 필요

기존:

> PQ reconstruction과 ADC를 동일 PQ budget에서 비교한다.

수정:

> 동일 gallery PQ code budget에서 full-precision-query ADC와 compressed-query reconstruction을 비교하고, 추가 one-sided cosine 및 SDC controls로 query precision과 metric 효과를 분리한다.

### Contribution 3 — 타당하나 새 방법은 아님

> 각 score space에 held-out threshold를 적용하고, valid realized FPIR에서 TPIR20/DIR/Rank20 retention을 평가한다.

`원본 operating point를 재현한다`보다 `목표 FPIR 근방에서 원본 utility를 얼마나 보존하는지 평가한다`가 정확하다.

## 6. 논문 표의 수정 조건

외부 GPT가 제안한 표에는 다음 열을 반드시 추가한다.

- `query_representation`: origin 또는 PQ/reconstructed
- `gallery_representation`: origin 또는 PQ code/reconstructed
- `score_space`: cosine 또는 negative squared-L2 ADC
- `threshold_source_split`
- `target_met_on_test`
- realized FPIR count/denominator와 CI
- TPIR20 count/denominator와 CI
- Rank20
- gallery storage와 query storage/transfer condition

`Metric_method - Metric_origin`은 TPIR/DIR/Rank처럼 rate metric에는 사용할 수 있지만, 다음 조건이 필요하다.

1. 동일 protocol과 test population
2. 각 score space의 held-out threshold
3. target FPIR 충족 또는 realized-FPIR curve상 정합
4. target 실패 row는 같은-FPIR 우세 주장에 사용하지 않음

Raw threshold와 raw score delta는 ADC와 cosine 사이에서 계산하지 않는다.

## 7. TinyFace 제안의 판정

TinyFace는 저화질 external validation으로 연구를 강화할 가능성이 있다. 그러나 현재 저장소에는 TinyFace experiment integration이 확인되지 않았다. 더 중요한 점은 dataset 추가가 현재 ADC/reconstruction 비교의 두 confound를 해결하지 않는다는 것이다.

우선순위는 다음이 맞다.

1. one-sided reconstruction cosine
2. PQ/PQ SDC 또는 decoded-query L2
3. 같은 gallery budget과 query condition 명시
4. target-valid operating-point curve/CI
5. 그 뒤 TinyFace 등 external low-quality dataset

졸업 일정과 GTX 1080 Ti 범위를 고려하면 새 dataset보다 같은 기존 embedding/codebook에서 파생 가능한 fair control이 비용 대비 가치가 높다.

## 8. IEEE Access 적합성의 수정 판정

IEEE Access reviewer guideline은 높은 algorithmic novelty가 항상 요구되지는 않지만 기존 연구와 distinct하고 technically sound해야 한다고 한다. 동시에 scope/quality prescreen은 clear SOTA advance를 요구한다.

따라서:

- `ADC > reconstruction + recalibration`만 제출: **novelty 약함, 위험**
- current multi-model/multi-profile open-set characterization: **투고 타당, 조건부 현실적**
- one-sided cosine/SDC로 원인을 분리하고 lifecycle·storage·valid FPIR까지 연결: **Access applied engineering paper로 충분히 방어 가능**

외부 GPT의 `IEEE Access fit 높음`은 세 번째 상태를 전제로 하면 타당하다. 현재 두 방법 비교만을 뜻한다면 과도하게 낙관적이다.

## 9. 수정된 핵심 문장

외부 GPT의 마지막 영문은 다음처럼 수정하는 것이 안전하다.

> We do not propose ADC as a new method. We study how query and gallery compression conditions affect 1:N open-set face search under a fixed gallery PQ budget. After applying held-out, score-space-specific thresholds, we compare full-precision-query ADC, one-sided reconstruction cosine, and compressed-query baselines using realized FPIR, TPIR@20, DIR, Rank@20, and storage. This design separates recoverable score-space shifts from irreversible ranking losses and quantifies when preserving query precision provides operational benefit.

한국어:

> 본 연구는 ADC를 새 방법으로 제안하지 않는다. 동일 gallery PQ budget에서 query와 gallery의 압축 조건 및 distance metric을 분리하고, score-space별 held-out threshold 적용 후 realized FPIR, TPIR20, DIR, Rank20과 저장량을 비교한다. 이를 통해 재보정 가능한 score shift, 회복 불가능한 ranking loss, 그리고 원본 query 정밀도 보존의 운용상 이점을 구분한다.

## 10. 최종 판단

1. 외부 GPT 답변의 연구 방향과 Access scope 해석은 대체로 타당하다.
2. current reconstruction 구현을 one-sided cosine으로 설명한 부분은 명백히 수정해야 한다.
3. `동일 PQ budget`은 `동일 gallery code budget`으로 한정해야 한다.
4. ADC의 성능 우세는 관찰됐지만 모든 profile·dataset·operating point에서 일관되게 유효하지는 않다.
5. threshold 숫자의 유지가 아니라 별도 calibration 후 valid realized FPIR에서 utility retention을 평가해야 한다는 지적은 정확하다.
6. TinyFace보다 one-sided cosine과 SDC control이 우선이다.
7. 수정된 설계라면 IEEE Access에 잘 맞지만, 현재 좁은 결론만으로 `충분히 부합한다`고 확정하는 것은 이르다.
