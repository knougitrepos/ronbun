CSV는 sample_id, split, aligned_content_sha256, target/valid 플래그와 두 특징을 담는다.
- Faithfulness는 기존 v2의 summary/rows·동일 saliency spec을 검증하고 all-group 평균/건수를 원자료와 대조한다. `evaluation_split=calibration/development`와 실제 test 비중복이 추가 실행 조건이다. 과거 manifest 문구를 수정하는 것으로 새 근거를 만들지 않는다.
- 실행 결과는 `results/calibration/saliency_incremental/<run_id>/<uid>` 또는 `saliency_incremental_split_stability`에 method_summary/paired_comparisons/models/split_summary CSV + manifest로 저장한다. 입력/실행소스 hash, baseline/seed/hyperparameter, score space와 metric 계약을 기록한다. 기존 UID 재사용은 모든 파일 hash를 검증한다.
- Gate가 blocked이면 적합·성능 결과 저장을 하지 않는다. 최초/이후 셀을 재실행해 gate를 우회하지 못하도록 runner 내부에서 다시 검증한다.

### 검증·재실행 범위·미해결 위험

- 신규 10개 테스트와 관련 continuous/conditional/FIQA/faithfulness/report 회귀를 포함하여 총 **93개 통과**, Ruff 통과.
- 합성 ready 입력의 네 방법, 두 seed panel, retrieval 기준, test score 변경 시 모델 불변, 기준 계수 일치, blocked 입력의 fit 미호출, alignment/split/coverage/Random gate, 파일 및 메모리 변경 감지, 저장/reuse 검증.
- 실제 ArcFace 노트북을 새 커널에서 전체 실행: calibration coverage **0.0**, test **1.0**. High−Random 평균 약 **−0.025278**, 95% CI 약 **[−0.026108, −0.024425]**로 strong gate 실패. 실제 faithfulness ID **182159개**가 test와 겹친다. 결과적으로 정상적으로 blocked이며 FIQA+Saliency 성능 숫자는 생성하지 않았다.
- 부족한 calibration Grad-CAM·독립 가림 실험을 생성하는 producer는 이번 범위에 포함하지 않았다. 02는 검증·소비·조건부 비교 구현이며, 실제 자료 생성은 GPU 장치/범위/추가 비용을 정한 별도 작업이다. 기존 00/01/batch/FPIR 진단 및 완료 결과를 다시 돌릴 필요는 없다.
- 95% CI는 고정 threshold/codec/gallery 조건에서 FPIR=query, TPIR=mated identity cluster이다. 다중 비교·calibration 재적합 불확실성·추론비용까지 확증하지 않는다. seed별 최소/중앙/최대는 기술통계다. 실제 개선 검증 및 공통 보고 자동 연결은 미완료다.
