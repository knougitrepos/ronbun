## 핵심 결론

시도할 것이 소진된 상황은 아니다. 우선순위는 원본에도 동일 보정을 적용하는 교차 대조, 압축률 변경 후 재보정 데이터 효율, 이후 갤러리 증가에 대한 유지 성능이다. Margin/distortion/saliency 조합을 더 늘리는 것은 우선순위가 낮다. 기존 22.md의 방향을 유지하며 새로운 방법의 우월성을 주장하지 않는다.

## 검증할 실험과 수학적 정의

질의 x, 품질 q, 압축 조건 c, gallery G에 대해 S_c(x)=max_g[-||x-Q_c(g)||²]. 미등록 질의의 FPIR은 P(S_c(x)>=tau_c(q(x)) | non-mated)다.

1. 원본/PQ 각각 Global-safe와 Continuous FIQA를 같은 분할·표본 예산·safety 절차로 비교한다. 동일 실제 FPIR에서의 진단 TPIR을 T라 할 때 I_c=[T(c,FIQA)-T(c,Global)]-[T(origin,FIQA)-T(origin,Global)]로 압축과 보정의 상호작용을 확인한다. Test 곡선은 사후 진단이며 threshold 선택은 calibration에서만 한다.
2. 대표 backbone·dataset 하나에서 m128→m64/m32 전이를 평가한다. Target calibration 예산을 가용량에 맞춰 사전 고정한다. Source 그대로, target Global 재적합, tau_target(q)=f_source(q)+delta_target, target 전체 함수 재적합을 같은 예산으로 비교한다. Delta는 target non-mated residual로 정한다. 실제 FPIR·TPIR20·목표 초과·CI·보정 시간·source 비용을 보고한다. 기존 Global 재적합만으로 충분하면 복잡한 전이법 개발을 중단한다.
3. 두 번째 실험에서 유용성이 있으면 core identities/probes/codec을 고정하고 distractor만 늘려 gallery 증가를 평가한다. Unknown identity 유입을 방지하고 필요한 검색 replay 비용을 포함한다.

TPIR20은 정답 rank<=20과 정답 score의 threshold 통과를 함께 요구한다. Rank 실패와 threshold 실패를 분리해 보정으로 회복 가능한 범위를 진단한다. 최종 검증은 설계 고정 후 미사용 outer cohort를 사용하며 동일 test의 20개 내부 분할을 독립 재현으로 계산하지 않는다.

## 직접 비교 후보와 중복 점검

- QMagFace, WACV 2023 정식: [공식 페이지](https://openaccess.thecvf.com/content/WACV2023/html/Terhorst_QMagFace_Simple_and_Accurate_Quality-Aware_Face_Recognition_WACV_2023_paper.html). 품질 기반 score 조정이 겹친다. 같은 1:N 프로토콜의 외부 baseline 후보다. ADC adaptation은 원 방법 재현과 구분한다. 이번에 공식 페이지 확인.
- CQR, NeurIPS 2019 정식: [공식 페이지](https://proceedings.neurips.cc/paper/2019/hash/5103c3584b063c431bd1268e9b5e76fb-Abstract.html). Quantile regression과 calibration 결합은 기존 방법론이다. 이번에 공식 페이지 확인. 현 empirical offset에 그 보장을 자동 부여하지 않는다.
- NP threshold, Science Advances 2018: [기관 원문](https://escholarship.org/uc/item/2996c8m6). 22.md의 검증 기록 참조. 오수락 제어 자체를 신규성으로 주장하지 않는다.
- KWS quantization score calibration, ICASSP 2026: [DOI](https://doi.org/10.1109/ICASSP55912.2026.11464442). 출판 상태는 22.md 기록 참조, 이번 재검증 없음. 압축 오차 기반 보정의 재명명으로 차별화하지 않는다.
- MRQ, PVLDB 2026: [공식 PDF](https://www.vldb.org/pvldb/vol19/p1240-yang.pdf). 출판 상태는 22.md 기록 참조, 이번 재검증 없음. 압축 오차·다단계 refinement와 일반 uncertainty rejection/exact fallback을 새 이름으로 제안하지 않는다.

남은 차별화 후보는 특정 압축 변경에서 같은 target 데이터 예산으로 오수락 목표와 식별률을 얼마나 회복하는지, 어떤 조건에서 실패하는지를 실증하는 것이다. 식 자체의 최초성이나 기존 연구 대비 우위는 미입증이다.

## 최신 세컨드오피니언의 해석 수정

S>=tau(q)는 S-tau(q)>=0과 동치다. 따라서 score 쪽을 바꾸는지 threshold 쪽을 바꾸는지만으로 수학적 독창성을 입증할 수 없다. 쿼리 공통 보정인지 후보별 보정인지, 사용하는 정보, 순위 변화, 평가 단위와 데이터 비용이 실제 비교 대상이다. PQ gallery에도 품질 스칼라를 따로 저장할 수 있으므로 압축 때문에 gallery quality가 원천적으로 불가능하다고 말하지 않는다. 또한 현재 quality-only 함수에는 FIQA 단조성 제약이 없으며 코드의 box 제약은 선택적 adc_margin 계수에 적용된다.

이 기록은 연구 방향 자문이며 architecture 변경 결정이 아니다. 기존 코드를 변경하거나 대규모 실험을 실행하지 않았다.
