# 2026-10-31 KST — Backbone 이름과 baseline 학습률 교정

상태: 검증됨(코드·관련 회귀 테스트 범위). 정식 학습/성능 실험 완료를 뜻하지 않는다.

20261028·20261029의 두 저장소 독립 운영, 외부 공유 저장소, 데이터 분할,
1024D 및 수치 안정화 정책을 유지한다. 20261030 논리 감사에서 재현한
ResNet 학습률 강제값 오류와 이름에 따른 batch 검사 차이를 수정한다.

- UCFace 본문 IV-A-3(PDF 6쪽): downstream baseline은 MobileFaceNet LR 0.001,
  ResNet-50/100 LR 0.0001. 기본값과 검증을 같은 함수로 연결한다.
- 모델명은 strip/lower로 판별하고 새 설정에는 기존 호환 표기인
  MobileFaceNet/Resnet으로 기록한다. 기존 metadata 자체를 고쳐 hash를 바꾸지 않는다.
- FaceX-Zoo 설정·모델 생성·slug·검증·parent 비교에 동일한 판별을 적용한다.
  ronbun도 독립적인 판별 함수를 사용하여 export 해석과 모델 생성에 적용한다.
  두 저장소 사이에 runtime import를 추가하지 않는다.
- campaign.pretrain_lr를 분리하여 fine-tune LR 교정이 parent LR를 바꾸지 않게 한다.
  기존 로컬 parent 기본값 0.001 유지이며 저자의 명시적 parent recipe라는 주장은 하지 않는다.
  실제 실행 설정과 optimizer/checkpoint/campaign 기록에 단계별 LR를 반영한다.
- 저장된 LR는 자동 이관하지 않는다. 잘못된 fine-tune LR는 검증에서 거부한다.
  다른 LR의 resume를 허용하지 않으며 기존 코드 fingerprint 검사도 완화하지 않는다.

영향: FaceX-Zoo backbone_factory/notebook_workflow/shared_storage, 00~04 노트북과
실행 안내; ronbun export metadata 해석과 로컬 backbone loader, 관련 테스트.
모델 수식·데이터 역할·평가 지표·DB schema는 변경하지 않는다.

export hash 불변과 독립 consumer 추론. 정식 학습·성능 개선 검증은 별개다.
