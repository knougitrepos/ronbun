# 2026-10-01 연구 구조 기록

## LFW 공개 BLUFR 기준 평가와 matched calibration의 분리

- 상태: **구현됨 / 단위·회귀·제한된 실제 입력·새 커널 검증됨**. BLUFR 정식 성능 실험과 전체 보정 행렬은 실행하지 않았다.
- 기준 브랜치: `step13`, commit `2c510a4234cffe75a05212447773fe0bab81e697` + 이번 변경. 기존 완료 run과 결과는 보존한다.
- 사용자 결정: 공개 BLUFR 기준 실험과 기존 LFW 분할을 개선한 별도 보정 실험을 병행한다. BLUFR의 1,500명 training pool을 압축 학습·1,000명 calibration gallery·미등록 보정 인물로 재분할하는 방안은 이번 구현에 채택하지 않는다.

### 배경과 이전 결정의 유지·보완

20260929의 원본/PQ 동일 cohort·동일 FIQA 보정, genuine-score-topk-v2, test 학습 금지 원칙을 유지한다. 20260930의 SQLite 재개·소수 파일 저장·메모리 단계 점검·채팅 ZIP을 유지한다. 기존 LFW-Custom 결과와 12개 source run 선택값은 수정하지 않는다.

최종 구조는 `research/experiments/lfw_protocol_experiments.py`가 기존 계산·검증·저장 함수를 호출하는 파생 실행 경로다. 기존 source 실행기는 Grad-CAM 등 여러 단계를 묶고 있으므로 BLUFR에서 이를 그대로 반복 호출하지 않는다. 당초 예상 파일 목록 중 `pipeline_runner.py`, `step4_workflow.py`, 기존 calibration core 등을 직접 변경할 필요가 없어졌다. 노트북 5개에서 새 경로를 선택하며, 노트북 수는 늘리지 않는다.

### 두 실험의 과학적 계약

1. **BLUFR 공개 test-list 기준 평가**
   - MATLAB `imageList`, `labels`, `trainIndex`, `testIndex`, `galIndex`, `probIndex`를 읽는다. 인덱스는 1-based에서 한 번 변환하며 공개 순서를 보존한다. 13,233장/5,749명/10 trials, training 1,500명, gallery 1,000명·1장, identity 분리와 이미지 partition을 검증한다.
   - 공개 gallery/probe를 재추첨하지 않는다. 모든 필요한 임베딩이 있어야 실행한다. 네 FR 모델 모두 현재 13,195개 임베딩만 있어 38장이 누락되었다. 자동 제외·대체 crop·test 조정은 하지 않는다.
   - Origin cosine과 PQ m128/m64/m32 ADC를 비교한다. 기존 임베딩을 읽고 PQ를 각 trial의 training embeddings에서 새로 학습한다. 기존 custom PQ codebook은 BLUFR에 재사용하지 않는다. Query는 원본이며 gallery만 PQ codes다.
   - `OpenSetROC.m`의 false-alarm 반올림, threshold 및 Rank-1 DIR 계산을 포팅하고 Rank-20도 추가한다. stable gallery order로 동점을 처리한다. 원본 toolkit FAR는 목표 false-alarm 수/N이고 동점 때 실제 FPIR가 다를 수 있어 양쪽을 기록한다.
   - threshold는 test curve를 기술하기 위한 값이다. 운영용 calibration model이나 held-out FPIR 보장으로 해석하지 않는다. trial별 값, 평균, 표본 표준편차(ddof=1), mean-minus-std를 보고한다. 겹치는 trial을 독립 표본으로 취급한 CI는 산출하지 않는다.
2. **별도 LFW-Custom matched calibration**
   - `lfw-custom-matched-gallery-calibration-v2`라는 별도 UID를 사용한다. 공개 BLUFR 재현이라고 부르지 않는다.
   - 기존 development, test gallery/probe, 원본·PQ test 점수와 codebook을 유지한다. calibration pool에서 기존 deterministic builder로 gallery를 구성하되 test와 gallery 인원·인당 enrollment 수를 일치시킨다. 현재 source에서는 50명×5장이다. mean→L2 aggregation도 기존 함수를 공유한다.
   - calibration query는 2,789장, 그중 non-mated 1,741장이다. 원본 calibration의 2,882 non-mated보다 적으므로 low-FPIR 추정의 불확실성은 계속 보고한다.
   - 새 calibration 검색을 수행한 뒤 Origin/PQ 각각 Global-safe·FIQA 5-bin·Continuous FIQA를 새로 적합한다. 기존 PQ threshold 모델을 재사용하지 않는다. FR/FIQA 추론과 codebook 학습은 하지 않는다.
   - fit/safety seed는 기존 identity 분리 함수를 사용한다. 20개 seed를 BLUFR 10개 trial이나 독립 cohort 반복으로 간주하지 않는다.
   - gallery에 의존하는 기존 saliency를 새 calibration의 feature로 전용하지 않는다. 이번 선택된 보정 범위는 03의 원본/PQ × 세 가지 FIQA 보정이다.

### 출처와 artifact 계약

- 논문: Shengcai Liao et al., *A Benchmark Study of Large-scale Unconstrained Face Recognition*, IJCB 2014. https://shengcailiao.github.io/doc/liao-ijcb14-blufr.pdf
- 저자 안내: https://shengcailiao.github.io/projects/Benchmark_of_Large-scale_Unconstrained_Face_Recognition.html
- 저자 OneDrive 다운로드에 이번 환경에서 접근하지 못해 공개 toolkit mirror의 MAT와 README/평가 코드를 확인했다. 저자가 인증한 byte equality는 확인하지 못했다. 실제 다운로드 출처를 config에 남기고 공개 목록 SHA-256 `8f99875f50ee8a7b88659a15527f50ae9b8850a84df52b0b13ce32177895d51c`를 고정했다. 구조 검증은 저자 인증을 대신하지 않는다.
- 공개 목록 캐시는 `data/external/blufr/`, 실행 결과는 `results/lfw_blufr/`, 별도 보정 결과는 `results/calibration/lfw_matched/`다. 기존 `origin_vs_pq`나 source run을 덮어쓰지 않는다.
- SQLite에 모델/trial별 점수·codebook 또는 source/seed별 보정 결과를 transaction으로 저장한다. checkpoint spec에는 입력 출처·hash·코드 hash·runtime 버전을 포함한다. 완료 job은 hash 검증 후 재사용한다. 세부 표는 완료 시 ZIP으로 게시하며 부분 실행은 누락 job과 함께 compact ZIP만 게시한다.
- BLUFR 보고서는 `blufr_open_set_benchmark` 타입으로 별도 보관하여 test curve를 운영 calibration 보고서와 혼동하지 않는다. 저장 비용에는 gallery codes와 shared codebook을 구분한다.
- 메모리 점검은 강제 상한이 아니다. BLAS/Faiss thread 제한과 query batch 적용, 모델/trial 또는 source/seed 단위 재개를 사용한다.

### 검증 기준과 미해결 위험

- 공개 목록 파싱·hash·1-based indexing·중복/누출/누락 거부, genuine score와 Top-1 최대 점수 구분, 동점·FPIR endpoint, bounded cosine/ADC 수치 일치, codebook 재학습 없는 완료 trial 재사용, 보정 seed 재개를 테스트한다.
- 기존 노트북 legacy 경로와 새 경로 분기, notebook schema/AST, 새 Jupyter 커널 순차 실행을 검증한다.
- 실제 입력 검증은 네 모델, seed 8972, target FPIR .10, bootstrap100 범위다. 모든 Origin/PQ test table이 기존과 정확히 같고, 재실행 새 fitting이 0이며, source marker/manifest 등 24개 파일 hash가 유지되는지 확인한다.
- 전체 4모델×10 BLUFR trials와 전체 4모델×20 calibration seeds×5 FPIR 성능 실험, GPU 재추출, DB 작업은 미실행이다.
- BLUFR 누락 38장을 복구하려면 별도 전처리/임베딩 artifact가 필요하다. 기존 crop의 대상 인물 정확성과 checkpoint 학습 데이터 overlap도 미확인이다. 누락 이미지를 제외한 성능을 공개 BLUFR 재현으로 발표하지 않는다.
- 이전 보고된 97.90% 반복이 이번 split 변경으로 해결되었다고 주장하지 않는다. 원본 test와 crop을 유지하므로 해당 실패 원인 검토는 별도다.
