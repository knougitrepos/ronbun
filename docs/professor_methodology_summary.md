# 연구 주제

**PostgreSQL/pgvector 기반 압축 얼굴 임베딩 검색에서 유사도 분포 보정을 통한 미등록 인물 거부 성능 개선**

본 연구는 사전학습된 ArcFace/InsightFace 얼굴 임베딩을 PostgreSQL/pgvector에 저장하여 유사 인물을 검색하는 환경에서, 임베딩 압축이 유사도 분포와 미등록 인물 거부 임계값을 어떻게 변화시키는지 분석하고, 이를 경량 calibration으로 보정할 수 있는지 검증한다.

# 현재 구현 기반

현재 코드에는 FastAPI 기반 실험 흐름, ArcFace 임베딩 추출, PostgreSQL/pgvector 벡터 저장, PCA 기반 차원 축소, Faiss PQ 기반 압축 코드 생성, 코사인 유사도 기반 검색 유틸리티가 포함되어 있다. 따라서 연구는 새로운 얼굴 인식 모델을 학습하는 방향이 아니라, 기존 얼굴 임베딩을 실제 DB 검색 환경에서 저장, 압축, 검색, 평가하는 방향으로 구성한다.

# 제안 기법

제안 기법의 핵심은 압축 인지형 미등록 인물 거부 보정이며, 품질 기반 대표 템플릿 생성은 보조 실험 및 ablation으로 둔다.

1. **압축 인지형 미등록 인물 거부 보정**
   임베딩을 PCA 또는 PQ 등으로 압축하면 유사도 분포가 변할 수 있다. 따라서 단순 임계값만 사용하는 대신, 최고 유사도, 1위와 2위 점수 차이, 이미지 품질, 템플릿 분산, 압축 방식별 정규화 재구성 오차, 압축 profile 정보를 함께 사용하여 해당 질의가 등록 인물인지 미등록 인물인지 보정한다. 기본 모델은 logistic regression이며, shallow MLP와 비교한다.

2. **품질 기반 대표 템플릿 생성**
   동일 인물의 등록 이미지가 여러 장 있을 때 단순 평균을 사용하지 않고, 흐림, 해상도, 얼굴 검출 신뢰도, 자세 등 품질 정보를 반영하여 대표 임베딩을 생성한다. 또한 임베딩 분포에서 크게 벗어난 이미지는 이상치로 보고 제외한다. 이 구성은 핵심 novelty가 아니라 압축 환경에서 성능 안정화에 기여하는지 확인하는 비교 실험이다.

# 연구 구성

연구는 다음 순서로 진행한다.

1. 공개 얼굴 이미지 데이터셋에서 ArcFace/InsightFace 임베딩을 추출한다.
2. 인물별 등록 이미지를 구성하고, 단일 이미지, 단순 평균, 품질 기반 대표 템플릿을 비교한다.
3. 원본 512차원 임베딩과 PCA 기반 압축 임베딩을 PostgreSQL/pgvector에 저장하여 검색한다.
4. 질의 이미지가 등록 인물인 경우에는 Rank-1, Rank-5 등 검색 정확도를 평가한다.
5. 질의 이미지가 미등록 인물인 경우에는 known unknown과 unknown unknown을 분리하여, 잘못된 등록 인물을 반환하지 않고 unknown으로 거부하는 성능을 평가한다.
6. 압축 방식별 reconstruction error를 정규화하고, fixed threshold, per-compression threshold, logistic regression, shallow MLP를 비교한다.
7. 최종적으로 정확도, 저장공간, 질의시간의 trade-off를 비교한다.

# 기대 기여

본 연구의 기여는 새로운 얼굴 인식 모델 자체가 아니라, **얼굴 임베딩을 실제 데이터베이스 검색 시스템에 적용할 때 압축으로 인해 발생하는 유사도 분포 변화와 open-set 임계값 불안정을 정량화하고 보정하는 방법**을 제안하고 검증하는 데 있다.

특히 다음을 확인하고자 한다.

- 압축 이후 점수 보정이 미등록 인물 오인식을 줄이는지
- known unknown과 unknown unknown에서 보정 효과가 어떻게 다른지
- 품질 기반 대표 템플릿이 단순 평균보다 압축 전후 검색 성능을 안정화하는지
- 정확도 손실을 제한하면서 저장공간과 질의시간을 줄일 수 있는지

# 한 줄 요약

본 연구는 PostgreSQL/pgvector 기반 압축 얼굴 임베딩 검색에서 **압축으로 흔들리는 유사도 분포와 open-set 임계값을 경량 calibration으로 보정**하여, 미등록 인물 거부 성능과 저장 효율을 함께 개선할 수 있는지 검증하는 연구이다.
